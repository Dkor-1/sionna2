<details><summary><b>말 풀이</b> — 아래에서 되풀이해 쓰는 말 여덟 개</summary>

- **정지 성분(DC)** — 시계열의 평균, 즉 «가만히 있는 부분». 동체처럼 안 움직이는 데서 오는 몫이다.
- **움직이는 부분(AC)** — 평균을 뺀 나머지. 프로펠러가 도는 데서 오는 몫이고, 마이크로도플러는 여기 산다.
  ⭐레벨 비교는 전부 정지 성분을 뺀 뒤에 한다.
- **날개끝 상한(f_tip)** — 날개 끝이 낼 수 있는 가장 빠른 도플러. 그 **위**의 주파수에는 «날개가 만들 수 있는
  물리» 가 없다 — 그래서 거기 뭐가 있으면 계산이 만든 것이다.
- **빗살** — 프로펠러 박자(f_flash)의 정수배마다 서는 선들. **바닥**은 그 선들 밖의 잔잔한 부분.
- **리듬 몫** — 상한 위 전력 중 빗살에 앉은 몫. 완전히 흐트러진 신호면 12.6 % 언저리가 나온다(«백색»).
- **광선 표집 흔들림(몬테카를로 잡음)** — 광선을 무한히 못 쏘고 유한하게 쏴서 생기는 계산 흔들림.
  이것이라면 광선을 4 배 늘릴 때 세기가 4 배 준다(= −6 dB, «옥타브» 당 −3.01 dB).
- **옥타브** — 광선 수를 2 배 하는 한 계단.
- **수렴했다** — 값이 더 안 변한다는 뜻. ⛔이 문서에서 「수렴」이라 적힌 옛 문장은 **정지 성분에 한해서만** 참이다.

## ⓪ 판정 문턱 — 앞으로 모든 실험이 쓰는 «격자 산포 밴드»

R16 이 같은 커널·같은 자세·같은 기하에서 **격자만** λ/12 → λ/24 로 조여서 잰 값이다. 물리는 하나도
안 바꿨는데 잣대가 이만큼 움직인다. 그러니 규칙은 하나다 — **두 팔의 차이가 이 밴드 안이면 «판정 불가»**.
밴드는 네 앙각(0·−15·−30·−45)에서 잰 |λ/24 − λ/12| 의 **최대값**이다(보수적으로 쓰려고 최대값을 쓴다).
근거: `outputs/grid_convergence_check.json` → `grid_dispersion_bands`.

| 잣대 | **밴드(최대)** | 중앙값 | 읽는 법 |
|---|---|---|---|
| **움직이는 부분 세기** (정지 성분 뺀 AC 절대전력) | **3.86 dB** | 0.85 dB | 레벨 주장은 이 밖에서만 유의하다 |
| **리듬 몫** | **21.8 %p** | 12.3 %p | ⛔**이 축으로는 판정하지 않는다**(R29). «λ/12» 꼬리표로는 부족하다 — 창 반폭 hw 를 2/8/32 Hz 로만 옮겨도 같은 데이터가 **9.9 / 63.4 / 90.0 %** 로 움직이고, `f_above` 를 함수 기본값(1.5·f_flash)으로 두면 63.4 % 가 **98.9 %** 가 된다(`outputs/rhythm_share_knob_audit_0825.json`). **격자보다 분석 손잡이가 더 크게 흔든다.** 대신 자유 파라미터 없는 양(요동 진폭비 · \|상관\| · 크기비)을 쓴다 |

강제 규칙 넷:

1. **밴드 안 = 판정 불가.** «유의하다» 를 쓰려면 밴드 밖이어야 한다. 문턱을 새로 적는 실험은 이 표의 줄을 인용한다.
2. **«λ/12 한정» 꼬리표 발동.** 사전등록 조건(팔 사이 순서가 λ/24 에서 바뀌면 꼬리표 강제)이 성립했다 —
   뒤집힌 칸 6 개가 나왔고 **전부 밴드 안**이었다. 즉 그 순서들은 «바뀐» 것이 아니라 애초에 격자 해상도로
   **판정할 수 없던 순서**다. 리듬 몫·날개끝 밖 몫의 절대값을 인용할 때는 «λ/12 에서 잰 값» 을 같이 적는다.
   ⭐반대로 **AC 절대전력 순서**(우리 ≫ 물리켬·물리끔)는 네 앙각 모두에서 밴드보다 훨씬 큰 여유로 살아남는다.
3. **상관은 «자» 를 달고 인용한다.** 같은 커널·같은 격자에서 **앙각만** 15~45° 바꿔도 \|ρ\| 가 0.27~0.78 나오고
   (섞기 널은 0.009), STFT dB-맵 상관은 격자만 바꿔도 0.60~0.74 로 내려간다. 즉 **0.5~0.8 대는 명백히 다른
   물건들 사이의 평범한 값**이다 — 덱의 «우리 0.9877 ↔ PathSolver 0.6961» 에서 **0.6961 은 격자 바닥과
   구별되지 않는다**. 상관으로 «안 닮았다» 를 세우지 않는다.
4. **밴드를 잰 자리는 el 0 ~ −45 뿐이다.** −60·−75·−90 에는 아직 λ/24 짝이 없다 — 거기서 이 밴드를 쓰면
   «인용이지 검증이 아님» 을 함께 적는다(큐 C 블록이 그 구멍을 메운다).

| **R22 · 4RX ULA 대 분산** | false·5·5 (평균 4.7) | **실험에서 내리고 닫힌형 부록 한 장으로 격하.** ①`MEASUREMENT_PLAN §2-1` 이 «4 채널 동시포착은 우리 설계가 아니다, 최소 기준 1 + 감시 1» 을 이미 못 박았고 3 층은 모노스태틱이다 — 닫힌 결정을 다시 여는 셈. ②비교의 한쪽 팔(ULA 각도축)을 **이 원장으로는 못 잰다** — 방향당 복소 스칼라 시계열이라 각도 정보가 없다. 한쪽만 계산된 비교로 발주 사양을 정하는 것은 위험하다. ③통과선이 잘못 교정됐다 — R50 을 1.3 배 올리려면 1/R⁴ 라 ≈11 dB 가 필요한데 비코히런트 2 채널은 1.5 dB 다. 사실상 «분산은 진다» 를 미리 정해 둔 문턱. ⇒ 부록에 비코히런트 √N · 앙각별 대역 몫 산포 ±15 dB · ULA 3 소자 빔폭 33.8° 를 한 표에 놓고 «지금 원장으로는 여기까지» 로 끝낸다. 먼저 **앙각 간 AC 상관 길이**를 원장에서 재라(무료) — 상관이 0.9 면 다양성이 없다는 결론이 한 줄로 난다 |

### 살아남았지만 잘라낸 팔 (기록)

- **R1 의 q=0.05 팔** — `sample.pdf *= probs` 라 중요도 가중이고, q 를 0.2→0.05 로 내려도 정반사 몫이
  80→95 % 로 오를 뿐(≈+0.8 dB). 사전등록한 «40 %p 회복» 은 구조상 불가능해 검정력이 없다. 게다가
  el −30 에서 D1 칸(−95.5 dB)이 D0F1 칸(−133 dB)보다 **38 dB 지배**하므로 재가중으로 리듬을 되살릴 수 없다.
- **R1 의 spp 1.6e10 팔(16 GPU-h)** — ✅**폐기 확정.** R17 이 공짜로 선답했다 — 상한 위는 광선 수에 불변이고,
  10 dB 낮추려면 10³⁰ 배가 필요하다. 예산을 4 배 올리는 팔은 검정력이 0 이다.
- **R1 의 등가 대조군(R0D0E0F1 · spp 3.2e9)** — 위와 같은 이유로 불필요.
- ⚠**R1 의 spp 내리는 사다리도 «12 배 싸고 판별력이 같다» 는 말은 이제 못 쓴다** — 그 판별력의 근거였던
  «바닥이 1/spp 를 따라간다» 가 물리끔 팔에서 **거짓**으로 나왔다(R17). 남은 판별력은 §② 18 행에 적은
  한 가지(회절 팔에서도 같은 불변인가)뿐이고, 그것으로 설계를 다시 쓰기 전에는 발주하지 않는다.
- **R5 의 엔진 교차 절반** — `classify_airframe` 은 제원에서 만든 템플릿 정합이라 **학습 파라미터 0 개**다.
  «ours 로 세운 결정을 sionna 에 적용» 할 결정이 존재하지 않는다. 학습 개념이 필요하면 R9 Stage 0 의 몫.
- **R5 의 PathSolver 팔(31 GPU-h)** — 우리 팔부터. 그리고 az45·el 0 에서 PathSolver 레벨이
  −63.25 → −120.32 dB 로 무너지므로, 그 상태에서 정확도를 재면 «자세 일반화» 가 아니라 «에코 소실» 을 잰다.
- **R9 Stage 0.5(3 기체 확장) · Stage 2(표 108 개)** — 관문(Stage 1) 통과 전에는 예산 논의를 하지 않는다.
- **R4 의 el 0·−30·−45 λ/48 판** — ✅R16 판독이 확인했다. 통과선 0.03 기준으로 el 0 은 0.0270 → 0.0152,
  el −30 은 0.1062 → 0.0136, el −45 는 0.0181 → 0.0027 로 셋 다 λ/24 에서 내려갔다.
  남은 자리는 **el −15 하나**(0.1718 → 0.0463, 아직 통과선 위).
- **R2 의 `--physics` 팔** — D1 조합은 `STANDARD_FRAME.md` 에서 표준 프레임 밖(별도 트랙)이다.
  회절 트랙이 되살아날 때로 미룬다.
- **R14 의 2 단계(mini5pro 물리켬, 14~21 GPU-h)** — 1 단계에서 설정 C 가 2 클래스 65 % 미만일 때만 발주.
- **R20 의 32768 자세 큐** — 드웰이 416 ms 까지 계속 오를 때만 조건부 발주.
- **R11 의 임펄스·파레토 잡음 팔** — 헤드라인은 백색으로 유지, 2 라운드로.
- **R8 의 A1(ResNet18 대조군 포함)** — 프로펠러 큐가 빈 뒤. A3·A2 는 CPU 로 먼저.

   폐기하고, spp 내림 사다리도 재설계 전에는 발주하지 않는다. 층 5 에서 지금 살아 있는 것은 «광선 수» 가
   아닌 축을 건드리는 것들이다 — 두께(R2) · 격자(R4·C·D) · 방위(R5) · 반송파(R23②) · 드웰(G).
2. **⓪ 밴드 없이 «유의하다» 를 쓰지 않는다.** ✅이제 밴드가 있다 — 옛 문턱(3 dB·10 %p·1 dB)은 전부 ⓪ 표의
   해당 줄로 갈아 적는다. 특히 «1 dB 차이» 류는 전부 밴드 안이라 **판정 불가**다.
3. **우리 커널 신규 투입은 PTD 적대검증 게이트 뒤다**(`STANDARD_FRAME.md`). 다만 **격자 수렴 확인은
