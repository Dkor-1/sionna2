# 8/18 까지 — **상류부터의 작업 순서**

> ## ⭐사용자 방침 (2026-08-11) — 이 문서의 골격을 정한 것
> *"덱은 **재료가 쌓인 뒤에** 만들자. 급할 것 없다."*
>
> ⇒ 이 문서는 이제 **덱 일정표가 아니라 재료 목록**이다. 덱은 5 층이고 **맨 마지막**이다.
> 장수·마감으로 역산하지 않는다. 층이 닫히는 순서대로 쌓고, 쌓인 만큼만 덱에 올린다.
> ⛔ 아직 안 닫힌 층의 결과를 «자리표시» 로 덱에 미리 넣지 않는다 — 그게 지난 두 번의 사고였다.

작성 2026-08-10. 갱신 2026-08-11(문서 정합 라운드). 진행 상황은 `docs/RESUME.md` 와 함께 갱신한다.

## ⭐ 순서 규칙 — [[upstream-first-ordering]]

```
1층  물리 커널     사다리(SNR 규약·이득·듀티) · PO/SBR 산란식 · 격자 · 전처리 체인
2층  원장          σ 격자 · 거리 스윕 · 시드/예산 사다리 · 낡은 원장 정리
3층  태스크        탐지 · 분류 · 패시브 2채널   ← 여기서 «말할 것» 이 생긴다
4층  리포트        권별 서술 · 그림
5층  덱            ⛔재료가 쌓인 뒤에
```
⛔ **결함을 발견한 시점에 층을 다시 세우고 순서를 갈아엎는다.**
아래 각 층은 **닫힘 조건**(무엇이 참이면 다음 층으로 가나)을 함께 적는다.

- ⭐**확증의 핵심**: 사다리 ③ 이 `src/freespace_link.py::snr_rd_db(T=1/PRF)` 와 소수점 14 자리까지

- ⭐**PRF 는 20,000 Hz** (`microdoppler_nearfield.DECLARED_PRF_HZ`). 19,700 Hz(37.06 dB)는

- ⭐**실효 이득은 28 ~ 37 dB** (항별 측정의 합, `verify_linkbudget` 파일럿·straddle 항).
  하나의 수가 아니라 **띠**로 그린다.
- ⭐**실측 R90 (3.5 GHz·EIRP 12 dBm)**: mavic4pro 72.5 m · s1000plus 51.2 · matrice4e 22.1 ·

### ⛔ 이 축에서 아직 수치를 넣으면 안 되는 자리
- **상시 기준신호(LTE CRS·5G SSB) 팔의 SNR** — 코드가 44~50 dB 비관적이다(1층 K-1).
  «SNR 이 아니라 **도플러 모호**가 그 팔의 대가» 라고만 쓰고 수는 뺀다.
- **점유(듀티) 팔** — 사다리에 듀티 항이 없다(1층 K-2). 9모드로 옮기지 마라.
- **«37 dB 를 실제로 번다»** — 끝에서 끝까지 게이트(G12)가 아직 없다(3층 T-0).

## 1층 — 물리 커널 (⭐가장 먼저. 아래층이 전부 여기 기댄다)

> **닫힘 조건**: 사다리가 «어떤 팔에도 그대로 쓸 수 있는» 상태가 된다. 즉 풀캡처·상시
> 기준신호·점유 세 팔이 **같은 사다리 위에 놓인다**. 그 전에는 어떤 거리 수치도 확정이 아니다.

- [ ] ⭐**K-1 `always_on_pilot` 의 τ_on** — `matched_filter_gain_db(capture="always_on_pilot")`
      이 0 dB 를 돌려준다. 옳은 값은 `G = 10log10(B·τ_on)` 이다(LTE CRS +50.0 · 5G SSB +44.6 dB).
      **0 dB 를 원장에 싣지 마라.** 당장 못 고치면 그 팔을 «미계산» 으로 표시하고 수를 안 낸다.
- [ ] ⭐**K-2 듀티 항** — 사다리에 없다. `src/freespace_link.py::duty_db_from_cpi` 를
      **재사용**한다(재구현 금지, 이중계상 가드도 그쪽 방식 그대로).
      측정: LTE 연속 0.00 · 5G SSB 버스트 −18.45 · WiFi 1 kHz 패킷 −10.00 dB.
- [ ] ⭐**K-3 이름 분리** (값 재계산 0)
      · `g_stft_db` → `g_frame_db`(조각 16.69 dB) / `g_cpi_db`(전창 36.12 dB) — 같은 키가
        두 원장에서 **19.4 dB** 다르다
      · `snr_ac_*_db` → `snr_ac_premf_*_db` — 현행 원장에서 `snr_slow_ac_*_db` 와 **36.99 dB**
        다른데 이름이 둘 다 «ac» 다(`RESUME.md` U-3)
      · `do_not_confuse` 에 «37 dB 짜리 수» **다섯 개 전부**와 «CPI 이득은 기록 길이의 함수» 를 적는다
- [ ] **K-4 광선 격자 수렴** — SBR 팔의 대역 밖 전력이 이산화 잡음인지 판정(λ/8 → λ/32).
      · 내려가면 → 생산 격자 교체 여부 + **전 원장 재계산 범위** 결정
      · 안 내려가면 → 원인이 다른 데 있고 **그게 더 큰 발견이다**
- [ ] **K-5 `experiment_freespace_range.py:496`** 하드코딩 `eca_depth_db=60.0` 라벨 굳음 —
      원장 1,209 셀의 `limit` 라벨이 전부 한 값이다. 개명 + 조건 배지

## 3층 — 태스크 (⭐여기서 «말할 것» 이 생긴다)

> **닫힘 조건**: 탐지·분류 각각에 «되는 범위» 와 «안 되는 범위» 가 수로 적힌다.

- [ ] ⭐⭐**T-0 G12 — 사다리 ↔ 실사슬** (다른 모든 것의 신뢰도가 여기 걸린다)
      `passive_two_channel_md` 의 `sinr_ideal_db` 와 사다리 예측을 **≤1 dB** 로 맞춘다.
      이게 없으면 28~37 dB 는 «항별 측정의 합» 이지 사슬 측정이 아니다
- [ ] ⭐⭐**T-1 패시브 호버 사슬** (`RESUME.md` U-1) — 지금 **끊겨 있다**.
      블레이드선을 내는 팔(얼린 격자)은 절대 레벨을 못 내고, 절대 σ 를 내는 팔은 위상이 없어
      블레이드선을 못 낸다. **ECA 노치가 DC 를 지우면 AC 행이 최대 37 dB 움직인다 — 미측정**(G16)
- [ ] ⭐**T-2 분류 데이터셋** — 기체 5 종 이상 × 자세 × 무작위 산포, 기체당 20 시행 이상.
      ⚠잡음 0 은 **상한**이다. 잡음 팔을 하나라도 돌려 «어디서 무너지나» 를 낸다
- [ ] ⭐**T-3 패시브 2채널** — 기준채널 이상적/잡음/다중경로 세 팔, ECA→CAF→CFAR 실사슬
- [ ] **T-4 PathSolver 가산성**(`docs/PLAN_PATHSOLVER_CLASSIFY.md` T1) — 광선으로는 시드
      편향이 안 지워진다는 것이 실측됐으므로, PathSolver 분류 가능성은 **가산성 하나에** 달렸다
- [ ] **T-5 σ 불확실성 띠** — 우리 σ 는 Das 실측의 **2.39 배(3.78 dB)** = 거리 ×0.79.
      R90 표에 이 띠가 **아직 없다**
