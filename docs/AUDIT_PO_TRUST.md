# PO(SBR+PO) 결과는 지금 얼마나 믿을 만한가 — 감사

> 원장: `outputs/audit_po_trust.json`
> 이 라운드는 **GPU 를 안 썼고 원장을 한 줄도 안 고쳤다.** 읽기만 했다.
> 새 계산은 CPU 에서 기존 npz 하나를 sinc 보간한 것 하나뿐이다(§5).

---

## 쉬운 말 요약

1. 우리 커널이 내는 것은 하나가 아니라 **세 층**이다 — 마이크로도플러의 «모양», 두 값 사이의 «dB 차이», 그리고 «절대 dBsm».
2. **모양은 믿을 만하다.** 해석적으로 답을 아는 최소 표적과 파형이 ρ = 0.9999 로 맞고, 프로펠러 플래시 박자를 앙각 7 점 전부에서 0.5 Hz 안으로 되돌려준다.
3. **절대 dBsm 은 아직 못 믿는다.** 사전등록한 함대 검증이 떨어졌고(산포 16.27 dB, 문턱 6.0), 부피만 같은 PEC 구가 4 기체 중 3 에서 우리를 이긴다.
4. **dB 차이는 축을 골라야 한다.** 블레이드선 전력은 격자를 바꿔도 1.4 dB 안이지만, 동체 성분과 가림 축은 15 dB 씩 움직이고 부호까지 뒤집힌다.
5. 그래서 지금 논문에 설 수 있는 것은 **분류(87.85 %)와 앙각에 따른 마이크로도플러 모양**이고, 못 서는 것은 **절대 탐지거리(15.4~72.5 m)와 널 깊이 dB** 다.

## 3. 가장 약한 고리 셋

### 1위 — 절대 σ 가 검증 안 됨. 그런데 **실패가 «메쉬 증거» 축을 따라 갈린다**

- 막는 것: R90 절대 미터값, 파형 벤치마크의 절대 거리, «우리 σ 가 맞다» 는 문장 전부, 실측 필드테스트 예측치.
- **고치면 열리는 것**: 원장이 이미 방향을 가리킨다 — 자기 형상 증거가 있는 두 기체는 \|DL\| ≤ 1.47 dB 다.
  즉 **커널을 고치는 문제가 아니라 증거를 사 오는 문제**일 수 있다.
  phantom2(자기 증거 0) · m350rtk(사진 1 장, IoU 0.503)에 증거를 붙이고 사전등록을 다시 걸면
  P3 산포가 16.27 → 1 dB 대로 내려갈 **가능성**이 있고, 그러면 R90 과 벤치마크가 절대값으로 풀린다.
- ⚠ 이건 n=4 의 2:2 분할에서 나온 가설이다(p = 0.167). 결론으로 쓰지 마라.

### 2위 — «블레이드선의 절대 레벨» 을 낼 수 있는 팔이 **없다**

- 기제: 위상을 쓰려면 격자를 얼려야 하고 → 절대 레벨이 판 한 장에 걸린다(3.452 dB).
  절대 σ 를 내는 정적 디더 팔은 위상이 없어 → 블레이드선을 못 낸다. **두 팔이 안 만난다.**
- 막는 것: 호버 표적 탐지거리 전체. ECA 0-도플러 노치가 동체를 지우면 탐지가 블레이드선 절대 레벨에 걸린다.
- **고치면 열리는 것**: 호버 패시브 탐지거리를 **처음으로** 낼 수 있다.
  그리고 고치는 법을 이미 데이터가 가리킨다 — `tsladder` 가 `P_ac` 격자 산포를 **0.07~1.36 dB** 로 쟀다.
  ⇒ **판을 여러 장 돌려 `P_ac` 만 평균**하면 블레이드선 절대 레벨을 1.4 dB 오차막대와 함께 낼 수 있다.
  판 1 장이 ~105~128 초다. 3~5 장이면 된다.

### 3위 — 근거리장에서 **광선이 발산하지 않는다** (8/18 앙각 챕터에 직격)

- 막는 것: el −30·−60 널 깊이 주장, PathSolver 와의 사과-대-사과, 10 m 라는 실험 설정 자체의 방어.
- **고치면 열리는 것**: 널 깊이가 물리가 되고, PathSolver 비교가 같은 기하 위에 서고, 근거리장 실험이 정당해진다.
- ⚠ «고치면 널이 얕아질 것» 은 **예측이지 측정이 아니다.** 반대 방향도 배제 못 한다.

## 4. ⚠ 근거리장 문제 — R = 10 m, 경계 14.076 m

**답: 지배항은 들어가 있고, 부차항 둘이 빠져 있다. 레벨·박자·맵 모양엔 충분하고 널 깊이엔 불충분하다.**

### 들어가 있는 것

2차 위상 `k·D²/(4R)` 이 커널에 그대로 들어간다(`src/rcs_sbr.py:1090-1093`).
R = 10 m, D = 0.7764 m 에서 **1.1055 rad = 63.3°** 다. 무시할 크기가 아니고, 그래서 넣은 것이 옳다.
(원장 `nearfield_sphere_vs_plane.json` 의 `quadratic_phase_rad` 가 3/8/15 m 에서 3.6851 / 1.3819 / 0.7370 —
같은 식이다.)

### 안 들어가 있는 것 둘

| 빠진 항 | 크기 (R=10 m) | 근거 |
|---|---|---|
| **1/r 진폭 기울기** | 편도 **0.675 dB** · 왕복 **1.349 dB** | `po_refinement_survey.json :: our_kernel_baseline.ray_divergence = 'none'` |
| **입사방향 산포** — 가림 판정과 `cos_i` 가 단일 방향 û 하나로만 계산됨 | 반각 **±2.223°** (전각 4.446°) | `src/rcs_sbr.py:1055` 평행 격자 · `:1069` `cos_i = Nn @ u` |

⭐ 두 번째가 중요하다. **널의 3 dB 폭이 1~2.5° 다**(`verify_po_elev_rebuttal.json :: 깨진_것.2`).
안 넣은 각도 산포 ±2.22° 가 그 폭보다 **넓다** ⇒ 실제 조명이라면 메워질 널을 우리는 뾰족하게 남긴다.

## 5. ⚠ el −60 의 π 모호성 — 176.4°, 4 표본

### 사실 (원장)

`verify_po_elev_metric.json :: old_metric_autopsy['-60']`

| 키 | 값 |
|---|---|

감사가 `elevation_sweep_md.npz` 에서 직접 세어 확인했다 — `n>150° = 4` · `n>90° = 27`(원장과 일치) · `n>170° = 2`.
다른 앙각의 최대 스텝은 3.8~71.0° 로 **el −60 만 특이하다.**

### ⭐ 이건 도플러 나이퀴스트 문제가 **아니다**

| | 값 |
|---|---|
| el −60 의 f_tip | 636.5 Hz |
| PRF | 19,700 Hz |
| 무모호 도플러 | ±9,850 Hz |
| **과표본 배수** | **15.5 배** |

도플러는 이미 15.5 배 과표본이다. 176° 스텝은 도플러가 커서가 아니라
**합성 페이저가 원점 가까이(−38.1 dB) 지나가서** 난다. 원점 통과의 각속도는 |v|/d 이고
최근접거리 d 가 0 으로 갈수록 발산한다.

### PRF 를 얼마로 올려야 하나 (감사 자체 계산, CPU)

기존 npz 를 밴드제한 sinc 보간으로 유효 PRF 를 M 배 올리며 최대 위상 스텝을 다시 쟀다.

| M | 유효 PRF | 최대 스텝 | >150° | >90° |
|---|---|---|---|---|
| 1 | 19.7 kHz | 176.43° | 4 | 27 |
| 4 | 78.8 kHz | 162.11° | 4 | 14 |
| 16 | **315 kHz** | 142.46° | **0** | 3 |
| 32 | 630 kHz | 121.34° | 0 | 1 |
| 64 | **1.26 MHz** | 72.29° | 0 | **0** |

⇒ **150° 밑으로 내리려면 ≈315 kHz(16 배), 언랩을 안전하게 하려면 ≈1.26 MHz(64 배)** 다.
도플러 나이퀴스트(1.27 kHz)의 **250~1,000 배**다.

⚠ 이 계열은 완전한 밴드제한이 아니다 — \|f\| > 4 kHz 에 에너지의 **0.639 %** 가 있다.
따라서 sinc 보간은 근사이고 위 사다리는 **자릿수 추정**이다.

### 얼마나 심각한가 — 잣대에 따라 갈린다

| 걸리는 잣대 | 안 걸리는 잣대 |
|---|---|
| `np.unwrap` 위상 변동폭(4,217°) — 못 쓴다, 이미 폐기 | 스펙트럼 rms 대역폭 — 널 위에서도 해석값과 **1.03 %** 안 (`M2_..._div48`) |
| 순시주파수 p95/최대 — 널 근처에서 해석값 대비 최대 **842.5 %** | 블레이드선 전력 `P_ac` — el −60 격자 산포 **0.07 dB** |
| | 플래시 박자 — el −60 에서 126.55 Hz (오차 0.09 %) |

### ⛔ 그리고 더 깊은 점 — PRF 를 올려도 **물리를 사는 게 아니다**

원점 최근접 거리 자체가 격자 판의 성질이다. 같은 λ/12 를 반 셀 옮기면
winding 이 **7.024 → 0.023 바퀴**로 사라진다(`tsladder`).
즉 64 배 표본율을 들여 더 곱게 보게 되는 대상이 **격자 아티팩트**다.

실무적으로도 이미 재 봤다 — `probe_prf_effect.json` :
PRF 19.7 → 35 kHz 에서 Δf 281.4 → 282.3 Hz, 박자 이동 0.013 Hz, 1x/2x 여유 이동 0.051 dB, 비용 **1.78 배**.
**분해능은 창의 시간 길이가 정하지 PRF 가 정하지 않는다.**

**결론** — 심각도는 «우리가 쓰는 잣대에는 안 걸린다» 다. 조건은 하나: **언랩 기반 잣대를 절대 쓰지 않는다.**
PRF 를 올리는 것은 이 문제의 해법이 아니다.
