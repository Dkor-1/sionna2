## 0. ⭐⭐ 오늘의 결론 — 프레임이 바뀌었다

**하루 종일의 감사가 하나로 수렴했다:**

```
❌ 틀렸던 프레임 :  "Sionna 로 드론 σ 를 낸다"
✅ 옳은 프레임   :  σ 는 우리 커널(Mitsuba + PO)이 낸다.  Sionna 는 환경을 낸다.
                    둘은 레이다 방정식에서 곱해진다 — 원래 분리되는 양이다
```

⭐ **σ 가 Sionna 와 무관한 것은 정상이다.** σ 는 평면파 조명 하의 표적 성질이라 거리·광선 도달과
무관하게 정의된다. LAMBDA·JSAC·상용솔버 전부 이렇게 한다.
**우리가 틀렸던 건 계산이 아니라 그 계산을 부르는 말이었다.**

### 역할 분담 확정

| | 담당 | 왜 |
|---|---|---|
| **σ 의 각도 구조 · 가림** | 우리 메쉬 + PO 커널 | 다중경로가 각도 구조를 요구. 가림이 11~40 dB |
| **σ 의 절대 레벨** | ⚠ **실측** | 메쉬로는 검증 불가 |
| **환경 · 다중경로 · 유령** | Sionna | 클러터 서베이가 16 dB 로 값어치를 증명 |

⛔ **메쉬 미세 정밀화(나사·배선·mm급)는 중단한다** — 검증 불가한 정밀도는 다른 종류의 틀림이다.
⛔ **상용 솔버(FEKO/CST) 구매 불필요** — 솔버 오차 0.85 dB 를 사려고 메쉬 오차 ≥2.7 dB 를 남긴다.

### 1-4. md-rt 재확인 (IEEE ICCT 2025, ⚠ 탑베뉴 아님)
