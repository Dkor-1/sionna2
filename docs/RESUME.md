✅ 메인       드론 탐지  +  마이크로도플러 패턴으로 분류

σ 는 **기여가 아니라 인프라**다. «우리가 σ 를 정확히 냈다» 를 논문 주장으로 쓰지 않는다.

층을 그리고 **아래층부터** 끝낸다. 상류가 틀린 채로 하류를 돌리면 버릴 결과에 계산을 태운다.
```

2층  메쉬        기하 · 겹침 · 재질 배정

```
