### 왜 지금까지 아무도 눈치 못 챘나 — 답을 찾았다

1. ⭐**게이트가 두 팔을 가로지르지 않았다.** `outputs/verify_linkbudget.json` 의
   `BE_processing_gain` 은 정합필터 이득을 **이미 측정해 두고 있었다** —
   WiFi 80 MHz **24.92 dB** · LTE 20 MHz **39.07 dB** · 5G 100 MHz **42.40 dB**.
   그런데 `microdoppler_nearfield.py` 는 링크버짓을 **처음부터 다시 짰다**(재구현 금지 규약을
   깬 유일한 자리). 두 팔은 각자 내부적으로 일관됐고, 둘을 잇는 게이트가 없었다.
2. **«5 m» 에 이미 그럴듯한 설명이 붙어 있었다.** EIRP 12 dBm 은 출처문서 없는 `[선언]` 값이다
   (16 mW). «송신이 이렇게 약하니 당연히 짧지» 로 읽히므로 **두 번째 원인을 찾을 이유가 없었다.**
   원인 둘이 같은 방향을 가리켰고, 그중 하나가 이야기를 갖고 있었다.
3. **함수 이름에 층위가 없었다.** `echo_over_noise_db()` 도 `add_noise()` 도 «어느 층의 SNR인가»
   를 말하지 않는다. 호출부는 한 줄(`add_noise(E, snr, rng)`)이라 층위 불일치가 **눈에 안 보인다.**
4. **챔버 서사가 반례를 막았다.** 마이크로도플러 팔은 통제 챔버 실험으로 짜여 있어 1~10 m 가
   설계 범위였다. 8/18 덱이 «40 m» 를 물을 때까지 «5 m» 는 아무것과도 모순되지 않았다.

## 3. ⚠새로 찾은 결함 둘 (이번 정정이 만들었다)

### D-1 ⭐`always_on_pilot` 팔이 **44~50 dB 비관적**이고, 없던 거짓 주장을 만든다
`matched_filter_gain_db(capture="always_on_pilot")` 이 **0 dB** 를 돌려준다. 그러면 상시
기준신호 팔의 SNR 이 `P_echo/(kT0F·B)` 로 남는데, 이건 물리적으로 아무 층도 아니다.
옳은 값은 반복 1회당 **실제 조명시간** τ_on 으로 `G = 10log10(B·τ_on)` 이다.

| 팔 | 지금 코드 | 옳은 값 | 차이 |
|---|---|---|---|
| LTE CRS 1 kHz (연속조명 τ=1 ms) | 0 dB | **+50.0 dB** | 50.0 |
| 5G SSB 50 Hz (버스트 τ=4×71.4 µs, 듀티 −18.45 dB) | 0 dB | **+44.6 dB** | 44.6 |

⚠ 그리고 이 0 dB 는 «상시 기준신호는 풀캡처보다 37 dB 손해» 라는 **틀린 문장을 만든다.**
   SNR 로는 오히려 **유리하다**(반복률이 낮을수록 표본당 적분시간이 길다).
   상시 기준신호의 진짜 대가는 **도플러 모호**(f_tip 1,229 Hz 가 PRF 1 kHz 에서 접힌다)와
   **듀티**다. `prf_feasibility` 가 이미 판정하는 그것이지 SNR 이 아니다.
⇒ **8/18 덱·리포트에 «상시 기준신호 −37 dB» 를 절대 쓰지 마라.**

### D-2 사다리에 **듀티 항이 없다**
`src/freespace_link.py::duty_db_from_cpi(M, T_ref, T_CPI)` 가 이미 있고, 이중계상을 막는
가드까지 달려 있다(`mode` 와 `duty_db` 를 동시에 주면 예외). 사다리에는 그 항이 없다.
측정값: LTE 연속 **0.00 dB** · 5G SSB 버스트 **−18.45 dB** · WiFi 1 kHz 패킷 **−10.00 dB**.
`capture="full_waveform"` 헤드라인은 듀티 0 이라 무해하지만, report12 의 9모드 점유 팔로
사다리를 옮기는 순간 틀린다.

## 4. 이중계상 — **활성 사슬에는 없다** (전수 확인)

⚠ 다만 **이름 충돌이 하나 살아 있다** — `g_stft_db` / `snr_map_ac_db` 가 두 원장에서 다른 값이다.

|---|---|---|---|

## 5. ⚠«37 dB» 짜리 수는 셋이 아니라 **다섯**이다

`snr_convention.json` 의 `do_not_confuse` 는 셋만 적는다. 실제로 원장에 도는 것은 다섯이다.

| 이름 | 값 | 어디 |
|---|---|---|
| ② 정합필터 이득 `10log10(B/PRF)` | **36.99 dB** | 사다리 |
| CPI 코히어런트 적분, 5000 표본 | 36.99 dB | 설계서 §0-2 예시 (**우연히 같다**) |
| CPI 코히어런트 적분, **6144 표본 Hann** | **36.12 dB** | `md_range_sweep_mf.json` 이 실제로 싣는 값 |
| CPI 코히어런트 적분, 2 s·19.7 kHz | 45.95 dB | 설계서 부록 A |
| ④ STFT 한 조각, 70 표본 Hann | **16.69 dB** | 맵에서 눈으로 보는 유일한 이득 |

⇒ `do_not_confuse` 에 뒤 둘을 **추가**하고, «CPI 이득은 단일 수가 아니라 기록 길이의 함수» 라고
  적어라. 안 그러면 이 정정이 고친 것과 **같은 종류의 사고**가 다시 난다.

## 6. ⭐실효 이득 — «37 dB» 는 상한이다

전부 우리 원장의 **측정값**이다(추정 아님).

| 항 | dB | 누계 | 출처 |
|---|---|---|---|
| 이상 정합필터·풀웨이브폼·기준신호 완전 | **+36.99** | 36.99 | 게이트 MF1–3 (오차 ≤ 0.11 dB) |
| 5G NR **파일럿만** 아는 기준채널(디코딩 안 함) | −5.49 | 31.50 | `verify_linkbudget` `pilot_power_frac_db` |
| 거리빈 straddle 최악 | −2.42 | 29.08 | 같은 원장 |
| 도플러빈 straddle 최악 | −1.50 | 27.58 | 같은 원장 |
| ECA 가 정합필터에서 깎는 몫 | −0.08 | **27.50** | 같은 원장 |

⇒ **실효 이득 ≈ 28 ~ 37 dB.** 사다리에 들어 있는 것은 **첫 줄 하나뿐**이다.
  거리로는 10^(9.5/40) = **×1.7 배** 폭이다. 리포트·덱은 이 폭을 띠로 그려야 한다.

### 기준채널 «절벽» 은 정합필터 손실이 **아니다** (반증 성공)
두 잡음채널 상호상관 이론은 손실 = `10log10(1 + 1/ρ_ref)` 를 준다 — ρ_ref = 20 dB 에서 **0.04 dB**.
그런데 `outputs/passive_two_channel.json` 실측은 같은 자리에서 **7.9 ~ 26.6 dB** 다. 두 자릿수 차이다.
그 원장 자신의 `mechanism.verdict` 가 답을 갖고 있다 — *«표적 피크는 안 움직이고 바닥만
올라간다»*. 즉 절벽은 **못 지운 직접파(DPI)** 이지 정합필터 이득 손실이 아니다.

⇒ 두 결론이 동시에 참이다.
  (a) 열잡음만 있는 마이크로도플러 팔에서 37 dB 는 이 절벽에 **안 깎인다**(직접파가 없다).
  (b) 직접파가 있는 실사슬로 옮기면 **ρ_ref ≥ 32.7 ~ 37.2 dB** 가 별도 입장료다(측정값).
  이 둘을 한 문장에 뭉치지 마라.

## 0. ⭐⭐ 방향과 순서 — 두 가지 상시 규칙

### 메인 태스크
```
❌ 메인 아님   드론 RCS 를 정밀하게 계산한다
✅ 메인       드론 탐지  +  마이크로도플러 패턴으로 분류
```
σ 는 **기여가 아니라 인프라**다. «우리가 σ 를 정확히 냈다» 를 논문 주장으로 쓰지 않는다.
값어치를 내는 축은 σ 의 절대 레벨이 아니라 **구조** — 자세에 따른 변동(ε)·가림·블레이드 변조.

### ⭐ 작업 순서 — 상류부터
층을 그리고 **아래층부터** 끝낸다. 상류가 틀린 채로 하류를 돌리면 버릴 결과에 계산을 태운다.
```
1층  물리 커널   재질 Γ · PO/SBR 산란식 · 전처리 체인
2층  메쉬        기하 · 겹침 · 재질 배정
3층  재계산      σ 격자 · 마이크로도플러 (GPU)
4층  서술        리포트 · 그림      ← ⭐물리와 병행 가능(빌더가 JSON 을 읽는다)
5층  발표물      덱 · 논문
```
⛔ 결함을 **발견한 시점에** 층을 다시 세우고 순서를 갈아엎는다.
