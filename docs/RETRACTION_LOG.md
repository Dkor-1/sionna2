## R1 ⭐ 무모호 속도식의 우선권 — **두 번 틀렸다**

| 시점 | 주장 | 실제 |
|---|---|---|
| 처음 | `v_max = λ·PRF/4` 는 **우리 발견** | ❌ |
| 1차 정정 | **Chen 2024** 가 같은 기호로 먼저 | ❌ **또 틀림** |
| **확정** | **Abratkiewicz 외, IEEE JSTARS 16:3469–3484 (2023), 게재, 식 (16) p.3476** | ✅ |

원문(직접 확인):
> *"The Doppler range is limited by T^SSB_dist so that **Vb ∈ [−λ/(4·T^SSB_dist), λ/(4·T^SSB_dist)]**"*

**반구간 규약까지 동일**하다. Chen 2024(Appl. Sci. 14(10):4282, 게재)는 **닫힌형 식이 없다** —
`PRF` 기호 0회, 바이스태틱 도플러 식 (4)와 수치 예시뿐이고 그마저 Samczynski TGRS 2021 인용이다.

⭐ **보상 발견 — 이게 R1 을 유리하게 만든다.** Abratkiewicz 결론 p.3482:
> *"The subsequent problem worth considering is **small target detection, for instance, drones whose
> reflectivity is significantly lower than the car** used in the experiment."*

그들 표적은 **Volvo XC90**(`car` 31회, `drone` 3회는 전부 향후과제 맥락, `UAV` 0회).
Chen 표적은 **스테퍼모터 회전 모형**. **두 논문 다 드론을 안 썼다.**

→ **우리 위치**: *"우리가 처음"* 이 아니라 **"식의 저자가 직접 열어둔 자리"**. 반박이 안 된다.

## R3 "5G 커버리지 = 0"

**단일 CPI 아티팩트.** CPI=100 ms **와** 선언 2.5빈 가드가 동시에 성립할 때만 참이다.
검출기의 실제 1.5빈 하드가드에서는 같은 CPI 에서 **0.636**, 200 ms 면 0.303.
⚠ **LTE 도 짧은 CPI 면 1.000 이 된다** — 전 헤딩 블라인드는 5G 의 성질이 아니라 짧은 CPI 의 성질이다.
⚠ 슬라이드에 쓸 때 **어느 가드 규약인지 반드시 명시**할 것(선언 2.5빈이면 LTE T_max=0.005 s,

### A8 ⭐ "+2.5068 dB 앵커 오프셋은 근거 없으니 끄라" — **그 지시가 틀렸다**

`src/sigma_anchor.py : LOG_TO_LIN_EXPONENTIAL_DB = 10/ln10 · γ = 2.5068 dB` 는
dB영역평균 `E[10log10 σ]` → 선형평균 `10log10 E[σ]` 변환 상수다(σ 가 지수분포 = Swerling I/II 일 때 **정확**).

**증거 — 직접 재실행**(`reconcile_das_yuan`, Das Table III Phantom 3 vs Yuan 고도풀링 선형평균):

| 분기 | 오프셋 | 우리 3밴드(1.843/3.5/5.21 GHz) 잔차 | 전대역(1.8~18.2) 잔차 |
|---|---|---|---|
| **`exponential`** | **+2.5068 dB** | **0.1161 ~ 0.2502 dB** ✅ | 0.4894 dB |
| `lognormal` | +3.1921 dB | 0.8013 ~ 0.9355 dB | 1.1773 dB |
| `none` (= 끄기) | 0.0000 dB | **2.2566 ~ 2.3908 dB** ❌ | 2.9963 dB |

두 논문은 **같은 원자료**이므로(A2) 잔차는 0 이어야 한다. 끄면 2.26~2.39 dB 어긋나고, 켜면 0.25 dB 안에 든다.

⭐ **물리도 같은 쪽을 가리킨다.** Das Table II 는 Phantom 3 최적적합을 **Rician** 으로 놓고(d_AD 0.436),
Yuan Fig.6(a) 축자: *"The K factors vary around −10 dB at some frequencies, while the others are
significantly lower, falling below −30 dB."* K ≤ −10 dB 인 Rician 은 레일리 진폭 = **지수 전력**이고,
그 자리가 바로 +2.5068 이 **근사가 아니라 정확**한 자리다.

**규칙(이게 A8 의 본체다):** 이 상수는 **분포 가정**이지 측정값이 아니다.
→ **두 분기를 언제나 함께 들고 다닌다**(`exponential` +2.5068 / `lognormal` +3.19~3.43).
→ **조용한 단일값 금지.** 끄는 것도 단일값이다(`none` 을 고른 것이고, 그게 제일 나쁘다).
→ ⭐ 그리고 **기울기로 이끈다** — 오프셋은 레벨 상수라 `dμ/df` 에서 **완전히 상쇄**된다.
   규약 논쟁이 안 닿는 자리가 기울기다.

## 재발 방지

1. **주장 전 원문** — 에이전트 보고를 그대로 옮기지 않는다. 파일명까지 틀린 적이 있다(R1 확인 중).
2. **인용 등급 3단** — `verbatim` / `reconstructed`(표·그림에서 옮김) / `unverified`.
   기계 검사기 `benchmark/verify_quotes_tool.py` 가 판정한다.
3. **숫자에 등급을 붙여 보고** — "직접 확인" / "인용문 있음" / "기계집계" / "방금 센 것".
   마지막 것은 **발견이 아니라 가설**로만 말한다.
4. ⚠ **기계집계는 인용을 계산과 구별하지 못한다.** wave 1 에서 12편 중 6편이 정정됐다 —
   **미독 논문에도 같은 오류율을 가정**한다.
