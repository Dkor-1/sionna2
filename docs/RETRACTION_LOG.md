## R1 ⭐ 무모호 속도식의 우선권 — **두 번 틀렸다**

### A8 ⭐ "+2.5068 dB 앵커 오프셋은 근거 없으니 끄라" — **그 지시가 틀렸다**

`src/sigma_anchor.py : LOG_TO_LIN_EXPONENTIAL_DB = 10/ln10 · γ = 2.5068 dB` 는
dB영역평균 `E[10log10 σ]` → 선형평균 `10log10 E[σ]` 변환 상수다(σ 가 지수분포 = Swerling I/II 일 때 **정확**).

**증거 — 직접 재실행**(`reconcile_das_yuan`, Das Table III Phantom 3 vs Yuan 고도풀링 선형평균):

| 분기 | 오프셋 | 우리 3밴드(1.843/3.5/5.21 GHz) 잔차 | 전대역(1.8~18.2) 잔차 |
|---|---|---|---|
| **`exponential`** | **+2.5068 dB** | **0.1161 ~ 0.2502 dB** ✅ | 0.4894 dB |
| `lognormal` | +3.1921 dB | 0.8013 ~ 0.9355 dB | 1.1773 dB |
| `none` (= 끄기) | 0.0000 dB | **2.2566 ~ 2.3908 dB** ❌ | 2.9963 dB |

두 논문은 **같은 원자료**이므로(A2) 잔차는 0 이어야 한다. 끄면 2.26~2.39 dB 어긋나고, 켜면 0.25 dB 안에 든다.

⭐ **물리도 같은 쪽을 가리킨다.** Das Table II 는 Phantom 3 최적적합을 **Rician** 으로 놓고(d_AD 0.436),
Yuan Fig.6(a) 축자: *"The K factors vary around −10 dB at some frequencies, while the others are
significantly lower, falling below −30 dB."* K ≤ −10 dB 인 Rician 은 레일리 진폭 = **지수 전력**이고,
그 자리가 바로 +2.5068 이 **근사가 아니라 정확**한 자리다.

**규칙(이게 A8 의 본체다):** 이 상수는 **분포 가정**이지 측정값이 아니다.
→ **두 분기를 언제나 함께 들고 다닌다**(`exponential` +2.5068 / `lognormal` +3.19~3.43).
→ **조용한 단일값 금지.** 끄는 것도 단일값이다(`none` 을 고른 것이고, 그게 제일 나쁘다).
→ ⭐ 그리고 **기울기로 이끈다** — 오프셋은 레벨 상수라 `dμ/df` 에서 **완전히 상쇄**된다.
   규약 논쟁이 안 닿는 자리가 기울기다.

   (37.2 → 32.8 로 줄 뿐 규약을 갈라야 하는 이유는 그대로다) **인용 수치는 갈아야 한다.**
⚠ mavic4pro 의 −31.9 dB 이동이 왜 났는지는 **모른다.** 같은 라운드에 메쉬·회전수 사양도
움직였으므로(형제 원장 `docs/MD_RANGE_SWEEP_CITATIONS.md` §0 이 9칸을 나란히 잰다)
정합필터 정정 하나로 귀속하면 안 된다.
⛔ 그러니 **dc_ac 는 기체 이름만 붙여 인용하지 않는다** — 원장 판·자세·주파수를 함께 적는다.

### R21 `ac_snr_db()` 가 총전력→AC 변환에서 `dc_ac_db` 를 그냥 뺐다

정확식은 `dc_ac_off_db = 10log10(1 + 10^(dc_ac_db/10))` 이다. 근사와의 차이는
`dc_ac ≥ 10 dB` 에서 ≤ 0.41 dB 로 무해하지만 **`dc_ac ≈ 0` 에서 3.01 dB** 다.
ECA 0-도플러 노치가 호버링 동체선을 지우면 실제로 그 영역에 들어간다.
⇒ 정확식을 `dc_ac_offset_db()` 로 넣었다. 기본값은 옛 동작 유지(원장 비트 보존, 게이트 SC2).

**원장이 싣는 표**(`verify_snr_convention.json` SC4, 정확−근사):

```
dc_ac  0.0 dB → 3.0103 dB      dc_ac  3.0 → 1.764349      dc_ac 10.0 → 0.413927
dc_ac 17.3     → 0.080126      dc_ac 26.5 → 0.009712      dc_ac 37.2 → 0.000827
```

### R22 ⭐ «상시 기준신호는 풀캡처보다 37 dB 손해» — **이번 정정이 만든 새 거짓**

`matched_filter_gain_db(capture="always_on_pilot")` 이 **0 dB** 를 돌려준다. 그 값을 그대로
읽으면 상시 기준신호 팔이 SNR 에서 37 dB 손해라는 문장이 나온다. **반대다.**

옳은 값은 반복 1회당 실제 조명시간 τ_on 으로 `G = 10log10(B·τ_on)` 이고, 반복률이 낮을수록
표본당 적분시간이 **길어서 유리**하다.

| 팔 | 코드 | 옳은 값 | 차이 |
|---|---|---|---|
| LTE CRS 1 kHz (연속, τ = 1 ms) | 0 dB | **+50.0 dB** | 50.0 |
| 5G SSB 50 Hz (버스트 τ = 4×71.4 µs, 듀티 −18.45 dB) | 0 dB | **+44.6 dB** | 44.6 |

상시 기준신호의 진짜 대가는 **도플러 모호**(f_tip 1,229 Hz 가 PRF 1 kHz 에서 접힌다)와
**듀티**이지 SNR 이 아니다. `prf_feasibility` 가 이미 그것을 판정한다.
⇒ 코드는 아직 **안 고쳤다.** 고치기 전까지 그 팔의 수치를 원장·리포트·덱에 싣지 않는다.

### 이 라운드가 **철회하지 않은 것** (정직성)

- **«37 dB 를 실제로 번다»** 는 여전히 미검증이다. 항별로는 다 쟀다 — 이상 정합필터 36.99 dB
  (게이트 오차 ≤ 0.11 dB), 5G 파일럿 기준채널 −5.49 dB, straddle 최악 −3.92 dB
  (`outputs/verify_linkbudget.json`) ⇒ **실효 28 ~ 37 dB**. 그러나 이것은 **항별 측정의 합**이지
  끝에서 끝까지 측정이 아니다. 사슬 게이트(G12)가 남았다.
- **기준채널 «절벽» 은 정합필터 손실이 아니다** — 두 잡음채널 상호상관 이론은 ρ_ref = 20 dB 에서
  손실 0.04 dB 를 주는데 `outputs/passive_two_channel.json` 실측은 7.9 ~ 26.6 dB 다.
  그 원장 자신의 `mechanism.verdict`(*표적 피크는 안 움직이고 바닥만 올라간다*)가 답이다 —
  **못 지운 직접파(DPI)** 다. 열잡음만 있는 마이크로도플러 팔에서는 이 절벽이 안 걸리고,
  직접파가 있는 실사슬에서는 **ρ_ref ≥ 32.7 ~ 37.2 dB** 가 별도 입장료다. 두 문장을 뭉치지 마라.

### R27 «PathSolver 의 시드 잡음이 CNN 에 공짜 데이터 증강» — **철회**

사용자 반박: *"환경에 잡음 모델링을 하면 결국 장점은 아니지 않나?"* — 맞다.

- 우리가 **세기를 지정할 수 없는** 잡음이다. 손잡이가 아니면 축이 못 된다.
- **분포가 다르다** — 수신기 열잡음이 아니라 유한 표본의 추정 분산이다.
- ⭐ **거리에 따라 안 커진다.** 진짜 잡음은 멀수록 신호를 묻는데 이건 그 법칙을 안 따른다.
- 수신기 잡음과 겹치면 **성능 하락을 어느 쪽에 붙일지 못 가른다.**
- ⭐ 그리고 R23 이 이것을 물리로도 막는다 — 그 변동은 i.i.d. 가 아니라 **계통 편향**이다.
  계통 편향을 증강으로 쓰면 모델이 **시드를 학습**한다.

### R28 ⭐⭐ 구면파 마이크로도플러의 **도플러 부호가 뒤집혀 있었다** (코드 결함, 고침)

`sbr_field(..., range_m=R)` 의 구면파 위상이 **거리**에 `+j` 를 걸고 있었다.

```
평면파(옳음)   exp(+j2k (P−ctr)·û)        ← 투영.  다가오면 커진다 ⇒ 위상 ↑ ⇒ ⊕ 도플러
구면파(결함)   exp(+j2k (|P−p_tx| − R))   ← 거리.  다가오면 줄어든다 ⇒ 위상 ↓ ⇒ ⊖ 도플러
구면파(정정)   exp(+j2k (R − |P−p_tx|))
```

원거리장 극한에서 `(|P−p_tx| − R) → −(P−ctr)·û` 이므로 두 갈래는 **정확히 −1 배**였다
(수치 잔차 8.9e−16 m). ⇒ `range_m` 을 주는 순간 도플러 부호가 뒤집혔다.

**어느 쪽이 옳은지** — 표준 규약 `exp(−j2πf τ)`, `τ = 2R/c`, `R = R₀ − P·û` 를 전개하면
`exp(−j2kR₀)·exp(+j2k P·û)` 이므로 **투영에 대한 `+j` 가 옳다**. 답을 아는 문제로 확정했다
(5 m/s 로 다가오는 산란체, 참값 `f_d = +116.75 Hz`):

| 식 | 잰 값 | |
|---|---|---|
| 평면파 `exp(+j2k P·û)` | **+117.19 Hz** | ✓ |
| 구면파 `exp(+j2k(\|P−p_tx\|−R))` | **−117.19 Hz** | ✗ 결함 |
| 정정판 `exp(+j2k(R−\|P−p_tx\|))` | **+117.19 Hz** | ✓ 표준과 `\|ρ\| = 1.000000` |

**게이트 3/3 PASS** — `benchmark/verify_phase_sign.py` → `outputs/verify_phase_sign.json`

| G | 무엇 | 값 |
|---|---|---|
| G1 | `\|E\|` 불변(정정 = 켤레) | `max_rel_diff = 0.0` |
| G2 | ⭐원거리장에서 구면파 → 평면파 | `range_m = 5000` 에서 **ρ_real = +0.99999974** (고치기 전이면 −1 근처) |
| G3 | 접근 = 양의 도플러 | 우리 `+117.19` = 표준 `+117.19` |
