## 0. 규약의 출처 — 사용자 지적이 맞다

«편당 셀 25개 · 셀당 12줄 · 편당 그림 8장» 과 «6편 골격은 유지» 는 사용자가 만든 규칙이 아니다.
2026-07-30 «13편 → 6편» 재편 때 우리가 넣었다 — `src/report_style.py:154`, 계약은
`docs/REBUILD_2026-07-30.md` §5.7.

그 조항은 자기 안에서 모순됐다. 앞은 *"넘치면 내용을 줄이지 말고 편을 쪼개라"* 이고
뒤 괄호는 *"다만 6편 골격은 유지"* 다. 쪼개라고 해 놓고 6편으로 묶으면 남는 수는 **합치기**뿐이다.
그 자국이 측정된다 — 한 셀에 §제목이 둘 이상인 `compound_cell` **11건**, 12줄 검사를 통과하면서
화면에서는 벽인 셀 **105/170개**.

**이 문서는 그 두 조항을 다 버린다.**

## 1. 새 편성 — 70편 · 12부

### 원리

| | |
|---|---|
| **한 편 = 한 중심 메시지** | 메시지가 둘이면 편을 쪼갠다. 편 수는 세지 않는다 |
| **편 제목이 곧 그 문장** | 제목만 읽어도 결론이 보인다. 물음표로 끝나는 제목 금지 |
| **첫 줄은 «이 편의 한 문장»** | 그 아래 «근거» 한 줄(JSON 목록), 그 아래 근거 셀 |
| **편 크기는 읽는 시간으로** | 본문(출처 태그 제외) 800~3,000자 = 2~6분 |

`01` → `04` → `05` → `21` → `22` → `25` → `26` → `27` → `28` → `32` → `35` → `46` → `47` → `54` → `69`

리포트를 읽지 않는다. `docs/REPRODUCE.md` 의 «편 번호 → 명령 → 출력 JSON → 소요시간» 표 하나면 끝난다.

### ⚠ 추적 가능성은 잃지 않는다 — 네 겹

옮기는 것이지 버리는 것이 아니다. 「이 편의 근거 파일이 무엇인가」를 한 번에 찾는 길을 넷 둔다.

1. **편 머리 «근거» 한 줄** — `근거: meshfix_applied.json · sbr_kr_sweep.json → REPRODUCE.md#21`.
   이건 리포트에 남는다.
2. **편 끝 «출처» 표** — 각주 번호 ↔ 파일 ↔ 키 ↔ 값. `num()` 이 **쓴 순서로 자동 생성**한다

3. **`outputs/reports_index.json`** — 기계 판독 색인. 편 번호로 근거 JSON·각주·앵커·그림·명령을 한 번에 준다.

4. **역방향** — 논문 조각마다 `<!-- from: 편 NN · anchor -->` 를 박는다.

그리고 검증 자체는 1비트도 안 약해진다. `num()` 은 태그를 **찍기 전에** JSON 을 열어 값을 대조하고

### 출처 태그 — 여섯 안 중 왜 각주인가

진단이 낸 6안(각주 A / 절끝표 B / 접기 C / 약칭 D / 재인용제거 E / 별색 F) 중
**A(각주) + E(재인용은 같은 번호)** 를 고르고, **표 안은 B**(칸에서 빼고 표 바로 밑 «출처» 줄)로 간다.

- **왜 A** — 절감이 가장 크고, 숫자↔출처 짝이 번호로 남아 재감사가 되며, 렌더러에 기대지 않는다(그냥 글자와 표다).
- **왜 표 안은 B** — 태그 1,421개 중 **692개가 표 칸 안**에 있고, 표 칸이 문단이 되는 원인 중 하나가 그 태그다.
- **왜 C(접기)를 안 골랐나** — 취향이 아니라 렌더러 위험이다. `<details>` 는 nbconvert · GitHub ·
  VSCode · JupyterLab 이 다 같게 그리지 않고, PDF 로 뽑으면 통째로 사라지거나 통째로 펼쳐진다.
  우리 리포트가 PDF·GitHub 로 넘어간다는 전제가 **틀렸다면 C 가 A 보다 낫다.**

**받아들이는 손실 두 가지.** ① 각주는 «숫자를 보는 순간 출처가 보인다» 는 지금의 최대 장점을
한 눈금 깎는다. 편이 1,400자로 짧아져 각주 표가 같은 화면에 들어오면 그 손실이 작아진다.
② 번호 관리가 **새 실패 지점**이다 — 번호가 밀리면 출처가 어긋나는데 지금 구조에는 그런 실패 모드가 없다.
그래서 각주 표는 `num()` 이 쓴 순서로 자동 생성해야 하고, 라운드트립 검사(각주 표의 값 = JSON 값)를 같이 넣는다.
