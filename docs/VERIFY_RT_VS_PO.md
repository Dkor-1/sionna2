# 검증 리포트 — Sionna RT 는 표적 RCS 를 모델링하지 않는다

*2026-07-14 · 대상: 본 프로젝트 · 재현: `benchmark/verify_rt_no_rcs.py`*

---

## 1. 요약 (결론부터)

**Sionna RT(2.0.1) 의 path solver 에는 표적의 RCS(σ) 를 담는 자리가 없다.** RT 가 표적에서 만드는 경로는 두 종류뿐이고 **둘 다 σ 의 함수가 아니다**:

| 채널 | 진폭 법칙 | σ 의존성 | 실측 |
|---|---|---|---|
| **SPECULAR** | image-source(무한거울), 1/(R₁+R₂) 확산 | **없음** | 금속 평판의 변을 0.2 → 4 m 로 키워 **σ 를 52 dB** 바꿔도 진폭비는 **−7.91 dB 로 불변**(산포 0.00 dB). 이론 image-source 값 −7.88 dB 와 일치 |
| **DIFFUSE** | √(f_s·Ω)·γ — 산란계수 **S** 의 함수 | **없음** | 같은 금속구에서 S 만 0.2 → 1.0 으로 올리면 진폭비가 **+15.8 dB** 이동(S² 법칙 예측 +14.0 dB) |

게다가 **물리적으로 옳은 설정(PEC 금속, S=0)에서는 RT 가 구의 경로를 단 하나도 만들지 못한다** — 반지름 0.3/1/3 m, spp 100만~1600만, 어떤 조합에서도 표적 경로 0개.

> **그러므로 "표적 = PO, 환경 = RT" 하이브리드는 기본 solver 를 쓰는 한 필연이다**(정공법의 부재가 아니라 비용의 문제 — §6·§7-10).
> 다만 정당화의 근거는 *"표준 관행이라서"* 가 **아니라**, *"Sionna RT 에 산란적분(PO) 단계가 없어 σ 가 창발하지 않기 때문"* 이다.
> 검증축은 **RT ↔ PO 대조가 아니라** **PO ↔ 해석해** 및 **PO ↔ 실측 앵커링** 으로 가야 한다.

## 2. 왜 이 검증을 했나

> *"Sionna 시뮬레이션이 목적인데 표적 RCS·에코를 PO 로 계산해 넣으면, 그걸 'Sionna 로 검증했다'고 할 수 있는가?"*

정당한 지적이었다. 가능한 답은 셋이었고 —

1. RT 로도 표적 에코가 나오고 PO 와 일치한다 → PO 는 지름길, 하이브리드는 검증됨.
2. RT 로 나오지만 PO 와 다르다 → 둘 중 하나가 틀렸다.
3. **Sionna RT 의 기본 path solver 에는 산란적분(PO) 단계가 없어 표적 RCS 가 창발하지 않는다** (SBR 계열 RCS 솔버는 창발시킨다 — §6 참조) → 기본 solver 를 쓰는 한 하이브리드는 **필수**이고, 검증은 다른 축에서 해야 한다.

증상은 2번처럼 보였다(드론 RT 에코가 PO 대비 −5 ~ −40 dB 로 시드마다 요동). **결론은 3번이었다.**

## 3. 실험 설계

**비교량 — 직접파 대비 표적에코 진폭비.** 절대 보정(안테나 이득·송신전력)과 무관해 두 엔진을 공정하게 맞댈 수 있다.

- RT: `a_echo / a_dir` — 단, 표적 에코는 **지연 게이트**로 고른다(|τ − (R₁+R₂)/c| < 3 ns).
- PO+링크버짓: `ratio = L·√(σ/4π) / (R₁·R₂)` (바이스태틱 레이더방정식)

**기하** (`src/bistatic_scene.py`, 30×20×11 m 챔버): L = 15.075 m, R₁ = 18.748 m, R₂ = 18.608 m, β = 47.6°, f_c = 3.5 GHz
→ 표적에코 기대지연 **τ = 124.61 ns**, LOS **τ = 50.28 ns**.

> ⚠️ **초기 설계의 실수를 먼저 밝힌다.** 교정 표적으로 금속구를 고르며 *"구는 어떤 각에서도 정반사점이 존재하니 RT 에 가장 유리하다"* 고 가정했는데, **SBR 솔버 기준으로는 정확히 반대**다. 구는 RT 에 **가장 불리한** 표적이다(§5). 이 오해가 진단을 한참 지연시켰다.

## 4. 결과 (`benchmark/verify_rt_no_rcs.py` 로 재현)

### [A] 정반사는 표적 크기와 무관하다 — RCS 정보가 0

이등분선에 법선을 맞춘 금속 평판(정반사 조건 충족), spp = 1M:

| 평판 변 | 이론 σ (4πA²/λ²) | RT 진폭비 | 경로수 | τ |
|---|---|---|---|---|
| 0.2 m | +4.4 dBsm | **−7.91 dB** | 1 | 124.61 ns |
| 0.5 m | +20.3 | **−7.91** | 1 | 124.61 |
| 1.0 m | +32.3 | **−7.91** | 1 | 124.61 |
| 2.0 m | +44.4 | **−7.91** | 1 | 124.61 |
| 4.0 m | +56.4 | **−7.91** | 1 | 124.61 |

**σ 가 52 dB 변하는 동안 진폭비 산포 = 0.00 dB.** image-source 예측 20·log₁₀(L/(R₁+R₂)) = **−7.88 dB** 와 일치한다.
→ Sionna 의 정반사 필드는 **무한평면 거울장**이다(곡률·발산인자·유한개구 보정 없음). **정반사 경로가 잡혀도 RCS 정보는 0이다.**

### [B] 확산은 σ 가 아니라 산란계수 S 를 측정한다

같은 금속구(r=0.3 m, 이론 σ=πr²=−5.49 dBsm → 이론 진폭비 **−43.77 dB**)에 S 만 바꿔서:

| 산란계수 S | RT 진폭비 | 이론 대비 | 표적경로수 |
|---|---|---|---|
| 0.2 | −56.56 dB | −12.79 dB | 6 |
| 0.5 | −46.75 | −2.99 | 55 |
| 0.9 | −41.72 | +2.04 | 174 |
| 1.0 | −40.80 | **+2.97** | 212 |

**S 만으로 +15.8 dB 이동** (S² 법칙 예측 +14.0 dB — 차이는 S=0.2 에서 살아남는 경로가 6개뿐이라 생기는 MC 잡음).
이론값에 맞추려면 **S ≈ 0.85** 가 필요하다 → **RT diffuse 로 PO 와 숫자를 맞추는 것은 S 를 피팅하는 순환논법이다.**

### [C] 물리적으로 옳은 금속구(PEC) — 경로가 아예 0개

| 반지름 | spp | 표적 경로수 | interaction 히스토그램 |
|---|---|---|---|
| 0.3 m | 1M / 16M | **0 / 0** | {NONE: 1} (LOS 하나뿐) |
| 1.0 m | 1M / 16M | **0 / 0** | {NONE: 1} |
| 3.0 m | 1M / 16M | **0 / 0** | {NONE: 1} |

크기·표본수를 올려도 0. **그러나 같은 위치의 평판은 spp=1M 으로도 즉시 잡힌다([A]).**
→ 메쉬·재질·솔버는 **정상**이다(LOS 이득도 λ/(4πL) 이론과 일치). 판별 변수는 **크기가 아니라 곡률**이다.

### [D] 드론에서의 RT 산포 (참고 — `benchmark/verify_target_rt.py`)

mavic4pro, PO 예측 −64.87 dB. 순수 1-bounce + 지연게이트:

- spp 4M: −83.47 dB (2/4 시행은 **경로 0개**)
- spp 16M: −105.17 / −76.46 / −100.00 / −89.49 dB → **산포 ≈ 29 dB**
- 잡히는 표적 경로는 **전부 DIFFUSE** → §B 에 따라 이 숫자는 우리가 고른 S(플라스틱 0.2 / 카본 0.3)의 함수이지 드론 RCS 의 측정값이 아니다.

> ⚠️ **초기 보고의 "챔버에서 PO 대비 −5 dB 일치"는 허수였다.** 그 9개 '표적경로' 중 순수 1-bounce 는 τ=124.1 ns 짜리 **1개뿐**이고, 나머지 8개는 드론+벽 **다중반사**(τ = 182~223 ns)였다. `echo_radius=2 m` 규약이 "정점 하나라도 표적 근처면 에코"로 받아 생긴 오분류다.

## 5. 원인 규명

**(1) ITU metal 의 `scattering_coefficient = 0.0`** (`itu_material.py` 기본값). 따라서 `diffuse_reflection=True` 를 켜도 금속 표적에선 **확산 채널이 원천적으로 비어 있다** — 정반사만 가능하다.

**(2) SBR + image-method 가 곡면의 정반사점을 잡지 못한다.** 곡면을 삼각형으로 쪼개면 어떤 패싯도 자기 평면의 정반사점을 자기 삼각형 안에 품지 못한다(**디스코볼 문제**). 세분해도 면법선 격자 간격과 면 크기가 함께 줄어 비율이 그대로다.

이 둘이 겹쳐 **금속구 = 완전한 null** 이 된다.

> ⚠️ **"곡면에서 정반사는 원리적으로 불가능"이라고까지 말하면 안 된다.** 적대적 검증에서 반례가 나왔다 — 메쉬 자세를 무작위로 돌리면 유효 삼각형이 존재하는 자세가 수 % 확률로 나타나고, 그런 자세에선 Sionna 도 정반사 경로를 만든다. 다만 **잡혀도 진폭은 틀린다**(단일 패싯이 '평판'으로 반사 → 구 이론 대비 +15 dB). 정확한 표현은 **"저확률 + 잡혀도 진폭 무의미"** 다.

**(3) 더 근본적으로 — Sionna RT 의 path solver 에 산란적분 단계가 없다.** SBR 로 RCS 를 계산하려면 **산란적분(PO) 단계**가 필요한데 Sionna RT 에는 그 단계가 없다. Sionna RT 2.0.1 패키지 전체에서 `rcs|radar_cross` grep → **0 hits**, 공개 심볼 161개 중 radar/sensing/RCS **0개**, 공식 튜토리얼에도 **0개**. 메인테이너(J. Hoydis)도 Discussion #844 에서 RCS 는 *"not supported out of the box"* 라고 답했다 — 다만 그는 곧이어 **직접 구현할 수 있다**고도 했다(§7-10).
> ⚠ 2026-07-21 실측 정정: 그 '직접 구현'을 **custom PathSolver** 로 적었던 것은 틀렸다 —
> sionna-rt 2.0.1 에서 `PathSolver.__mro__ == (PathSolver, object)` 로 **subclass 확장점이 아니다**.
> 공식 확장점은 **커스텀 산란패턴/재질**(`ScatteringPattern`·`RadioMaterialBase` 추상베이스)이고,
> RCS solver 는 **노출된 Mitsuba 광선엔진 위에 직접** 얹는다(우리 `src/rcs_sbr.py` 가 그 길).

## 6. 판정

### 하이브리드(표적=PO, 환경=RT)는 정당한가 — **그렇다. 단, 이유를 정확히 말해야 한다.**

정당한 이유: **Sionna RT 의 path solver 에 산란적분 단계가 없어 표적 σ 가 창발하지 않기 때문.** 우리 설정 실수나 튜닝 부족이 아니라 **도구의 설계 범위**다.

**정당화에 쓰면 안 되는 근거** (적대적 검증에서 깨진 것들):

- ❌ *"3GPP 가 지지하는 표준 관행"* — 범주오류. 3GPP ISAC 의 RCS 파라미터화는 **통계적 채널모델(GSCM) 안**의 이야기다. "결정론적 RT 환경 + 외부 결정론적 PO σ 주입" 하이브리드를 3GPP 가 표준화한 바 없다.
- ❌ *"RCS 는 레이트레이싱에서 창발하지 않는다"* — 거짓. **SBR(GO+PO)는 기하에서 RCS 를 계산해낸다.** 참인 명제는 훨씬 좁다: **"산란적분 단계가 없는 전파용 레이트레이서(Sionna RT 포함)에서는 창발하지 않는다."**
- ❌ *"정공법이 아예 없다"* — in-Sionna 경로가 존재한다: **커스텀 산란패턴/재질**(공식 확장점) + **노출된 Mitsuba 광선엔진** 위의 자작 적분. 우리가 그 위에서 SBR+PO 를 돌린다. (⚠ `PathSolver` subclassing 은 그 경로가 아니다 — 위 정정 참고.)

### 유효 조건

1. **표적 산란 = PO(외부), 환경 산란(벽·바닥·다중경로) = RT.** (`benchmark/channel.py` 의 `target_amp='po'` 기본값 — 이미 옳게 돼 있다)
2. **RT 의 표적 근방 경로를 절대 진폭 소스로 쓰지 않는다.** 지연·도플러·기하는 RT 가 정확히 준다(τ=124.6 ns 확인). **진폭만 PO 로 대체한다.**
3. **PO 의 유효 조건**: 볼록·전기적 대형·단일 반사 지배. 드론은 오목부(로터 아래·짐벌)가 있어 자기차폐·다중반사 오차가 남는다.

### 남은 리스크 (정직하게)

| 리스크 | 상태 |
|---|---|
| **PO 의 절대 RCS 불확실도** | **모른다.** 기존 문서의 ±3 dB 는 유도가 깨졌다 — 재유도 전까지 인용 금지 |
| PO 점간격 λ/7 의 계통 과소평가 | −0.12 ~ −0.28 dB (λ/30 대비). 소폭이지만 알려진 편향 |
| 널(null) **깊이** | **인용 불가** — 이산화 의존(λ/7 −95.8 → λ/28 −55.4 dBsm). 널은 **위치만** 인용할 것 |
| 챔버 RT 경로예산 절단 | `max_num_paths_per_src` 기본 1M 에 챔버 총경로수가 점근 중(98만) — **확인 필요** |
| 드론 오목부 다중반사 | PO 가 원리적으로 못 다룸 (알려진 모델 한계) |

**리포트 수치에 대한 파급은 없다.** report4 의 표적 에코는 합성값이고, `benchmark/channel.py` 는 `target_amp='po'` 가 기본이다. **재검토해야 할 "RT 기반 표적 수치"는 저장소에 존재하지 않는다.**

## 7. 권고

**즉시 (이 커밋에 포함)**
1. ✅ `benchmark/verify_rt_no_rcs.py` 신설 — 핵심 3실험을 저장소에 고정(그전엔 근거가 스크래치에만 있어 재현 불가였다).
2. ✅ `verify_target_rt.py` 의 잘못된 전제("구는 RT 에 유리") 정정 + β 출력 버그(`np.degrees` 이중적용 → 2727°) 수정.
3. ✅ `rcs_po.py` 의 널 깊이 수치 삭제(위치만 인용), **평판 검증을 근거 목록에서 강등** — 평판은 el=90° 에서 P·û ≡ 0 이라 커널이 무엇을 하든 σ=4πA²/λ² 가 나오는 **진단력 0의 항등식**이다. 대신 **구 ↔ 해석적 PO(±0.015 dB)** 를 헤드라인 근거로 승격.

**단기**
4. PO 점간격 기본값을 λ/7 → λ/15 로 올릴지 결정(−0.28 dB 계통오차 제거 vs 전 그림 재생성 비용).
5. ~~**PO 절대 불확실도를 재유도.** 자기차폐를 켤 때 불투명 depth-buffer 를 내부 산란체에 적용하면 안 된다~~
   → **2026-07-21 완료.** 유전체 셸을 τ=1−|Γ|² 로 투과시켜 내부 금속을 살린다(`penetrate=True`). 아래는 당시 서술:
   원문: 자기차폐를 켤 때 **불투명 depth-buffer 를 내부 산란체에 적용하면 안 된다**(재질 모델이 셸을 반투명으로 가정하는데 불투명 버퍼가 지배 산란체를 지운다).
6. `max_num_paths_per_src` 를 5e6 으로 올려 챔버 결과가 바뀌는지 1회 확인.

**중기 (선택)**
7. **노출된 Mitsuba 광선엔진 위의 in-Sionna RCS**(= 우리 SBR+PO)(TX=RX, 1-bounce 경로에서 σ = 4πr²·|E_s|²/|E_i|² 추출)를 시도할지 결정. **하이브리드가 이미 물리적으로 정당하므로 급하지 않다.**
