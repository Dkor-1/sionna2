# 검증 리포트 — 챔버 바닥: 클러터는 죽은 파라미터였고, 진짜 위협은 유령이다

*2026-07-14 · 재현: `benchmark/verify_floor_ghost.py` → `outputs/floor_ghost_verify.json`*

---

## 1. 요약 (결론부터)

report1~5 는 챔버를 **anechoic(무반사)** 이라 부르고, *"흡수체 덕에 클러터가 약하다"* 를 전제로 삼았다.
세 가지가 동시에 틀렸다.

| # | 발견 | 상태 |
|---|---|---|
| 1 | 챔버는 anechoic 이 아니라 **semi-anechoic** 이다 — 흡수체는 벽 4면 + 천장뿐, **바닥은 반사성 콘크리트**다 | **확정** (코드가 그렇게 돼 있다) |
| 2 | 그래서 정적 바닥 반사가 실재하고, **Sionna RT 는 이미 그걸 보고 있었다**. 우리 가정은 **16.2 dB 과소** | **확정** (RT 실측 ↔ 닫힌형 유도 −0.02 dB 일치) |
| 3 | 그런데 **그게 어떤 수치도 안 바꿨다** — ECA + 0-도플러 마스킹이 정적 클러터를 삼중 차단한다. `CH_CLUTTER_RATIO` 는 **죽은 파라미터** | **확정** (진폭 40 dB 스윕 → SCR 1.5e-9 dB 변동) |
| 4 | **진짜 위협은 표적 경유 바닥 유령**. 도플러가 실려 ECA 를 통과하고, **5G 에선 100% 가짜 표적으로 검출**된다 | **확정** (CFAR 실행) |

> **한 줄로**: 우리는 클러터를 **틀리게 모델링**했지만, 그 모델이 애초에 **아무것도 결정하지 못하는 자리**에 있었기
> 때문에 아무도 못 알아챘다. 그리고 정말로 결정하는 것(유령)은 **모델에 아예 없었다.**

## 2. 왜 이 검증을 했나

발표자료 리뷰에서 *"챔버를 anechoic 이라 부르는데 바닥이 반사면이면 semi-anechoic 이 맞다"* 는 용어 지적이 나왔다.
용어만 고치면 되는 오타처럼 보였다. **아니었다.** 바닥이 반사면이라는 사실을 끝까지 따라가 보니, 우리 클러터
모델 전체가 검증 불가능한 상태였다는 게 드러났다.

## 3. [A] 바닥은 실재한다 — 그리고 RT 는 처음부터 보고 있었다

**기하** (`src/bistatic_scene.py`): TX (4, 2.5, 8.0), RX (4, 17.5, 6.5) — 같은 벽에서 y 로 15 m 벌어짐.

거울상법으로 TX→바닥→RX 를 펴면:

| 항목 | 값 |
|---|---|
| 직접파 | 15.07 m |
| 바닥 경유 | 20.86 m |
| **여분 지연** | **19.3 ns** |
| 바닥 입사각 | 46.0° (법선 기준) — **스침각이 전혀 아니다** |
| 프레넬 (ITU 콘크리트 ε_r=5.24, **V편파 → 입사면 평행 = TM**) | \|Γ\| = 0.255 |
| 확산손실 (15.07/20.86) | −2.8 dB |
| **직접파 대비** | **−14.7 dB** |

**Sionna RT 가 report5 §D 에서 이미 실측해 둔 챔버 클러터 탭** (`outputs/report5_results.json`):

```
13.0 ns  −9.8 dB      6.5 ns  −14.6 dB     17.7 ns  −17.6 dB
19.3 ns  −11.6 dB    19.3 ns  −14.7 dB     20.6 ns  −19.4 dB
14.9 ns  −17.2 dB                          25.8 ns  −20.1 dB
```

**19.3 ns 에서 −14.7 dB** — 닫힌형 예측과 **지연 0.0 ns, 진폭 −0.02 dB** 로 일치한다. 바닥이다.

> ⚠️ **모르는 것은 모른다고 적는다**: RT 는 19.3 ns 에 경로를 **두 개**(−11.6, −14.7 dB) 찾았다. 우리 예측과 맞는 건
> 하나뿐이고, **나머지 하나가 무엇인지는 확인하지 않았다.** 바닥 타일이 밝은/어두운 두 SceneObject 로 쪼개져 있어
> (`chamber.py` floor_light/floor_dark) 반사점 근처에서 경로가 둘로 잡혔을 가능성이 있지만 **검증하지 않았다.**
> 아래 결론에는 영향이 없다.

**우리 가정 vs 실제**:

| | 최강 탭 |
|---|---|
| `CH_CLUTTER_RATIO` (가정) | **−26.0 dB** |
| Sionna RT (실측) | **−9.8 dB** |
| | **16.2 dB 과소가정** |

`geometry.py` 의 원래 주석은 이 −26 dB 를 *"흡수체 불완전·**바닥**/장비 반사"* 로 정당화했다. 바닥을
−26 dB 짜리 잔향에 묶어둔 것이다. 실제 바닥은 −14.7 dB 다.

## 4. [B] 그런데 왜 아무 수치도 안 틀렸나 — 클러터는 죽은 파라미터다

16 dB 를 과소가정했는데 report4/report5 의 Pd·SCR 은 왜 멀쩡한가? **클러터 진폭을 직접 스윕했다:**

| 정적 클러터 최강 탭 | SCR [dB] | Pd |
|---|---|---|
| 없음 | 45.637073024088 | 1.00 |
| −26.02 dB (기본값) | 45.637073024099 | 1.00 |
| −6.02 dB | 45.637073024195 | 1.00 |
| **+13.98 dB — 직접파보다 강함!** | 45.637073025153 | 1.00 |

**직접파보다 14 dB 센 클러터를 넣어도 SCR 이 1.06e-9 dB 움직인다.** 물리가 아니라 **구조**다. 정적 클러터는
**삼중으로 차단**돼 있다:

1. **ECA 사영** — `make_cpi` 의 클러터는 `camp * delayed(1.0, ctau)`, 즉 **도플러 항이 없는** 지연된 기준신호의
   선형결합이다. ECA 의 기저가 정확히 그 '지연된 기준신호들'이므로, 사영이 **진폭과 무관하게 정확히 0** 으로 지운다.
   사영은 진폭을 보지 않는다.
2. **잔류는 0-도플러에 앉는다** — 파일럿 부분공간 밖의 데이터 성분 잔류조차 f_d = 0 행에 남는다.
3. **그 행이 삭제된다** — `run_min_cell.py`: `det[zd, :] = False` (0-도플러 능선 행을 CFAR 히트에서 제외).
   SCR 프로브도 표적 셀(f_d ≠ 0)에서 재므로 건드리지 않는다.

### 이것이 무너뜨리는 것

**report5 §D 의 결론이 공허해진다.** 그 섹션은 같은 셀을 `AnalyticChannel` ↔ `SionnaRTChannel` 로 스왑해
*"Pd 100% vs 100%, SCR 36.4 vs 36.4 dB — 두 백엔드가 일치하므로 이후 대규모 스윕은 빠른 Analytic 으로"* 라고 결론냈다.
두 SCR 은 유효숫자 12자리까지 같았다. 그건 **검증이 아니라 항등식**이다 — **어떤 클러터 모델을 넣어도 일치할 수밖에
없었다.** (기하·직접파·표적 경로에 대한 교차검증으로서는 여전히 유효하다. **클러터에 관해서만** 공허하다.)

그리고 report5 본문은 자기가 출력한 숫자와 모순됐다:

> *"흡수체 챔버 RT: 잔향 8개 실측 (직접파 대비 **−10dB, −12dB, −15dB** …) — Analytic 의 가정(**−26/−29/−34 dB**)과
> **같은 자리수의 약한 잔향**. 무반사 챔버 전제(클러터 약함, DPI 지배) 유지."*

같은 줄에 −10 dB 와 −26 dB 를 나란히 찍고 "같은 자리수"라고 썼다. 16 dB(전력 40배) 차이다.

### 그래서 CH_CLUTTER_RATIO 를 고쳤나? — **아니다. 일부러 그대로 뒀다.**

RT 실측값에 맞춰 고치면 물리적으로는 정직해지지만 **수치는 하나도 안 바뀌고**, 대신 *"우리가 클러터를 제대로
모델링했다"* 는 **잘못된 인상만** 준다. 정직한 모델링은 둘 중 하나다:
(a) ECA 에 **유한 동적범위/클러터 도플러퍼짐**을 넣거나, (b) **유령을 켜거나**(§5).

> ⚠️ **오해 금지**: "정적 클러터는 무해하다"가 아니다. **이 모델이 그걸 검증할 능력이 없다**는 뜻이다.
> 실제 ECA 는 유한 ADC 동적범위·클러터 도플러퍼짐·양자화 때문에 이렇게 완벽하지 않다. 그 한계는 **아직 모델에 없다.**

## 5. [C][D] 진짜 위협 — 표적 경유 바닥 유령

**TX → 표적 → 바닥 → RX.** 이 경로는 **표적을 거치므로 표적과 함께 도플러가 실린다.** 정적 클러터와 달리
**ECA 의 영공간 밖**이고, 0-도플러 행도 아니다. **지워지지 않고 CFAR 에 그대로 노출된다.**

`geometry.floor_ghost()` 가 거울상 + 프레넬로 (지연, 도플러, 진폭)을 닫힌형으로 준다. 표적이 quiet zone
중앙(21, 10, 5.5)에 있을 때:

- 바닥 입사각 **57.0°**, \|Γ\|_TM ≈ 0.15
- 진짜 표적보다 **바이스태틱 거리 +3.53 m** 뒤
- 진짜 에코 대비 **−18.1 dB**
- 도플러는 진짜와 **7.2 Hz** 다르다 (거울상 RX 기준 기하가 다르므로)

### 대역폭이 유령의 운명을 가른다

유령을 실제로 주입하고 ECA → 거리-도플러 → CA-CFAR 를 돌렸다 (`run_cell(floor_ghost_on=True)`):

| 파형 | B | ΔR_b = c/B | 분리 / ΔR_b | 유령 진폭 | Pd(진짜) | **P(유령을 별개 표적으로 검출)** |
|---|---|---|---|---|---|---|
| **5G NR** | 98 MHz | **3.1 m** | **1.16×** | −18.1 dB | 1.00 | **1.00 — 매 시행마다 가짜 표적** |
| WiFi | 76 MHz | 4.0 m | 0.89× | −18.2 dB | 1.00 | 0.00 (진짜와 병합) |
| LTE | 18 MHz | 16.7 m | 0.21× | −17.6 dB | 1.00 | 0.00 (완전 병합) |

유령의 물리적 위치(+3.53 m)와 세기(−18 dB)는 **파형과 거의 무관하다** — 순전히 기하다. 갈리는 건 **거리분해능**뿐이다.

> **5G 는 진짜 드론(R_b = 22.1 m)과 3.5 m 뒤의 유령(R_b = 25.6 m)을 매 시행마다 둘 다 검출한다.**
>
> **report5 가 5G 의 장점으로 내세운 바로 그 거리분해능이, 바닥을 유령 드론으로 바꾼다.** 광대역의 이득이
> 그대로 오경보로 되돌아온다. 협대역(LTE)은 유령을 못 분해해서 "안전"하지만, 그건 위치정보를 못 주기 때문이다.

## 6. 판정

### 정당한 것
- 하이브리드(표적=PO, 환경=RT) 설계는 그대로 유효하다. 이번 건과 무관하다.
- report4/report5 의 **탐지 관련 결론**(대역폭이 가르는 건 탐지가 아니라 위치정보, 점유의 대가)은 **그대로 선다** —
  전부 표적·잡음·직접파가 결정하는 양이고, 정적 클러터에 의존하지 않았기 때문이다. 아이러니하게도 **클러터가
  죽은 파라미터였다는 사실이 그 결론들을 보호한다.**

### 인용하면 안 되는 것
- ❌ *"무반사 챔버라 클러터가 약하다"* — 바닥은 −14.7 dB 다. 약하지 않다.
- ❌ *"RT 와 Analytic 이 일치하므로 클러터 모델이 검증됐다"* — 항등식이다. 검증한 바 없다.
- ❌ *"RT 실측 잔향은 우리 가정과 같은 자리수"* — 16 dB 차이다.
- ❌ **바닥 반사를 "지배적 클러터"라고 부르는 것** — 지배적 클러터는 **직접파**(DPI)다(~60–70 dB 위).
  그리고 표적과 함께 도플러가 실린 것은 정의상 **클러터가 아니라 유령**이다.

### 남은 리스크 (정직하게)

| 리스크 | 상태 |
|---|---|
| **클러터 도플러퍼짐** | ✅ **메워짐 (2026-07-24, `verify_clutter_doppler.py` → report09 §5).** 서베이 §V-A4 처방(C=100·4 iso-Rb 링·v∈[−1,1] m/s)을 챔버에 이식. **결과: SCR '죽은 파라미터'는 항등식이었다** — 도플러가 실리면 즉사하고 잔류가 amp²로 복귀. ⭐정정: '죽인 것'은 ECA span(X) 이 아니라 **0-도플러 노치**(이 하네스의 tx-클러터는 ECA 가 ~1.4 dB 만 지운다; verify_eca S5 파일럿-클러터만 진짜 span(X) 항등식). ⭐C4: **움직이는 클러터는 표적셀에 가짜 검출**(표적 −80 dB 로 지워도 표적셀 CFAR Pd≈1, 클러터 빼면 0 — 링이 표적 거리빈 bracket) → 저속 드론은 움직이는 클러터와 분간 안 됨(서베이 경고 재현) |
| **유한 ADC 동적범위·양자화** | 클러터 도플러퍼짐과 별개로 **여전히 미포함**(verify_eca 는 ECA 상쇄깊이 단계에만 ADC 스윕, Pd/SCR 전파 안 됨) |
| **hot clutter** | ✅ **추가됨 (report09 §5.4).** 독립 이미터 1기. INR 20 dB 미미, CNR-matched 면 SCR 열화. ⚠ scnr_in 이 서베이 입력SCNR 과 정확한 apples-to-apples 아님(축 다름) |
| **유령이 report4/5 수치에 미반영** | `floor_ghost_on=False` 가 기본 — 기존 수치는 유령 **없는** 세계의 값이다 |
| 19.3 ns 의 두 번째 RT 경로 | **미규명** (−11.6 dB). 결론엔 영향 없음 |
| 벽·천장 흡수체 −25 dB | **실측 아님.** `materials.py` 는 평판 단일면 반사가 ≈−5 dB 이고 −25 dB 는 피라미드 다중반사로 달성되는 **설계 목표**라고 명시 |
| 유령의 표적 RCS | 시선각이 다른데 진짜와 같다고 근사했다(1차) |

## 7. 권고

1. **용어**: 전 저장소에서 `anechoic` → `semi-anechoic`. (완료 — 코드·figure·발표자료)
2. **report4/report5**: "클러터가 약하다" 서사를 걷어내고, **"정적 클러터는 우리 하네스에서 관측 불가능하다"** 로
   대체. §D 의 "일치 = 검증" 주장 철회.
3. **다음 실험**: `floor_ghost_on=True` 로 전 파형 × 전 드론 매트릭스를 다시 돌려, **오경보율을 포함한** Pd 를 낸다.
   지금 report5 의 "5G 가 최고" 결론이 유령을 넣으면 어떻게 되는지가 진짜 질문이다.
4. **ECA 현실화**: ✅ **클러터 도플러퍼짐은 넣었다**(`verify_clutter_doppler.py`, report09 §5) — '죽은 파라미터'는 항등식이었고 움직이는 클러터엔 amp²로 되살아난다. 남은 것은 유한 동적범위(ADC 비트)·양자화의 **Pd/SCR 전파**다.
