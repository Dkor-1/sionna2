# MESH_VALIDATION — Phantom 3 실측 대조가 우리에게 허락하는 것

생성 2026-08-03.
1차 산출 `outputs/p3_ours.json`(눈감고 계산) · 대조 `outputs/p3_validation.json`(봉인 해제 후 대조) ·
대조군 `outputs/p3_control.json`(기하 대리표적).
이 문서는 **그 시험이 우리에게 무엇을 허락하고 무엇을 금지하는지**만 적는다.

---

## 0. 판정 (먼저 적는다)

우리 메쉬+커널로 DJI Phantom 3 의 방위평균 σ 를 눈감고 계산한 뒤 실측과 맞대었다.

| | 값 | 성격 |
|---|---|---|
| **레벨 오차** | **−4.9 dB** (고도·규약 정합 대조) · 대조를 바꾸면 **−3.0 ~ −4.9 dB** | 계통 편향. 부호는 **과소평가**. 지배 오차 |
| **기울기 오차** | **+0.10 dB/GHz** (우리 0.420 ± 0.066 vs 실측 0.315) | **1.6σ — 95% 수준에서 유의하지 않다** |
| **우리 운용대역(1.8–6 GHz)** | 레벨 −8.0 → −3.4 dB, 기울기 **3.8배** | ⚠ **전대역 평균이 감추는 구조. 여기가 제일 나쁘다** |

세 줄 요약:

1. **우리 σ 는 실측보다 낮다.** 밴드 전체 평균 약 5 dB, 우리가 실제로 쓰는 저주파 끝에서 8 dB.
2. **주파수 의존은 구별되지 않는다.** "기울기가 측정의 2배" 는 고도가 정합이 아닌 대조에서만 나온다.
3. **이 숫자는 기체 하나·형상표 하나에 붙는다.** 5개 기체 전부에 그대로 붙일 수 없다(§7).

대조군(§6): 같은 자로 기하 대리표적을 재면 **박스 +12.9 dB · 등가부피 큐브 +14.3 · 최대치수 큐브 +19.5**
로 우리보다 2.6~4.0배 나쁘다. ⚠ 단 **등가부피 PEC 구는 밴드평균 레벨에서 우리를 이긴다**(+0.90 dB) —
대신 주파수 의존과 각도 구조를 하나도 못 내고, 그 승리는 자유 손잡이(등가반지름 규칙, 6.5 dB 폭)에서 나왔다.

## 1. 시험 설계 — 눈감기(blind) 규약

### 1.1 절차

```
1단계  outputs/p3_ours.json      2026-08-03 08:34  문헌값을 한 번도 열지 않고 σ(f, az, el) 산출
2단계  outputs/p3_validation.json 2026-08-03 10:33  봉인 해제. 문헌을 열고 1단계 산출을 대조
       → p3_ours.json 은 2단계에서 한 줄도 고치지 않았다(verdict.honesty)
```

1단계 조건 (`p3_ours.meta`):

| 항목 | 값 |
|---|---|
| 엔진 | SBR(Mitsuba/OptiX 최초교점) + PO 면적분, `src/rcs_sbr.rcs_sbr_batch` |
| 호출 경로 | `benchmark/rcs_anchor.raw_sigma_az` — **다른 기체와 동일 경로·동일 인자 규약** |
| 광선격자 | λ/16 (생산 기본은 λ/12), jitter=2 |
| 방위 | 0:1:359, 360점 · 고도 10종(−15/−5/−2/0/+2/+5/15/30/45/60°) |
| 주파수 | 1.8–18.2 GHz **균등 21점** (Δ=0.82 GHz) |
| 반사 | max_bounce=1, 유전체 셸 투과(τ=1−\|Γ\|²) 후 내부 배터리/PCB 코히런트 가산 |
| 통계 | μ(f)=10log10(mean_φ σ_lin) **선형평균**, ε(f)=std(10log10 σ_lin) [dB] |
| 비용 | 벽시계 4,967 s(≈83분), 프로세스 합 14,542 s, GPU 0·3 |

### 1.2 왜 눈감기가 필요했나

**우리 코드에 레벨과 기울기를 옮기는 손잡이가 실제로 있기 때문이다.** 보이는 상태로 맞추면
그 결과는 시험이 아니라 적합(fit)이 된다. 손잡이 목록:

| 손잡이 | 값을 얼마나 옮기나 | 출처 |
|---|---|---|
| σ 앵커 모드 | `slope_only`(기본) 0 dB · `level_and_slope_L2` **+7.42 dB** · `L4` **+16.92 dB** | RETRACTION_LOG R4 |
| 크기전이 지수 선택 | s1000plus 에서 **9.50 dB** 가 갈림 | R4 |
| dB↔선형 평균 규약 | **+2.51 dB**(지수분포) ↔ **+3.13~3.75 dB**(로그정규) ↔ 0(끄기) | A8 |
| 광선격자 div | λ/12 ↔ λ/16 에서 rms 0.52 dB, 1.8 GHz 에서 **1.18 dB** | `p3_ours.grid_control` |

즉 **±10 dB 급 자유도가 손 닿는 곳에 있었다.** 눈을 감지 않으면 "−4.9 dB 어긋났다" 는 문장이
"−4.9 dB 만큼 손잡이를 안 돌렸다" 와 구별되지 않는다.

### 1.3 눈감기가 실제로 지켜졌다는 근거

`p3_ours.blind_log` 가 열람 이력을 8줄로 남긴다. 요약:

- **읽음**: `benchmark/rcs_anchor.py`(절차·통계규약, 문헌 계수는 import 라 본문에 값 없음) ·
  `benchmark/airframe_phantom3.py`(열기 전 금지문자열 0건을 `grep -c` 로 확인) ·
  `src/drones.py` P3 스펙 · `src/rcs_sbr.py` · `src/gpu.py`
- **grep 만**: `src/sigma_anchor.py` — 딕셔너리 **이름과 줄번호**만. μ/a/b 수치는 보지 않았다
- **import 하되 출력 안 함**: `rcs_anchor` → stdout 0바이트를 리다이렉트로 확인
- **안 엶**: DAS/YUAN 상수 블록 · `outputs/rcs_anchor.json` 의 literature 절 · 두 논문 PDF ·
  `verify_comparability_yuan.py` · `validate_measured_airframe.py` · `outputs/sigma_anchor.json` 외 다수

⚠ **완전하지 않았던 부분도 그 로그가 스스로 적는다** — sigma_anchor 를 grep 할 때 ε(분포 폭) 관련
설명 문장 일부가 딸려 나왔다. μ 계수·절대 σ 는 아니지만, **ε 대조(§5)는 완전한 눈감기가 아니다.**
레벨·기울기 대조(§3)는 영향을 받지 않는다.

### 1.4 대조 대상을 고르는 문제 (사과-대-사과)

두 문헌이 있다. **독립 2건이 아니다** — Das(IEEE WCL 2026) 의 Phantom 3 행은 Yuan(EuCAP 2025)
원자료의 재분석이다(Das 사사에 명시, Table I 설정이 글자 단위로 동일).

| 축 | 우리 | Das | Yuan θ=90 |
|---|---|---|---|
| 주파수창 | 1.8–18.2 GHz, 21점 | 1.8–18.2, 2801점 | 동일, 2801점 |
| **고도** | el=0 단면 | **고도풀링(추정)** | **θ=90 = el 0 — 정합** |
| 방위창 | 0:1:359 (360점, 전주기) | −90:2:90 (91점, 180° 호) | 동일 |
| 추정량 | 단일주파수 CW | **시간영역 피크** | 단일주파수 CW — 정합 |
| 편파 | 무편파 스칼라 \|Γ\| | VV | VV |

→ **고도·통계규약·추정량이 모두 정합인 대조는 "우리 el=0 ↔ Yuan θ90 복원 실측곡선" 하나뿐이다.**
이 문서의 헤드라인 숫자는 전부 그 대조에서 나온다.

방위창 차이는 따로 쟀다(`window.azimuth_window`): 우리 패턴에서 91점·180° 호를 **모든 시작각으로**
잘라 μ 를 다시 내면 평균 편향 −0.10 dB(최대 |0.35| dB), 시작각 미상에 따른 최악 폭 4.46 dB.
→ **레벨 결손 −4.9 dB 를 설명하지 못한다.**

## 2. 우리 방식의 오차 — 레벨

### 2.1 값

| 대조 | 밴드평균 레벨차 [dB] | 정합 여부 |
|---|---|---|
| **Yuan θ90 복원 실측곡선** | **−4.91** (rms 5.15, std 1.60) | ⭐ 고도·규약·추정량 전부 정합 |
| Yuan θ90 공표 직선 | −4.60 | 고도 정합, 곡선 대신 직선 |
| Das + 지수분포 규약(+2.51) | −3.01 | 고도 비정합 |
| Das + 로그정규 규약(+3.43) | −3.94 | 고도 비정합 |
| Das 공표값 그대로(규약 미적용) | −0.51 | 고도·규약 둘 다 비정합 |

**부호는 전부 같다 — 우리가 낮다.** 폭 −3.0~−4.9 dB 는 **문헌 내부 불일치를 물려받은 것**이다
(같은 원자료의 두 논문이 레벨에서 어긋난다). 단일값으로 좁히면 거짓 정밀이다.

- 최악: **1.8 GHz 에서 −7.97 dB**
- 최선: 8.36 GHz 에서 −2.29 dB
- 잔차 산포: std **1.60 dB**

### 2.2 방향 — 왜 낮은가

잔차가 **저주파에서 가장 음(−)이고 고주파로 갈수록 줄어든다**(저대역 −5.78 / 고대역 −5.07,
Das 대조에서는 −4.85 / −2.35). 두 후보 기전이 같은 방향을 가리킨다:

1. **PTD(모서리 회절) 결손** — 우리 생산 커널은 1-bounce PO 뿐이다. 모서리 회절 σ 는 f 에 거의
   무관한데 PO 정반사항은 ∝f² 로 자라므로, **저주파일수록 빠진 몫의 비중이 커진다.**
2. **저 ka 에서 PO 가 지는 것** — 1.8 GHz 에서 부위별 ka 는 기체 반스팬 5.45 / 셸 반높이 1.21 /
   모터벨 0.64 / 다리튜브 **0.30** 이고, 우리 구 스윕은 kr≈1 에서 PO 가 Mie 대비 **−6.58 dB** 진다.
   18.2 GHz 에서는 가장 작은 부위조차 ka=3.05 다.

⚠ 둘을 가르는 직접 실험은 **아직 하지 않았다.** 그리고 (2) 는 구의 kr 곡선을 구가 아닌 부위에
갖다 붙인 **정황 일치이지 정량 예측이 아니다**(기여 가중치를 모른다).

### 2.3 레벨 오차를 설명하지 **못하는** 것들 (배제 기록)

| 후보 | 크기 | 판정 |
|---|---|---|
| 방위창 차이(180° 호 vs 전주기) | 평균 편향 0.10 dB | 배제 |
| 광선격자 수렴 | λ/12↔λ/16 rms 0.52 dB | 배제 |
| 방위 표본수 | 360↔720 최대 0.03 dB | 배제 |
| 메쉬 높이 185 mm vs 문헌 200 mm | 판 한계(σ∝A²)로 ≈0.7 dB (추정) | 부분 기여, 부족 |
| 선언된 과금속화(마그네슘 판 1장) | **부호가 반대** — σ 를 올린다 | ⭐ **−4.9 dB 는 하한이다** |

⭐ 마지막 줄이 중요하다. 우리 P3 메쉬에는 실물에 없는 마그네슘 판이 하나 들어가 있다(선언된 편향).
그 편향은 σ 를 **올리는** 쪽인데도 결과는 5 dB 낮다 → **결손은 적어도 그만큼 더 크다.**

## 3. 우리 방식의 오차 — 기울기

μ(f) = a·f + b 의 a [dB/GHz]:

| | a | 비고 |
|---|---|---|
| **우리 el=0, 1.8–18.2 GHz** | **0.420 ± 0.066** (95% CI 0.290–0.549) | R²=0.68, rmse 1.43 dB, n=21 |
| Yuan θ90 공표 | 0.315 | 고도 정합 |
| Yuan θ90 곡선 재적합 | 0.3164 (전곡선) / 0.359 (우리 21점 재표집) | 성긴격자 불확도 ≈ ±0.04 |
| Das 공표 | 0.21 | ⚠ 고도풀링 — 정합 아님 |

| 차이 | 값 | 유의성 |
|---|---|---|
| **우리 − Yuan θ90** | **+0.105 dB/GHz** | **1.58σ — 95% 수준에서 구별되지 않음** |
| 우리 − Yuan 실측곡선(잔차 추세) | +0.061 dB/GHz | 0.86σ |
| 우리 − Das | +0.210 dB/GHz | 3.17σ, 그러나 고도 비정합 |

⚠ **우리 기울기 추정치는 끝점이 끌고 간다.** leave-one-out 0.356~0.455, 양 끝점 둘을 빼면 **0.334**.
"2배 가파르다" 를 유효숫자 두 자리로 적으면 안 된다.

⭐ **기울기는 규약 논쟁이 안 닿는 자리다** — dB↔선형 오프셋은 레벨 상수라 지수분포 분기에서
기울기에 전혀 영향을 주지 않는다. ⚠ 단 로그정규 분기는 ε(f) 를 통해 f 에 의존하므로 Das 실효
기울기를 0.210 → 0.248 로 올린다.

**레벨 대 기울기 — 어느 쪽이 지배하나**: 16.4 GHz 폭 전체에서 기울기 오차가 만드는 차이는 1.7 dB,
레벨 오차는 4.7 dB → **레벨이 약 3배 크다.**

## 4. ⚠ 우리 운용대역에서는 더 나쁘다

전대역 평균이 구조를 감춘다. μ(f) 는 직선이 아니다 — 저주파에서 가파르게 오르다 포화한다.

| 구간 | 우리 a | 실측 a | 비 |
|---|---|---|---|
| **1.8–6.0 GHz (우리 대역)** | **1.563** (R²=0.96) | 0.411 | **3.81배** |
| 6.0–18.2 GHz | 0.199 (R²=0.33) | 0.306 | 0.65배 |
| 전대역 | 0.420 | 0.315 | 1.33배 |

레벨도 이 구간에서 가장 나쁘다: **1.8 GHz −7.97 dB → 5.9 GHz −3.37 dB.**

통신대역 3곳 (우리 값 vs Yuan θ90 실측):

| 대역 | 우리 μ [dBsm] | 실측곡선 [dBsm] | 점대점 차 | 직선대직선 차 |
|---|---|---|---|---|
| LTE 1.843 GHz | −24.24 | −15.10 | **−9.14** | −5.45 |
| 5G 3.5 GHz | −21.25 | −12.68 | −8.57 | −5.28 |
| WiFi 5.21 GHz | −19.09 | −15.08 | −4.01 | −5.10 |

⚠ 두 곡선 다 리플이 있으므로 **점대점 차는 리플을 포함한다**(우리 자체 rmse 만 1.43 dB).
직선대직선(−5.1~−5.5 dB)이 더 안정한 자다. 둘 다 적는다.

⭐ **결과의 방향**: 디텍션 벤치마크는 LTE 1.843 GHz 를 최악 대역으로 쓰는데, 바로 거기서 우리 σ 가
가장 낮다 → **우리 Pd 는 보수적(비관적) 쪽으로 치우쳐 있다.** 결론을 뒤집지는 않지만 마진을
과소평가한다. 이 방향성은 논문·슬라이드에 반드시 병기한다.

## 6. 대조군 — 기하 대리표적을 놓으면 얼마나 틀리나

선행 관행 중 가장 흔한 회피는 **기하 대리표적**이다 — UAV 를 *"metallic cube"* 로, 사람을
직육면체로 놓는다(`outputs/evasion_catalogue.json`, 표적 산란을 주장한 17편 중 계산된 절대 dBsm 을
인쇄한 것은 3편, 드론은 0편). 그래서 **같은 자·같은 앵커**로 대리표적을 재봤다.

### 6.1 대조군 설계

| 항목 | 값 |
|---|---|
| 커널 | `src/rcs_po.rcs_from_points` (PEC, \|Γ\|=1). **볼록체라 자기차폐가 없어 SBR 1-bounce PO 와 동일 물리** — 우리 메쉬가 쓰는 SBR 경로를 그대로 태우지 않은 것은 대조군이 볼록체라 결과가 같기 때문이고, 이 동치는 물리적 논증이지 실행 대조는 아니다 |
| 규약 | μ(f)=10log10(mean_az σ_lin), el=0, 방위 360점, 1.8–18.2 GHz 21점 — **우리 메쉬와 같은 자** |
| 격자 | λ/16. 수렴 대조 λ/24 와 차이 **0.002~0.016 dB** (대조군 자체는 수렴했다) |
| 구 대조군 | 정확 Mie (`benchmark/mie_pec_sphere`) — 근사 없음 |
| 대조 대상 | Yuan θ90 복원 실측곡선을 우리 21주파수에 재표집(a=0.359). **모든 행에 같은 자** |

### 6.2 결과

|---|---|---|---|---|---|---|
| **우리 P3 메쉬 (SBR+PO)** | **−4.91** | **5.15** | 0.420 | **+0.061** | 6.17 | — |

| PEC 정육면체 한 변 23.5 cm (등가부피) | **+14.28** | 14.35 | 0.542 | +0.183 | 9.67 | **2.9배 나쁨** |
| PEC 정육면체 한 변 35 cm (최대치수) | **+19.49** | 19.54 | 0.540 | +0.181 | 10.11 | **4.0배 나쁨** |
| PEC 구 r=14.6 cm (등가부피), 정확 Mie | **+0.90** | **2.08** | **0.011** | **−0.348** | 0 | ⚠ **레벨은 우리보다 낫다** |
| (참고) 문헌 ε | | | | | 5.46 | |

**박스·큐브는 전부 크게 과대평가한다.** 부호가 우리와 반대이고(+), 크기가 2.6~4.0배다.
가장 흔한 관행인 *"metallic cube"* 를 최대치수로 놓으면 **+19.5 dB** — 100배 가까이 틀린다.
방위 산포도 어긋난다(ε 9.7~10.1 dB vs 문헌 5.46 · 우리 6.17): 평평한 큰 면 넷이 만드는
정반사 플래시가 통계를 지배해 **드론의 요동 통계와 다른 물건**이 된다.

### 6.3 ⚠ 그러나 등가부피 구는 밴드평균 레벨에서 우리를 이긴다

정직하게 적는다. **PEC 구(r=14.6 cm)의 밴드평균 오차는 +0.90 dB 로 우리 −4.91 dB 보다 작다.**
rms 도 2.08 vs 5.15 로 낫다. 이 결과를 숨기지 않는다. 다만 **그 승리가 무엇을 사지 못하는지**를 같이 적는다.

1. **주파수 의존을 하나도 못 낸다.** 구의 a=0.011 dB/GHz 로 사실상 평탄이고, 실측 0.359 를
   통째로 놓친다(기울기 오차 **−0.348**, 우리 +0.061 의 5.7배). 광학영역 구는 σ=πr² 로 f 에 무관하다.
2. **각도 구조가 0 이다.** ε=0 — 방위·고도 의존이 원리적으로 없다. 요동 분포(Swerling)도,
   자세 의존도, 로브도 만들 수 없다. **검출 성능은 평균이 아니라 요동 분포가 정한다.**
3. ⭐ **그 +0.90 dB 는 자유 손잡이를 돌려 나온 값이다.** 등가반지름을 정하는 규칙이 없다:

   | 규칙 | r [m] | πr² [dBsm] | 밴드평균 Δ |
   |---|---|---|---|
   | bbox 등가부피 | 0.1457 | −11.76 | **+0.90** |
   | 대각/2 | 0.1750 | −10.17 | +2.48 |
   | 동체폭/2 | 0.1000 | −15.03 | −2.32 |
   | **메쉬 등가부피** | 0.0823 | −16.72 | **−4.03** |

   네 규칙이 **6.51 dB** 를 벌린다. 우리 메쉬 오차(−4.91)와 같은 자리에 떨어지는 규칙도 있다.
   **이기는 반지름은 답을 본 뒤에 골랐다.** 우리 메쉬에는 이 손잡이가 없다 — 치수가 공표 제원이다.

→ **판정**: 기하 대리표적 대비 우리 메쉬의 이득은 **박스·큐브 대비 2.6~4.0배(13~19 dB)** 이고,
**등가부피 구 대비로는 밴드평균 레벨에서 지고 주파수 의존·각도 구조에서 이긴다.**
"우리 메쉬가 모든 대리표적보다 낫다" 는 **쓸 수 없다**(§9.2).

## 7. ⭐ 이 숫자를 우리 5개 기체에 오차막대로 붙일 수 있는가

**우리 5개 기체** = `mini5pro` · `mavic4pro` · `matrice4e` · `phantom4` · `s1000plus`
(`outputs/report13_freespace.json` 의 표적 집합. 별도로 `typhoonh480` · `x500v2` 도 등록돼 있다.)

### 7.1 먼저 알아야 할 사실 — 시험된 것은 "P3 메쉬" 가 아니다

`benchmark/airframe_phantom3.py` 와 `docs/MESH_METHOD.md` §9 가 적는 그대로:

- P3 에서 **측정/공표인 것**: 대각 350 mm · 높이 200 mm · 프롭 DJI 9450 · 45° X 고정암 · 1280 g
- P3 에서 **상속인 것**(`SHAPE_DONOR = "phantom4"`): 셸 단면 법칙 · 암 폭 · 암 단면비 · 아치 다리 비율
- **저장소에 Phantom 3 사진이 한 장도 없다**

→ **P3 메쉬 = "Phantom 4 사진실측 형상표에 P3 제원을 얹은 것"** 이다.
따라서 이 시험이 채점한 것은 **"P4 형상표 + 우리 엔진"** 조합이다.

### 7.2 전이 판정표

| 기체 | 형상표 | 코드 경로 | 크기급 | 오차막대 전이 |
|---|---|---|---|---|
| **phantom4** | **동일**(`_SHELL_SHAPE["phantom4"]`, `_ARM_WIDTH/SECTION["phantom4"]`, `_gear_arch`) | 동일 | 350 mm, 1380 g | ✅ **직접 전이. 조건 없음** |
| mini5pro | 다름(사진 3장, 자기 표) | 동일(셸형) | 275 mm, 250 g | ⚠ **가정으로만** — §7.3 조건부 |
| mavic4pro | 다름(사진 4장, 자기 표) | 동일(셸형) | 441 mm, 1063 g | ⚠ 가정으로만 |
| matrice4e | 다름(사진 5장, 자기 표) | 동일(셸형) | 439 mm, 1219 g | ⚠ 가정으로만 |
| **s1000plus** | 다름 | **`build_frame_cad` 최상위 전용 분기**, 카본 암·tall 다리·belly 짐벌 | **1045 mm, 9500 g (3배)** | ⛔ **전이 안 됨** |

### 7.3 "가정으로만" 이 무슨 뜻인가 — 조건 목록

셸형 3종(mini5pro·mavic4pro·matrice4e)에 −5 dB 를 붙이려면 **아래를 전부 명시**해야 하고,
그러고도 그것은 **측정이 아니라 선언된 가정**이다.

전이를 **지지하는** 사실:

1. **엔진이 같다** — 익형 프롭 법칙(참조 프롭 3종 실측), 불리언 합집합, 그룹→재질 |Γ| 단일 진리원,
   λ 기준 재샘플링, SBR 가림, 1-bounce PO. 형상표와 독립이므로 P3 결과가 지지/반증할 수 있다.
2. **내부 산란체가 같다** — σ 를 지배하는 배터리/PCB/마그네슘 판이 **셸형 전 기종 같은 비율 상자**다
   (기종별 근거 없음, `MESH_METHOD` §7.7). 지배 부품이 공통이라는 뜻이므로 전이에 유리하다.
3. **형상 충실도가 같은 대역이다** — 사진 IoU(자기복제 상한 대비): phantom4 59 % · matrice4e 63 % ·
   mavic4pro 57 % · mini5pro 50 %. 도너인 P4 가 중간이다.

전이를 **막는** 사실:

1. **형상표가 통째로 다르다** — 기종당 손으로 적는 숫자가 100~160개다(셸 27 + 암 4 + 짐벌 20~52 +
   배치 38~61 + 다리 5~10 + 스펙 10). 그중 상당수가 등급 **H**(근거 미기재)다.
2. **짐벌이 다른 함수다** — P3 는 `_gimbal_hanging`(21개 숫자, 전부 H), mavic 은 `_gimbal_infinity/hasselblad`,
   matrice 는 `_gimbal_sensor_v2`(52개). 짐벌은 금속이라 σ 기여가 작지 않다.
3. **오차가 상수가 아니다** — 레벨 결손은 저주파에서 크다(§2.2). 그 기전이 저 ka 라면
   **더 작은 기체(mini5pro 275 mm)에서는 결손이 더 커지고, 더 큰 기체에서는 줄어든다.**
   즉 −5 dB 는 350 mm 급에 붙는 값이고 크기가 다르면 **값 자체가 이동**한다. 방향은 예측 가능하나
   크기는 모른다 — **측정하지 않았다.**
4. **공용 기본경로의 실측 정확도가 나쁘다** — 손을 안 댄 대조기체에서 방위별 RMS **7~10 dB**
   (`outputs/community_compare.json`, M100·M600). 방위평균만 우연히 1~2 dB 에 든다.

### 7.4 그래서 실제로 어떻게 그리나

```
phantom4        μ(f) 위에 −4.9 dB (규약폭 −3.0~−4.9) 오프셋 + 잔차 std 1.60 dB 밴드
                ⚠ 1.8 GHz 근처는 −8.0 dB. 상수 오프셋으로 그리지 말 것.

셸형 3종        같은 밴드를 그리되 캡션에 반드시:
                "P4 형상표에서 잰 값을 같은 엔진·같은 내부 산란체 가정 아래 옮긴 것이며,
                 이 기체에서 직접 측정되지 않았다."
                mini5pro 는 크기가 작아 결손이 더 클 것으로 예상되나 크기 미상.

s1000plus       ⛔ 붙이지 않는다. 코드 경로·크기급이 둘 다 다르다.
                필요하면 "우리 σ 는 계통적으로 낮은 쪽" 이라는 부호만 옮긴다.

typhoonh480     ⛔ 전용 분기. 위와 동일.
x500v2          ⛔ 열린 프레임 — 셸이 아예 없다. 위와 동일.
```

⭐ **오차막대는 대칭 ± 가 아니다.** 부호가 있는 편향(−)이고, 주파수 의존이 있으며,
선언된 과금속화 편향 때문에 **하한**이다. `±5 dB` 로 그리면 세 가지를 동시에 왜곡한다.

### 7.5 두 번째 앵커가 있어야 풀리는 것

"우리가 임의의 기체 형상을 σ 수준으로 재현한다" 는 주장은 이 시험으로 지지되지 않는다.
지지하려면 **형상표가 다른 기체**(다른 셸 법칙 + 다른 짐벌 분기)에서 두 번째 실측 앵커가 필요하다.
현재 그런 앵커는 없다.

## 8. ⚠ 이 시험이 검증하지 **않는** 것

각 항목은 "안 쟀다" 이지 "괜찮다" 가 아니다.

### 8.1 점별(각도별) 패턴

우리가 맞댄 것은 **방위평균 μ(f) 와 방위 산포 ε(f) 두 스칼라**다.
문헌이 인쇄한 것이 그 둘뿐이고(선형계수 a·b, ε), 방위창마저 다르다(180° 호 91점 vs 전주기 360점).
→ **σ(φ) 곡선이 각도별로 맞는지는 전혀 시험되지 않았다.**
⚠ 참고로 손을 안 댄 공용경로 기체에서 방위평균은 1~2 dB 에 들면서 방위별 RMS 는 7~10 dB 였다 —
**평균이 맞는다고 패턴이 맞는 게 아니라는 실측 사례가 저장소 안에 있다.**

### 8.2 편파

Das·Yuan 은 **VV**, 우리 커널은 **무편파 스칼라 |Γ|** 다(PO 면적분 항에 편파가 없다).
그 차이는 통째로 레벨 오차에 흡수됐다. → **교차편파·편파비·편파별 패턴은 시험 대상이 아니었다.**
(1차 PTD 프린지 항만 편파를 갖고 그것도 생산 커널에 아직 배선되지 않았다.)

### 8.3 회전 상태 / 마이크로도플러

**정지 메쉬다.** 프로펠러는 초기위상 하나로 고정돼 있다.
→ 회전에 따른 σ 변조, 블레이드 플래시, 마이크로도플러 스펙트럼은 **아무것도 검증되지 않았다.**
(Sionna RT 의 `Paths.doppler` 는 객체당 강체 속도 1벡터라 회전 프롭을 stock 으로 담지 못한다.)

### 8.4 바이스태틱

**전부 모노스태틱 후방산란이다.** 우리 디텍션 서사는 패시브 바이스태틱인데,
이 시험은 그 구성을 재지 않는다. PO obliquity 항이 바이스태틱에서 달라지고,
Das 논문이 바이스태틱 표를 갖고 있음에도 **이 대조에는 쓰지 않았다.**

### 8.5 그 밖에 안 쟀거나 못 잰 것

| 항목 | 상태 |
|---|---|
| 고도 의존 | el=0 만 정합 대조. 우리 μ 는 고도에 따라 최대 **11.97 dB** 벌어지고 el≥15° 에서 기울기 **부호가 뒤집힌다**(−0.09~−0.16) |
| 다중반사 | max_bounce=1. 암-동체 이면반사 등은 애초에 합에 없다 |
| 모서리 회절(PTD) | 생산 커널에 배선되지 않았다(`attach_to_sbr_field` 호출처 0건) |
| 근거리장 | 문헌·우리 둘 다 원거리장. 실측 계획의 근거리 구간은 별건 |
| 표적 개체차 | 논문이 "DJI Phantom 3" 로만 적어 **변종(Standard/4K/Advanced/Pro) 미상** |
| 독립 재현 | 앵커는 **한 대·한 실험실·한 원자료**다. Das 는 Yuan 의 재분석이므로 2건이 아니다 |
| 대역 상단 테셀레이션 | 18.2 GHz 에서 λ=16.5 mm 인데 삼각형 변 p90 9.4 mm·최대 150 mm → 곡률부 부족 |
| 프롭 재질 | 스톡 폴리머로 모형화. 옵션 카본 프롭이면 프롭 그룹에서 +11 dB 급 |

### 9.2 ⛔ 여전히 못 쓴다

| 못 쓰는 문장 | 왜 |
|---|---|
| *"우리 방식이 드론 RCS 를 ±5 dB 정확도로 검증됐다"* | 기체 1대·실험실 1곳·원자료 1건. 그리고 ± 가 아니라 부호 있는 편향이다 |
| *"5개 기체 전부에 ±5 dB 오차막대를 붙인다"* | phantom4 외에는 형상표가 다르다. s1000plus 는 코드 경로도 크기급도 다르다 |
| *"우리 메쉬가 실측 패턴과 일치한다"* | 각도별 패턴은 대조하지 않았다. 방위평균 두 스칼라뿐이다 |
| *"우리 기울기가 측정의 2배다"* | 그 2배는 고도풀링 Das 대조에서만 나온다. 고도 정합 대조에서는 1.33배·1.6σ·유의하지 않음 |
| *"레벨 오차는 −4.9 dB 다"* (단일값) | 규약 분기 0.93 dB + 문헌 내부 고도항 1.5 dB 를 달고 있다. 범위와 대조 대상을 함께 적어야 한다 |
| *"우리 σ 통계가 측정과 같은 분포족이다"* | 순위가 어긋난다(로그정규 vs 라이시안) |
| *"바이스태틱/편파/회전 상태에서도 같은 오차"* | 셋 다 이 시험 밖이다 |
| *"우리 σ 격자가 전 고도에서 검증됐다"* | el=0 만 정합이다. 고도 간 μ 가 최대 11.97 dB 벌어지고 기울기 부호도 뒤집힌다 |
| *"메쉬 충실도가 σ 정확도로 이어진다"* | 이 시험은 그 인과를 분리하지 못한다. 형상·재질·커널이 한 덩어리로 채점됐다 |
| *"실측 두 건과 맞췄다"* | Das 는 Yuan 원자료의 재분석이다. **한 건**이다 |
| *"우리 메쉬가 모든 기하 대리표적보다 낫다"* | 등가부피 PEC 구가 밴드평균 레벨에서 우리보다 낫다(§6.3). 쓸 수 있는 형태는 *"박스·큐브보다 2.6~4.0배 낫다"* 와 *"구보다 주파수 의존·각도 구조에서 낫다"* 로 나눠 적는 것이다 |
| *"메쉬를 정교하게 만들면 σ 가 맞는다"* | 이 시험은 그 인과를 지지하지 않는다. 정교한 메쉬(−4.91)가 단순한 구(+0.90)에게 밴드평균에서 졌다 |

### 9.3 ⛔ 표현 자체가 금지 (RETRACTION_LOG)

`해석해 검증` · `공개문헌상 공백` · `first` · `novel` — 이 문서에도 쓰지 않았고, 파생물에도 쓰지 않는다.
- "해석해 대비" 라고 쓰면 세 과녁(정확 Mie / 해석 PO / PO 폐형해)이 뭉개진다. 진짜 외부 기준은 **정확 Mie 하나**다.
- 코퍼스 안의 미발견을 문헌의 부재로 말하지 않는다. 쓸 수 있는 형태는
  *"보유 아카이브 안에서 …를 찾지 못했다"* 이다.
