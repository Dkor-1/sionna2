## 1. Question and design

The 0917 pilot set its thresholds on static target-absent frames and then met clutter that moved: at a frame false-alarm target of 1e-02 the measured rate was 0.783 with clutter Doppler up to +/-10 Hz (`outputs/ofdm_receiver_pilot_0917.json` : `h0.stress.h0_eval_drift10.frame["1e-02"]`). Its H1 targets carried |Doppler| 300..5e+03 Hz, so it never asked what suppressing low Doppler costs a slow or hovering drone. This run asks both on the same frames.

| Axis | Levels |
|---|---|
| clutter environment (Doppler of every clutter path, drawn uniformly per frame) | `static` +/-0 Hz, `drift2` +/-2 Hz, `drift10` +/-10 Hz |
| body Doppler (H1 target), in Doppler bins of this frame | 0, 0.1, 0.5, 2 (1 bin = 109 Hz) |
| SNR per resource element (dB) | -40, -36, -32 |
| suppression method | `mean_removal`, `notch_1bin`, `notch_2bin`, `h0_subspace` |
| threshold arm | `static_cal`, `matched_cal` |
| payload configuration | `qpsk_dcguard` (QPSK, DC + guard nulls) |

Methods x environments x body Doppler x SNR = 4 x 3 x 4 x 3 = 144 H1 conditions per threshold arm, plus 36 hover conditions with the stored ray-traced modulation and 24 H0 conditions.

The design asked for three methods - the present mean removal, one fixed low-Doppler rejection baseline and one H0-trained suppression method - which is 108 H1 conditions per arm. The second blank width `notch_2bin` is a fourth method added after the first full run; it raises the count to 144 and is reported alongside, never in place of, the three.

Methods:

- `mean_removal`: the 0917 pilot's step 3, subtract the slow-time mean of every active subcarrier.
- `notch_1bin`: mean removal, then drop every map cell whose Doppler grid row has |Doppler| below 1 Doppler bin (109 Hz) from the candidate search region. The half-width is the frame's Doppler resolution, a system quantity fixed before any evaluation frame was read; the CFAR training average is unchanged. The blank acts on the rows of the padded Doppler grid, so a candidate whose 3-point-interpolated Doppler falls inside the band is still kept when its grid row lies outside it.
- `notch_2bin`: the same candidate blank at a half-width of 2 Doppler bins (219 Hz), which is the Hann main-lobe half-width already used by the CFAR guard in section 2. It is also a system quantity and not a swept parameter, but it was added after the first run of this script showed that the 1-bin width left the frame statistic unchanged, so it is not a blind choice made before any result was seen; both widths are reported side by side and neither was tuned on evaluation frames. Note the geometry this creates: the fastest body Doppler in this run is 2 bins, which is exactly this half-width, so the reference target of sections 4.2 and 4.3 sits on the edge of this blank. Its Pd there is the best case for this width, and nothing in this run says what a blank one padded grid row wider would leave of it.
- `h0_subspace`: mean removal replaced by projecting every active subcarrier's slow-time sequence onto the orthogonal complement of the r leading eigenvectors of a slow-time covariance accumulated over the H0 development frames; r = the number of eigenvalues above 10 x the median eigenvalue, clipped to [1, 8].

Threshold arms: `static_cal` keeps the threshold (and, for `h0_subspace`, the trained subspace) of the static environment and carries it to the drifting ones; `matched_cal` recalibrates (and retrains) on the H0 sets of the matching environment. In the static environment the two arms are the same numbers by construction.

The system, payload, modulation, time-domain channel and receiver chain are those of `benchmark/ofdm_receiver_pilot_0917.py` (division by the per-frame reference on active subcarriers, suppression, separable Hann window, inverse FFT over subcarriers, FFT over symbols, CA-CFAR, local maxima, 3-point peak interpolation). This script replaces only the suppression stage and adds the candidate blank of `notch_1bin` and `notch_2bin`; with no notch and mean removal it reproduces the pilot's receiver exactly (test `test_matches_pilot_receiver`). Clutter is the pilot's three zero-Doppler paths at 18 m (30 dB), 61.5 m (24 dB), 143 m (18 dB) relative to the target, each given a Doppler drawn uniformly in +/- the environment's value, held constant within a frame. H1 adds one target path at a range drawn uniformly in 40..320 m; the pilot's target-borne second path is not used here, so every detection that is not within one resolution cell and one Doppler bin of the target counts as off-target. H0 frames use the noise level of SNR -35 dB for a unit target, as in the pilot.

## 6. What this does and does not show

- Nothing about hardware: no X410, no RF capture, no measured isolation, CFO, phase noise or ADC behaviour; the transmit permit and the 3.5 GHz carrier are working assumptions, not settings that were measured.
- Clutter here is three point paths whose Doppler is constant within a frame and redrawn per frame. Real foliage and traffic are not that; how site clutter moves is not known from this simulation, so which of these three environments matches a capture is open.
- The target is one point path with a frequency-flat gain: no rotor micro-Doppler line structure in the constant-amplitude sets, no range migration, no extended target, no frequency-dependent scattering. The hover set adds a slow-time modulation read from one stored cell; that is a flat-fading time-modulation test, not a per-path ray-traced channel.
- The hover modulation comes from one cell (`sionna_p4000000000_swR0D0E0F1_r15_n4096_prf28029_shell0.75mm_prop1.43mm_mfixbatteryi5_blperairframe_anttr38901_rt210_d2_el-15`): one airframe, one range (15 m), one elevation (-15 deg), one azimuth, open sky, max_depth 2, canonical slab. Nothing here says how it changes with aspect, range or environment.
- H0 is synthetic clutter plus white noise. It is not a target-absent capture, so none of these thresholds transfers to a measurement.
- Frame false-alarm targets were calibrated at 1e-01, 1e-02 only, from 1000 calibration frames; at the 1e-02 target that threshold is the 10-th largest calibration frame statistic, so the threshold itself is coarse at this calibration size.
- Only one payload configuration (`qpsk_dcguard`, QPSK) was run; 16-QAM and the random-null mask of the 0917 pilot are not in this set.
- Both candidate-blank half-widths and the eigenvalue rule are system quantities, not values tuned on evaluation frames, and were not swept; nothing here says they are the best choices. The 2-bin width was added after the 1-bin width was seen to leave the frame statistic unchanged, so the pair is a reported comparison, not a pre-registered one.
- Body Doppler mostly lands on the padded Doppler grid instead of between its rows. With pad_doppler = 2, a body Doppler of b bins sits at row b x 2 of that grid (0 bins at row 0, 0.1 bins at row 0.2, 0.5 bins at row 1, 2 bins at row 4), so 3 of the 4 levels are exactly on a row and carry no straddle loss, which is the best case for detection. Pd here is therefore not an average over the target's position within a Doppler cell.
- Every H1 target is one path drawn uniformly in range over 40..320 m while the three clutter paths sit at fixed ranges, so 0.116 of the H1 frames put the target within one resolution cell (8.15 m) of a clutter path in delay, where it is on top of a path 24 dB or 18 dB above it. Those frames are not separated out in any row above.
- Detection is scored only within one resolution cell and one Doppler bin of the target. For the hover set the target Doppler is 0, so a candidate raised by a rotor line is counted as off-target and never as Pd (section 4.4).

## 7. Reading (stated as reading, not as a result)

- In `drift10` at the 1e-02 target, the lowest measured frame false-alarm rate of the 8 method-arm pairs is `mean_removal`/`matched_cal` at 0.004 [0.00229, 0.00698], against 0.707 for `mean_removal`/`static_cal`. That is not by itself an improvement: in the same environment and arm its Pd at 2 bins and SNR/RE -32 dB is 0 [0, 0.0126] and at 0.5 bins 0 [0, 0.0126], so the lowest false-alarm rate in this run is bought by lowering detection as well. Section 4.2 carries the Pd of every row and is where any such trade is read.
- Of the 8 `drift10` pairs, 4 have a measured false-alarm rate that is not above the 1e-02 target (Wilson interval reaching the target or below it). Of those, the one with the highest Pd at 2 bins and SNR/RE -32 dB is `notch_2bin`/`static_cal`: measured Pfa 0.007 [0.00458, 0.0107], Pd 0.927 there and 0 at 0.5 bins. Every number in that sentence is measured in this run; which of them matters for a capture is not something this run answers.
- Not every threshold held on its own evaluation stream: `mean_removal`/`static_cal` in `drift10` measured 0.707 [0.69, 0.723]; `notch_1bin`/`static_cal` in `drift10` measured 0.707 [0.69, 0.723]; `notch_2bin`/`matched_cal` in `drift10` measured 0.0163 [0.0124, 0.0215]; `h0_subspace`/`static_cal` in `drift10` measured 0.708 [0.691, 0.724], whose Wilson interval lies above the 1e-02 target, so for those rows the target was not met and the Pd in section 4.2 is read at the measured rate, not at the target.
- A rate measured on this evaluation set cannot be read below the interval in section 1.1; two rows whose Wilson intervals overlap are not separated by this run.
- Section 4.4 compares one stored cell's time variation against a constant amplitude at the same mean target power. A difference there is a property of that cell's slow-time modulation within a 0.00913 s window, not of hovering drones in general.
