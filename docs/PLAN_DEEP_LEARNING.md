> 사용자(2026-08-11):

3. **약점이 한 기체에 몰려 있다**(typhoonh480). 전체 정확도보다 **이 기체의 F1** 이
   더 예리한 지표다. 헤드라인을 여기에 걸 수 있다.

## 1. 선행연구 — 무엇을 어떻게 했나

⚠ 아래는 **2026-08-11 웹 검색으로 얻은 요약**이다. `[원문]` 표시가 없는 것은
**초록·검색요약만 본 것**이고 원문 확인 전에는 인용하지 않는다
(상시규칙 [[sionna2-priorwork-verify]]).

### 1-1. ⭐⭐우리와 같은 실험을 한 팀 — White 외 (버밍엄)

**White, Jahangir, Baker, Antoniou, *Urban Bird-Drone Classification With Synthetic
Micro-Doppler Spectrograms*, IEEE Transactions on Radar Systems, **vol. 2, pp. 167–179, 2024**
(DOI 10.1109/TRS.2023.**3326317**)
⚠2026-08-11 정정 — 내가 적었던 DOI `…3323484` 는 **Crossref 404, 존재하지 않는 번호**였다.
  연도도 2023 이 아니라 **2024**다(권·호 배정 전 AAM 러닝헤드가 2023 이라 우리 파일 셋이
  서로 달랐다). `prior_work/rotor_randomness_survey.md:129,454` 가 처음부터 맞았다.

- ⚠**«합성으로만» 은 내 과장이었다(2026-08-11 원문 확인).** 실제로는 **반합성**이다 —
  큰 드론 2 종만 합성이고(학습셋의 **34.5 %**, 드론 클래스의 69 %), 새·Mini 2 는 실측을 쓰며,
  합성 표적을 **실측 배경 시계열에 더한다.** 그래서 −3.1 pp 라는 격차는 «순수 합성 대 실측»
  이 아니라 «반합성 대 실측» 이다. ⇒ 우리 목표선으로 그대로 쓰면 안 된다.
- **정확도 86.6 % (합성 훈련) vs 89.7 % (실측 훈련). 격차 3.1 포인트.**
- 합성 데이터셋 **4종**을 만들어 비교했는데, 서로 다른 것은 **모터 속도 샘플링 방식 하나뿐**이다.
- ⭐헤드라인: *"The effect of drone motor speed sampling used when simulating drone
  micro-Doppler is shown to have a **significant impact** on the accuracy of synthetic results."*

**우리에게 뜻하는 것 셋**
1. **«합성으로 훈련해 실측을 맞춘다»가 이미 성립한 일이다.** 우리 목표는 새롭지 않고,
   그래서 **비교 기준이 있다** — 격차 3.1 포인트가 우리가 넘어야 할 선이다.
2. ⭐**로터 속도 모델링이 정확도를 좌우한다는 것을 외부에서 이미 측정했다.**
   `NOISE_AND_ROTOR_PLAN.md` §2 가 «해야 한다»고 쓴 것의 **근거가 문헌에 있다.**
   지금 우리 로터는 상수 rpm + 정현파 한 톤이므로, White 의 «Fixed-Speeds 대조군»에 해당한다.
3. 같은 팀의 다른 논문을 우리는 이미 읽었다(`prior_work/rotor_randomness_survey.md` §2-3,
   실기 로그 4채널 rpm 을 쓴 판). **같은 그룹의 두 논문이 우리 계획의 두 축을 각각 지지한다.**

⚠ 다른 점도 적어야 한다: 그들은 **조류 vs 드론 2클래스**이고 우리는 **기종 6클래스**다.
2클래스 86.6 % 와 6클래스 87.9 % 는 난이도가 다르다 — 나란히 놓을 때 우연선을
함께 적어야 한다(50 % vs 16.7 %).

### 1-2. 입력 표현 — 문헌이 쓰는 것

| 표현 | 무엇 | 문헌 |
|---|---|---|
| **스펙트로그램(STFT)** | 시간-주파수 맵. 사실상 기본값 | 거의 전부 |
| **CVD** (cadence-velocity diagram) | 스펙트로그램의 **시간축을 다시 FFT** 한 것. «주기성»이 선으로 뜬다 | Kim 외 GRSL 2017; IRS 2022 |
| **병합 이미지** | 스펙트로그램 + CVD 를 한 장으로 | Kim 외 (KAIST), GRSL 14(1):38, 2017 |
| 켑스트로그램 · 가중 스펙트럼 | ⚠**스펙트로그램의 변형이 아니다** — WSP·CP 는 x(t) 에서 바로 나오고 WSP 는 dwell 전체를 창 하나로 FFT 해 **시간분해능이 없다**. SG 에서 파생되는 것은 CVD 뿐 | hal-03602645 |
| 원시 슬로타임 열 | 드묾 | — |

- **Kim 외 (KAIST), *Drone Classification Using CNN With Merged Doppler Images*,
  IEEE GRSL 14(1):38-42, 2017** — MDS + CVD 를 합쳐 GoogLeNet 에 넣는다.
- **EUSIPCO 2020, pp. 1561–1565 (DOI 10.23919/Eusipco47968.2020.9287525) · hal-03602645,
  *Micro-Doppler Signal Representation for Drone Classification by
  Deep Learning*** — 표현 5종(거리압축 시간신호 · 가중스펙트럼 · 켑스트럼 · 스펙트로그램 · CVD)을
  같은 **GoogLeNet** 에 넣어 비교(원문 전문에 AlexNet 0 회 — 2026-08-11 정정). **잡음 하에서 가중스펙트럼(WSP)이 92.7 % 로 최고.**
  ⇒ **표현 선택이 잡음 강인성을 바꾼다**는 직접 증거.

⚠ **CVD 는 우리 «STFT only» 규칙과 충돌하지 않는다** — CVD 는 STFT 크기맵의 시간축 FFT 이지
재할당·WVD 같은 **대체 시간-주파수 변환이 아니다**. 그래도 규칙([[md-stft-only]])이
«다른 표현이 필요하면 먼저 묻기»이므로 **A1 은 STFT 단독으로 먼저 하고, CVD 팔은 승인 후에 연다.**

### 1-3. 강인성 — 표준 훈련 CNN 의 함정

**[arXiv:2402.13651] *Robustness of Deep Neural Networks for Micro-Doppler Radar
Classification*, International Radar Symposium 2022** `[초록 확인]`

- 표준 관행으로 훈련한 CNN 두 개가 **«의미가 거의 없는» 시간 이동에 민감**했고,
  **적대적 예제에 극도로 취약**했다.
- 적대적 예제와 시간증강으로 훈련하면 일반화가 개선됐다.
- ⭐**CVD 입력 모델이 적대적 예제에 자연히 더 강인**했다.

**우리에게**: 시간 이동 민감성은 우리에게 **직접 위험**이다 — 우리 시계열은 초기 회전위상이
무작위이므로(`md_classify_dataset.py:624`), 시간 이동 불변성이 없으면 위상 추첨 하나로
답이 바뀐다. ⇒ **전역 평균 풀링 + 시간 순환이동 증강을 처음부터 넣는다**(§2-4 G3).

### 1-4. 공개 벤치마크

**DIAT-µSAT** (IEEE DataPort) — X-band(10 GHz) CW 레이다 **실측** 4,849장.
6클래스(RC plane · 3단날개 짧은/긴 로터 · 쿼드콥터 · 생체모방 새 · 미니헬기+새).
200~1740 rpm · 방위 0~360°(45° 간격) · 앙각 0~90°(30° 간격).

- 보고된 수치: 채널 어텐션 CNN **97.13 %**(추론 62 ms), IQGA-SVM **99.59 %**.
- ⚠**우리 결과와 직접 비교 금지.** 클래스 정의가 다르고(기체 종류가 아니라 로터 형태),
  주파수가 다르고(10 GHz vs 3.5 GHz), **모노스태틱 능동 CW** 다.
- ⭐**쓸 자리는 따로 있다** — 우리 신경망 구조가 «정상 범위»인지 보는 **위생 검사**로 쓴다.
  같은 구조가 DIAT 에서 90 % 대를 내면 구조 문제는 아니라는 뜻이다.

### 1-5. 패시브 쪽 — 우리 기하와 가장 가까운 것

- **Demissie 외, *Drone Detection With a LTE450-Based Passive Radar*, IET RSN, 2025** —
  LTE450 단일·다채널 패시브 레이다 실험. `[초록]`
- **DVB-T 패시브** — DJI Phantom 3 · F450 · Geoscan 401 을 **750~900 m** 에서 거리-도플러로

- **arXiv:2509.25732, Doppler-Based Multistatic Drone Tracking via Cellular Downlink** `[미열람]`

⚠ **패시브 + 딥러닝 + 마이크로도플러 기종분류**를 한꺼번에 한 논문은 이번 조사에서

리포트에 그렇게 적는다(더 넓은 조사 전에는 novelty 주장 금지 — [[sionna2-r20-novelty-correction]]).

## 2. 설계 — 무엇을 만들 것인가

### 2-1. 데이터 — ⭐**GPU 가 거의 안 든다**

우리 분류 데이터셋은 **위상표**에서 합성된다(`benchmark/md_classify_dataset.py`):
표 하나에 `E_ref` + `dE[로터, 위상100]` 이 들어 있고, 시행은 조회·보간으로 만든다.

⇒ **딥러닝용으로 표본을 10배 늘려도 SBR 을 다시 안 부른다.** 표는 이미 있다
(`outputs/md_classify_tables/`, 6기종 × 18자세 = 108개).
시계열 12,096개 × 4,925 표본 × complex64 ≈ **476 MB**. 통째로 GPU 에 올라간다.

**⇒ 딥러닝의 비용은 사실상 훈련 시간뿐이고, 그것은 분 단위다.**

### 2-2. 입력 — 세 팔, 순서대로

| 팔 | 입력 | 왜 | 문헌 대응 |
|---|---|---|---|
| **A1** | **STFT dB 맵** (flash_spec 규약 그대로, 창 70 · hop 2 · FFT 560) | 문헌 표준. 비교가 성립한다 | White TRS **2024**, 거의 전부 |
| **A3** | ⭐**접은 프로파일** — `f_flash` 로 접은 한 주기 평균 + 그 분산 | **우리 물리에 가장 맞다.** 접는 순간 f_flash 가 입력에서 사라져 **치트가 원천 차단**된다 | 우리 `fold_h1..h6` 특징의 학습판. 문헌 선례 못 찾음 |
| **A2** | 원시 슬로타임 `[Re, Im]` 2×4925 | STFT 는 정보를 버린다(창 70 → 분해능 281 Hz). 원시열은 안 버린다 | 드묾 — 해볼 가치 |

**권장 순서: A1 → A3 → (여력되면) A2.**
A1 이 먼저인 이유는 **문헌과 나란히 놓을 수 있는 유일한 팔**이기 때문이다(상시규칙
[[sionna2-priorwork-methodology]]).

⚠ **A1 의 함정**: 맵을 최대값으로 정규화하면 `dc_over_ac_db`(동체선 대 블레이드선 비)가
**사라진다.** 손 특징에서는 이것이 살아 있는 특징인데 CNN 입력에서는 죽는다.
⇒ **채널 2개**로 준다: ①peak-norm dB 맵 ②`dc_ac` 를 상수로 채운 채널.
아니면 CNN 특징벡터에 스칼라를 이어붙인다(late fusion). **어느 쪽인지 원장에 명시.**

### 2-3. 백본 — 데이터가 12k 밖에 없다

| 후보 | 파라미터 | 판단 |
|---|---|---|
| **ResNet18 (ImageNet 사전학습)** | 11 M | ⭐**A1 의 기본값.** 12k 로 scratch 는 과적합. 1채널→3채널 복제 |
| MobileNetV2 | 3.5 M | 가볍고 문헌에 많다(DIAT 계열). A1 의 두 번째 팔 |
| 4블록 소형 CNN (scratch) | ~0.3 M | 사전학습 없이 되는지 보는 대조군. **꼭 넣는다** — 사전학습 이득을 분리해야 한다 |
| **1D ResNet (A2·A3)** | ~0.5 M | 시계열용. 전역 평균 풀링 필수 |

⚠ **ImageNet 사전학습은 자연영상 통계다.** 스펙트로그램에 그것이 왜 도움이 되는지는
원리적으로 불분명하고, 문헌은 «되더라»로 쓴다. **scratch 대조군이 그래서 필요하다** —
사전학습이 실제로 얼마나 버는지 우리 수로 답한다.

### 2-4. ⭐평가 규약 — 여기가 진짜 설계다

합성 데이터 분류 논문이 실수하는 자리가 전부 여기다. **여섯 개를 못 박는다.**

| G | 무엇 | 왜 |
|---|---|---|
| **G1** | **leave-one-aspect-out 18겹** — RF 와 **글자 그대로 같은 분할** | 안 그러면 «딥러닝이 이겼다»가 «분할이 쉬웠다»와 구별 안 된다 |
| **G2** | **`no_flash` 대응 팔을 반드시 함께 낸다.** A3(접은 프로파일)는 자동, A1 은 **주파수축을 f_flash 로 정규화**해서 낸다 | §0 의 «특징 하나로 72.6 %». 이걸 안 하면 결과가 무의미하다 |
| **G3** | **시간 순환이동 증강**을 훈련에 넣고, **이동 불변성을 시험에서 측정** — 같은 시행을 0~1주기 이동시켜 예측이 바뀌는 비율 | arXiv:2402.13651 이 표준 CNN 의 실패로 보고한 것 |
| **G4** | **SNR 사다리** (+10 / 0 / −10 / −15 / −20 dB, `snr_slow_ac_db` 규약) — RF 와 같은 축 | RF100 의 0 dB 값 **0.8403** 이 비교선. 규약은 `NOISE_AND_ROTOR_PLAN.md` §1-2 |
| **G5** | **시드 3판** — 정확도 재현 **±2 포인트** | PathSolver 계획(T3)과 같은 기준 |
| **G6** | ⭐**open-set: 6기종 중 하나를 빼고 훈련**, 뺀 것을 «미지»로 판정 | 실전에는 훈련에 없던 기체가 온다. **6클래스 닫힌 집합 정확도는 실전 수치가 아니다** |

**⭐성공의 정의 — 미리 못 박는다.**
«딥러닝이 87.9 % 를 넘었다»는 성공이 **아니다.** 셋 중 하나여야 한다:
1. **typhoonh480 의 F1 이 0.646 에서 유의하게 오른다** (손 특징의 유일한 약점)
2. **`no_flash` 팔에서 손 특징(85.3 %)을 넘는다** (치트 없이 이긴다)
3. **잡음 사다리에서 열화가 완만하다** (0 dB 에서 RF 의 84.0 % 보다 낫다)

셋 다 아니면 «손 특징으로 충분하다»가 결론이고, **그것도 정직한 결과다.**

### 2-5. ⚠이 계획이 **하지 않는** 것

- **실측 데이터가 아직 없다.** White 의 «합성 훈련 → 실측 시험»은 **실측 전에는 못 한다.**
  지금 할 수 있는 것은 **합성 내부 일반화**(자세·시드·잡음)뿐이고, 리포트에 그렇게 적는다.
  ⭐실측 계획은 `docs/MEASUREMENT_PLAN.md`(X410 · Matrice 4E · Mini 5 Pro).
- **추적·경로는 안 쓴다.** 우리 태스크는 탐지·분류다([[sionna2-main-task-detection]]).
- **DIAT-µSAT 수치와 나란히 놓지 않는다** — §1-4 의 이유.
- **엔진은 우리 커널로 고정한다.** PathSolver 팔은 `PLAN_PATHSOLVER_CLASSIFY.md` T3 의
  일이고, **입력 표를 바꾸는 것뿐이라 이 계획과 직교한다.**

## 3. 착수 순서 — 상류부터

```
0층 (선행)   로터 랜덤성을 먼저 고친다 (NOISE_AND_ROTOR_PLAN §2)
             ↑ White TRS **2024** 가 «이것이 정확도를 좌우한다»고 이미 측정했다.
               고치기 전에 딥러닝을 돌리면 나중에 전부 다시 돌려야 한다.
1층         잡음 주입 배선 (NOISE_AND_ROTOR_PLAN §1) — G4 가 이것을 요구한다
2층         데이터 텐서화 — 표에서 시계열/STFT/접은프로파일 세 종을 뽑아 npz 로
3층         A1 (ResNet18 + scratch 대조군) → G1~G6 전부
4층         A3 (접은 프로파일 1D) → G1~G6
5층         reports/08_6_classification 에 «손 특징 vs 딥러닝» 절 추가
```

⭐**0층을 건너뛰지 않는다.** 지금 로터 모델(상수 rpm + 정현파 한 톤)로 딥러닝을 훈련하면,
신경망은 **우리가 틀렸다고 이미 아는 빗살 구조**를 학습한다. 그 위에 쌓은 정확도는
로터를 고치는 순간 전부 무효가 된다. [[upstream-first-ordering]]

## 4. 조사의 한계 — 정직하게

- **원문을 읽은 것은 없다.** 위 전부 초록·검색요약이다. 인용 전에 원문 확인이 필요하다
  ([[sionna2-priorwork-verify]]). 특히 White TRS 2023 의 **86.6 / 89.7** 두 수는
  **반드시 원문에서 확인**한다 — 우리 목표선이 될 수이므로.
- **«패시브 + DL + 기종분류 논문이 없다»는 이번 조사 범위의 결과일 뿐이다.**
  novelty 주장으로 쓰기 전에 더 넓은 조사가 필요하다.
- **DIAT-µSAT 의 97~99 % 수치는 우리와 비교 불가능**하다. 같은 표에 놓지 않는다.
