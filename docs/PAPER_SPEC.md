## 0. ⭐ 2026-07-31 재프레이밍 — 기하를 고정하지 않는다

사용자 지시:
> "우리가 하려고하는 태스크를 **패시브 바이스태틱으로 고정하는 것이 아니라**,
>  **모노스태틱으로도 벤치마크, 바이스태틱으로도 벤치마크** 한다는 프레임으로 잡아줘"

**기하를 결과에서 빼내 축으로 올린다.** 벤치마크는 **2 × 3** 이 된다.

|  | WiFi | LTE | 5G NR |
|---|---|---|---|
| **모노스태틱** (TX·RX 동일지점) | | | |
| **바이스태틱** (분리) | | | |

### 0.1 이 전환이 우리에게 유리한 세 가지

1. **RCS 가 원래 모노스태틱이 생산 경로다** — `rcs_sbr_batch` 가 모노다.
   바이스태틱은 상반성 위반 때문에 β≤45° 로 제한돼 있다.
   ⭐ 즉 **새로 얹는 모노 축이 우리 물리 중 가장 잘 검증된 부분 위에 선다.**
2. **선행 대조군이 생긴다** — LaSen(SenSys '26 게재)이 **모노스태틱 + PDSCH** 다.
   같은 축에 올려놓고 비교할 수 있다.
3. **부정적 결과가 설계공간 지도로 바뀐다** — "5G 패시브는 안 된다" 가 아니라
   **"어느 기하 × 어느 조명원이 어느 속도대를 덮는가"** 가 된다.

### 0.2 ⭐ 세 가지 구성을 구분한다 — 섞으면 틀린다

| 구성 | 송신 | 기하 | PRF 통제 | 예 |
|---|---|---|---|---|
| **A 능동 모노스태틱** | 내가 한다 | β≈0 | **설계변수** | LaSen |
| **B 패시브 준모노스태틱** | 남이 한다 | β≈0 (수신기를 기지국 옆에) | **불가** | — |
| **C 패시브 바이스태틱** | 남이 한다 | β 큼 | **불가** | 우리 기존 |

⚠ **"패시브 모노스태틱" 을 한 단어로 쓰지 말 것** — A 와 B 는 기하가 같고 **통제 자유도가 다르다.**
그 차이가 헤드라인 법칙의 전부다.

### 0.3 세 축이 서로 독립임을 유지한다

| 축 | 무엇이 바뀌나 | 기하 의존 |
|---|---|---|
| **기하** (모노↔바이) | 링크버짓 `1/R⁴` ↔ `1/(R₁²R₂²)` · 도플러 완화 `1/cos(β/2)` · 자세·가림 | — |
| **조명원** (WiFi/LTE/5G) | λ · 대역 · 상시신호 반복률 · 점유 | 무관 |
| **통제** (능동↔패시브) | PRF 가 설계변수인가 주어진 값인가 | 무관 |

⭐ **무모호 속도의 바닥은 기하와 무관하다** — 모노 = 바이 β=0 이고, 바이는 β 가 커질수록
**관대해진다**(β=90° 면 1.414배). 즉 우리가 인용해온 값이 **두 기하의 최악값**이다.
반대로 **링크버짓은 기하에 강하게 의존한다.** 두 효과를 절대 섞어 쓰지 않는다.

## 1. 대상 논문 — 확정형

> **Geometry × Illuminator: A Controlled Benchmark of Monostatic and Bistatic
> Drone Sensing on WiFi, LTE and 5G NR**
> *(부제안: Why the Ambient Reference Repetition Rate Decides What Passive Sensing Can See)*

**한 문장 기여**: 드론 센싱을 **기하(모노/바이) × 조명원(WiFi/LTE/5G)** 2×3 으로 통제 비교하고,
그 지도 위에서 **무모호 속도가 상시 기준신호의 반복률로 결정된다**는 것 — `v_max = λ·PRF_ref/4` —
그리고 그 한계가 **패시브에만 구속으로 작용한다**는 것을 보인다.

⭐ **옛 헤드라인은 이 지도의 한 행이 된다**: 규격이 상시를 보장하는 하향 기준신호 중
드론 속도대(5~20 m/s)를 덮는 것은 **LTE CRS 하나뿐**이고, 능동 모노스태틱(LaSen)은
**PRF 를 스스로 골라** 그 제약을 빠져나간다.

### 1.1 헤드라인 수치

| 상시 기준신호 | PRF_ref | f_c | v_max | 드론 5~20 m/s 를 덮나 |
|---|---:|---:|---:|---|
| LTE CRS (서브프레임당) | 1000 Hz | 1.843 GHz | **40.67 m/s** | **덮는다** |
| WiFi VHT-LTF (트래픽 1 kHz 가정) | 1000 Hz | 5.21 GHz | 14.39 m/s | 부분 (15 m/s 이상 접힘) |
| **5G NR SSB (기본 20 ms 주기)** | **50 Hz** | 3.5 GHz | **1.07 m/s** | 못 덮는다 |
| WiFi 비콘 (유휴 AP, 100 TU) | 9.77 Hz | 5.21 GHz | **0.14 m/s** | 못 덮는다 |

⟨`outputs/refrate_law.json : illuminators.rows.{lte_crs,wifi_vhtltf,nr_ssb,wifi_beacon}.v_max_ms`⟩

상시·고정반복 조명원 **12행**(셀룰러·WLAN·방송 3계열)의 v_max 는 **0.14 ~ 202.6 m/s, 1442배**로
벌어진다 ⟨`…: illuminators.ranking_ambient_fixed_prf` · `illuminators.headline.span`⟩.
**최악은 5G 가 아니라 유휴 WiFi 비콘이다** — 이 한 행이 법칙이 파형 이름이 아니라 반복률의
함수임을 증명한다 ⟨`…: illuminators.headline.note`⟩.

**인프라 서사**: LTE CRS → 5G SSB 로 갈아타면 상시 기준의 반복률이 **20.0배** 떨어지고
무모호 속도는 **38.0배**(40.67 → 1.07 m/s) 줄어든다. 파장 기여는 1.90배뿐이고 나머지가
반복률이다 ⟨`…: design_rule.lte_to_5g_migration`⟩. 원인은 파형 품질이 아니라 NR 의
**lean carrier 설계** — 셀 고유 상시 광대역 기준신호(LTE CRS)를 없앤 선택이다
⟨`outputs/vmax_hardening.json : C_frame.deep_cause`⟩.

### 1.2 ⭐ 의존성 논증 — 왜 이 논문이 제출 가능한가

헤드라인의 유도 사슬은 네 단계뿐이다.

| 단계 | 내용 | 지위 |
|---|---|---|
| 1 | 3GPP TS 38.213 §4.1 — SSB 버스트셋 주기 20 ms | 규격 조항 |
| 2 | 산술 — PRF = 1/T_ref = 50 Hz | 정의 |
| 3 | 나이퀴스트 — 슬로타임 표본화율 PRF 에서 `\|f_d\| < PRF/2` | 정리 |
| 4 | 운동학 — `f_d = v·(u₁+u₂)/λ` | 기하 |

**σ 는 이 사슬 어디에도 들어오지 않는다.** RCS·송신전력·CPI·대역폭 전부 무관하다
⟨`outputs/refrate_law.json : law.what_does_not_enter`⟩. 닫힌형은 저장소 기하 함수 대비
상대오차 **5.87e-07**(200 기하) 로, 접힘 개시점은 **1.34e-11** 로 검증된다
⟨`…: law.verification.V1_geometry_factor.max_rel_err` · `V2_nyquist_threshold[*].rel_err`⟩.

**대조군**: 이전 헤드라인 후보였던 절대 검출거리 R90 은 σ 에 dB(거리)/dB(σ) = 0.223~0.256 로
매달려 있고, 공통모드 ±10 dB 가 거리를 −43.3 % / +76.4 % 옮긴다
⟨`outputs/sigma_sensitivity.json : common_mode`⟩.

**결론**: 프로젝트에서 가장 약한 양(미검증 절대 RCS)이 헤드라인에 관여하지 않는다.
σ·검출사슬·Pfa 교정은 **헤드라인을 정량화하는 방법 계층**으로 내려간다.

| 모드 | 검출가능 | 무모호 | **둘 다** |
|---|---:|---:|---:|
| WiFi | 0.997 | 0.908 | **0.906** |

같은 표 안에서 보여주기 때문이다.

**⑷ 5G 전용 성질이 아님을 명시한다.** LTE 도 blind_hard = 1.000 이 CPI ≤ **0.0244 s**
에서 성립하고, 선언 규약이면 **0.0393 s** 까지다

낮은 파형만 걸림) 와 **B 진폭**(guard ≥ max|f_d|, 짧은 CPI 면 어떤 파형이든 걸림)
⟨`…: structural.two_mechanisms`⟩.

**⑸ 12.05배는 조건절과 함께만 쓴다.** ⚠ 이 배수는 **WiFi 패킷률 1000 Hz 가정 위에서만**
성립한다. 같은 "규격 보장 상시" 잣대를 대면 순위가 뒤집힌다
⟨`vmax_hardening.json : H_symmetry.headline_ratio_is_contingent`⟩. 헤드라인 숫자로 쓰지 않는다.

## 3. 투고처 계획 — 정직한 판정

⚠ **상위 학회는 좋은 논문을 대부분 떨어뜨린다.** 채택률은 품질 문턱이 아니라 경쟁 결과다.
아래의 "제출 가능"은 "채택된다"가 아니라 **"심사대에 세울 자격이 있다"** 는 뜻이다.

### 3.1 ICASSP — 4쪽 + 참고문헌, 채택률 ≈ 45 %, 신호처리 공동체

| | |
|---|---|
| **적합성** | 표본화·모호함수·검출. 헤드라인이 정확히 SP 문제다 |
| **가진 것** | 법칙 + 검증(5.87e-07) · 12종 교차표준 표 · 탈출구 6개 수치 판정 · 교정 Pfa 검출사슬 · 그림 7장 규격 |
| **없는 것** | 없다. 지금 있는 산출물로 4쪽이 찬다 |
| **위험** | 법칙 자체에 선행이 있다(Abratkiewicz 2023). 프레이밍이 **교차표준 정량화 + 탈출구 폐쇄 + 설계규칙**이어야 하고, "우리가 처음 발견"으로 쓰면 즉사한다 |
| **비용** | 집필 2주 · GPU 0 |

**판정: 지금 제출한다.** 4쪽 제약이 오히려 유리하다 — 법칙·표·탈출구 하나로 꽉 찬다.

### 3.2 MobiCom — 채택률 ≈ 16 %, 만들어서 배치한 시스템을 기대하는 시스템 문화

| | |
|---|---|
| **적합성** | 낮다. 시뮬 분석 논문은 이 문화에서 심사조차 통과하기 어렵다 |
| **가진 것** | X410 스펙 검토 · 원거리장/점표적/지면반사 계산표 · 대역별 ADC 여유(최소 19.2 dB) |
| **없는 것** | 동작하는 패시브 수신기 · 사이트 · RTK 지상진리 · **상용 셀 SSB 주기 배치 조사** · 다중 세션 |
| **비용** | 하드웨어 브링업 + 필드 캠페인 **수개월**, 그리고 "동작하지 않을 수 있다"는 위험 |

**판정: 캠페인이 논문 자체가 될 때만.** 시뮬 검증용 부록으로는 이 학회에 안 통한다.
E-ALIAS(§5) 를 여러 셀·여러 사이트로 확장해 **배치 관측 논문**으로 만드는 것이 유일한 경로다.

### 3.3 INFOCOM — 채택률 ≈ 19 %, 네트워킹 기여를 요구

| | |
|---|---|
| **적합성** | 서사는 맞다 — 인프라 전환(반복률 20배 감소)이 센싱 관측성을 정한다 |
| **가진 것** | 마이그레이션 분해(20.0배 반복률 · 1.90배 파장 = 38.0배) · lean carrier 인과 · 설계규칙 역산 |
| **없는 것** | **네트워크 층 실체** — 다중 셀 모델, 사업자 설정 비용(SSB 5 ms 로 낮출 때의 오버헤드·에너지·용량 대가), 배치 시사점, 커버리지-관측성 트레이드오프의 네트워크 규모 분석 |
| **비용** | 모델링 연구 1~2개월 + 가능하면 사업자 규모 데이터. 지금 없는 것이 논문의 절반이다 |

**판정: 아직 아니다.** "5G 가 패시브 센싱에 나쁘다"는 네트워킹 기여가 아니다. 기여가 되려면
**"사업자가 무엇을 얼마에 바꾸면 관측성이 얼마 회복되나"** 를 네트워크 규모로 답해야 한다.

### 3.4 ⭐ 시퀀싱 — 거절 위험을 관리하는 순서

| 순서 | 행동 | 이유 |
|---|---|---|
| 1 | **ICASSP 제출** (분석 논문) | 지금 있는 것으로 완성된다. 떨어져도 원고·그림·JSON 이 전부 재사용된다 |
| 2 | **동시에 캠페인 실행** (E-ALIAS 우선) | ICASSP 심사 기간이 캠페인 기간과 겹친다. 결과가 나오면 카메라레디에 한 문단 추가 가능 |
| 3 | **거절 시 저널 폴백** | *IEEE JSTARS* (Abratkiewicz 가 실린 곳 — 공동체가 이미 이 문제를 안다) · *IEEE Trans. AES* · *IET Radar Sonar Navig.* 8쪽 이상이라 탈출구 6개를 다 실을 수 있다 |
| 4 | **캠페인 성공 후 INFOCOM** | 실측 SSB 주기 분포 + 네트워크 층 비용 분석이 붙으면 그때 기여가 선다 |
