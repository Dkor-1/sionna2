# 실외 실험 설계·표현 검토 메모

현재 실외 조사에서 구현·설계·문구가 서로 다른 범위의 증거를 말하는 자리를 정리했다. 사용자 요청에 따른 작업 메모이며 발표용 결과 리포트가 아니다.

검토 항목은 18개다. 전체 저장소 전수조사가 아니라 아래에 연결한 실외 스윕·집계·필터·발주서·리포트 빌더와 직전 진단 코드가 범위다. 파일의 상태를 고정한 검사는 [검산 원장](../outputs/outdoor_design_review_checks_0908.json)의 소스 해시를 따른다.

**읽는 순서:** 기체별 분석 대역 → 조건부 재질·중복 제거 오류 → 데이터 완전성·상한 → 인과 해석과 필터 평가 → 철회 문구의 잔존 순으로 본다. 구현 오류의 존재와 기존 실외 낙차의 원인은 구분한다.

**이번에 한 일:** 실제 소스 구문을 작은 합성 입력으로 실행하고 대역 계산 함수를 대조했다. GPU 솔버 재실험, 실행 중 큐 변경, 분석 코드 수정, 기존 리포트 재빌드는 하지 않았다. 현재 큐의 설정에 직접 해당하지 않는 문제도 조건을 붙여 기록했다.

## 1. 기체 교체 결과를 읽는 도플러 대역에 날개 반경이 빠져 있다

**상태:** 구현 불일치 확인 · 새 기체 결과 해석 전 우선 점검

comb_snr.f_tip은 기준 기체의 대역 상한에 날개 통과율 비를 곱한다. 회전수와 날개 수는 이 비에 들어가지만 기체별 날개 반경과 프롭 배율은 들어가지 않는다. 반면 elevation_sweep_md.f_tip_at은 prop_dia_mm와 프롭 배율을 사용한다. 반송파 3.5 GHz·앙각 -60°·각 기체의 등록 회전수 조건에서 Mini 5 Pro 상한은 920.57 대 512.37 Hz, Phantom 4는 920.57 대 806.88 Hz다. 이는 같은 저장소의 계산식 비교이며 외부 계측 검증이 아니다. 검산 원장: tip_band_comparison.

**권장 표현:** 기체별 빗살 지표는 날개 통과율과 날개끝 도플러 대역을 각각 제원에 맞춘 뒤 비교한다.

## 10. 장면 신호 차이와 경로 목록의 증거가 같은 뜻으로 쓰인다

**상태:** 관측량과 해석의 혼용 확인

**권장 표현:** 장면 추가에 따른 복소 신호 차이의 변화를 관측했다. 직접 대조한 경로 목록의 범위에서 누락을 확인했다.
