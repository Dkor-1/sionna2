# 두 엔진의 물리 대조 — 무엇이 들어 있고, 이번 실행에서는 무엇이 켜져 있었나

> 원장: `outputs/engine_physics_matrix.json`
> 조사 방식: 소스 직독 + 기존 npz 를 numpy 로 다시 계산. **GPU 미사용.**
> 대상 실행: `benchmark/elevation_sweep_md.py` (matrice4e · 3.5 GHz · 구면 10 m · 앙각 7점)

---

## 쉬운 말 요약

1. **이번 실행에서는 두 팔 다 모서리 회절이 꺼져 있었고, 셸을 뚫는 투과는 우리 팔만 켜져 있었다.** 그러니 "PathSolver 가 굴절·회절을 더 잘 담는다" 는 이번 대조에 대해서는 사실이 아니다.
2. **원리로 보면 이야기가 반대로 뒤집히는 자리도 있다.** Sionna 는 유전체 쐐기에도 붙는 UTD 회절, 두께를 보는 슬래브 투과, 확산 산란, 완전 편파를 갖고 있다. 우리는 그중 확산과 편파가 아예 없다.
3. **"평면파 가정" 부분은 틀렸다.** 우리 팔도 `range_m=10` 으로 구면파였다. 그리고 Sionna 도 평면 가정에서 자유롭지 않다 — 면마다 **무한 평면 거울**로 보고, 정반사점에서 파면이 새로 퍼지지 않는다.
4. **직하방에서 도플러가 남는다는 관찰은 맞고, 원인은 회절이 아니라 기하다.** 시선축을 도는 강체는 평면파에서 원리적으로 도플러를 만들 수 없다(어떤 물리를 넣어도). 실제로 남는 것은 ① 파면 곡률(10 m 에서 −38.5 dB), ② 시선이 몇 도 어긋난 것(2°면 −32.8 dB), ③ 편파(우리가 못 내는 채널) 때문이다.
5. **지금 GPU 에서 도는 대조는 이 질문에 반쯤만 답한다.** `--physics` 는 네 스위치를 한꺼번에 켜서 귀속이 안 되고, `ours --ptd` 는 **블레이드에는 한 조각도 안 붙는다**(날개가 플라스틱인데 우리 PTD 는 금속 모서리 전용이다).

## 0. 이번 실행이 실제로 부른 것

**우리 팔** (`elevation_sweep_md.py:134`)

```python
E[j] = sbr_field(mv, gm, FC, u, spacing=d, grid_ref=gref,
                 range_m=RANGE_M, ptd=bool(a.ptd))
```

기본값이 그대로 걸린 것: `penetrate=True`(투과 O) · `ptd=False`(모서리 회절 X) · bounce 는 구조적으로 1회(이 함수에는 bounce 루프 자체가 없다) · `range_m=10.0`(구면파) · `ANGLE_GAMMA=1`(각도의존 |Γ|).

**Sionna 팔** (`elevation_sweep_md.py:176-183`)

```python
p = RP.rt.PathSolver()(
    sc, los=True, specular_reflection=True, diffuse_reflection=True,
    max_depth=(3 if a.physics else 1),
    refraction=bool(a.physics),      # 기존 실행 = False
    diffraction=bool(a.physics),     # 기존 실행 = False
    edge_diffraction=bool(a.physics),
    samples_per_src=spp, ...)
```

`PathSolver` 의 `refraction` **기본값은 True 인데 이 스크립트가 명시적으로 껐다.** `diffraction`/`edge_diffraction` 은 Sionna 기본값이 False 라 안 켠 것이다.

### 표에서 읽어야 할 것

- **이번 실행의 불공정은 양방향이다.** 투과는 우리만 켰고(우리 유리), 확산 산란과 편파는 Sionna 만 갖고 있다(저쪽 유리). "우리 팔이 물리를 더 담고 있었다" 는 **투과 축에 대해서만** 참이다.
- **회절은 두 팔 다 꺼져 있었다.** 다만 원리로는 Sionna 쪽이 넓다 — 우리 PTD 는 금속 모서리에만 붙고 Sionna 의 UTD 는 유전체 쐐기에도 붙는다.
- **진짜 비대칭은 맨 아랫줄 하나다.** 회절·굴절 스위치가 아니라 **표면 적분의 유무**가 두 엔진을 가른다.

## 2. R6 과의 정합 — "스톡 Sionna 에 회절이 없다" 는 우리 오류였다

`docs/RETRACTION_LOG.md` R6 은 이렇게 적어 두었다.

> **우리 오류다.** 기술보고서 p.47 에 **1차 UTD 쐐기회절이 구현**돼 있다(Kouyoumjian–Pathak 을 Luebbers 가 유한도전율로 휴리스틱 확장한 판). 우리 설치본 2.0.1 이 `diffraction=False` / `edge_diffraction=False` 로 **기본값이 꺼져 있을 뿐**이다.
> ⚠ 반대 방향 오류도 금지: *"Sionna UTD 가 우리 PTD 결손을 메운다"* 도 **거짓**이다 — Sionna 의 D 는 **전파경로의 필드 전달**용이지 표적 산란단면 산출이 아니다.

이번 소스 직독은 그 철회를 **한 글자도 뒤집지 않고 확인**한다.

- 구현 위치: `sionna/rt/radio_materials/radio_material.py` `_diffraction_matrix()` (964–1144행). 구조는 `D = −(D1+D2) + R_0·D4 + R_n·D3`, 전이함수는 `utils/electromagnetics.f_utd`. 두 쐐기면의 Fresnel 반사계수가 회절계수 안에 곱해지는 것이 곧 Luebbers 휴리스틱이다.
- 쐐기 탐색: `utils/wedges.sample_wedge_diffraction_point()` — 표면 히트점을 **실루엣에 투영**해서 회절 모서리를 뽑는다. `edge_diffraction=False` 면 서로 다른 프리미티브 사이의 모서리만, `True` 면 열린 경계(자유 부유) 모서리까지.
- 1차 한정: `sb_candidate_generator.py` — *"Only first order diffraction is supported."* 그리고 회절과 확산반사는 같은 경로에 못 섞인다.
- 표본 배분: `sb_candidate_generator.py:49` `DIFFRACTION_SAMPLING_PROBABILITY = 0.2` — 회절을 켜면 고정 확률 20 %가 회절로 간다.

**그리고 R6 의 두 번째 문장이 이번에도 그대로 산다.** Sionna 의 UTD 는 경로 필드 전달용이고, 우리 PTD 는 산란단면 적분에 더하는 항이다. 같은 물리(Ufimtsev/Keller 계열)를 **다른 사용처**에 쓴다. 한쪽이 다른 쪽의 결손을 메우지 않는다.

## 3. ⭐ 판정 1 — 모서리 회절이 이 표적에서 얼마나 중요한가

### 3.1 표적의 전기적 크기부터

`src/drone_cad.py` 의 블레이드 법칙 상수와 `src/drones.py` 의 `matrice4e.prop_dia_mm=274` 로 직접 계산했다(3.5 GHz, λ=85.66 mm).

| 항목 | 값 | λ 대비 |
|---|---|---|
| 블레이드 반경 | 137 mm | **1.60 λ** |
| 최대 시위(코드) | 33.9 mm | **0.40 λ** |
| 최대 두께 | **2.99 mm** | **λ/28.7** |

> ⚠ **지시문 정정.** "블레이드 두께 6.5 mm = λ/13" 은 단위를 잘못 읽은 것이다. 6.5 는 **두께비 6.5 %**(`TC_TIP=0.065`)이고, 절대 최대두께는 2.99 mm = **λ/28.7** 이다. 실제 날개는 지시문이 가정한 것보다 두 배 더 얇다.

이 크기가 뜻하는 것: **1차 UTD 도 1차 PTD 도 이 날개에서는 점근 영역 밖이다.** 두 이론 모두 "모서리가 고립돼 있고 인접면이 여러 λ 에 걸쳐 평평하다" 를 전제하는데, 이 날개는 앞전과 뒷전이 **0.40 λ** 떨어져 있어 서로의 근접장 안에 있다. 그리고 Sionna 는 2차 회절을 지원조차 하지 않는다(기술보고서 §3.4: *high-order diffraction is not currently supported*). **이 축에서는 두 엔진이 똑같이 취약하다.**

### 3.2 PTD 를 켜고 끈 비교 — 있다 (기체 전체에 대해서만)

원장 `outputs/ptd_wiring.json`, 키 `F_effect_size`. (⚠ `ptd_edges.py` 해시는 현재 파일과 같지만 `rcs_sbr.py` 해시는 그 뒤에 바뀌었다 — 배선은 같고 절대 레벨은 그때 값이다.)

`production_drones_8az` — 생산 SBR 경로, div=16, 방위 8점 평균:

| 기체 | fc | el | PO만 [dBsm] | PO+PTD [dBsm] | 자세별 최대 변화 |
|---|---|---|---|---|---|
| mavic4pro | 3.5 GHz | 15° | −16.047 | −16.497 | **2.616 dB** |
| mavic4pro | 1.843 GHz | 0° | −15.808 | −16.183 | 2.045 dB |
| mini5pro | 3.5 GHz | 15° | −20.688 | −20.855 | 0.803 dB |
| mini5pro | 1.843 GHz | 0° | −22.614 | −22.723 | 1.878 dB |

`grid_dependence` (div=12, 우리 실행과 같은 격자): 평균 레벨이동 **+0.554 dB**, 자세별 rms **0.453 dB**, 최대 **1.387 dB**. 격자를 div 12→24 로 바꿔도 레벨이동은 0.060 dB 밖에 안 흔들리는데 PO 절대레벨 자체는 같은 구간에서 0.566 dB 흔들린다 → **프린지 보정은 격자보다 강건하다.**

**요약: 기체 전체에서 모서리 회절은 방위평균으로 0.5~0.6 dB, 자세별로는 최대 ±2.6 dB 다.** 무시할 크기는 아니지만 판을 뒤집는 크기도 아니다.

### 3.3 ⛔ 그런데 블레이드에는 우리 PTD 가 한 조각도 안 붙는다

사슬은 세 줄이다.

```
src/drones.py       DRONE_GROUP_MAT['prop'] = 'prop_plastic'
src/materials.py    MATERIALS['prop_plastic']['gamma_po'] = 0.25
src/ptd_edges.py    GAMMA_METAL_MIN = 0.999,  edge_field(metal_only=True) 기본
```

`metal_only=True` 는 **양쪽 인접면이 모두 |Γ|≥0.999** 인 모서리에만 프린지를 붙인다. 플라스틱(0.28)·프롭(0.25)·카본(0.90)·PCB(0.80)·카메라(0.85) 는 전부 탈락한다. 실측된 금속 모서리 길이비는 mavic4pro **0.143**, mini5pro **0.149** 다(같은 원장 `F_effect_size`).

**결과: 지금 도는 `ours --ptd` 는 모터·배터리 같은 금속 모서리만 켠다. 그 모서리들은 로터가 도는 동안 정지해 있으므로, 프린지 항은 거의 상수 복소수를 더할 뿐이다 — 캐리어를 옮기고 변조 깊이를 바꾸지만 새 변조를 만들지 않는다.** 즉 "얇은 날개 모서리가 마이크로도플러를 바꾸나" 라는 질문에는 이 실행이 답하지 못한다.

날개까지 켜려면 `edge_field(metal_only=False)` 로 넘겨야 하는데, 지금 CLI `--ptd` 는 `ptd_opts` 를 안 넘기므로 코드 수정이 필요하다. 그리고 **프린지 계수 자체가 PEC 유도**라, 유전체 날개에 그냥 붙이면 그건 우리가 지금까지 거부해 온 휴리스틱이 된다 — 공교롭게도 **Sionna 의 Luebbers 확장이 정확히 그 휴리스틱**이다.

### 3.4 어디서 커질지에 대한 예상 (측정 아님)

평판 정면입사에서 PO 는 **정확**하다(4πA²/λ² 는 점근이 아니라 PO 의 정답). 모서리 항이 커지는 자리는 비스듬한 입사와 edge-on 이다. 마이크로도플러의 **플래시**는 브로드사이드 정반사에서 나오므로 PO 가 잘 맞는 자리다. ⇒ 모서리 회절이 주로 바꾸는 것은 f_flash·f_tip 의 **위치**가 아니라 **플래시 사이의 바닥**, 곧 플래시 대 바닥 대비일 것이다.

## 4. ⭐ 판정 2 — 굴절(투과)의 불공정이 결과를 얼마나 흔드나

### 4.1 무엇이 어긋났나

- 우리 팔: `penetrate=True` → 셸을 뚫고 배터리·PCB 를 코히어런트로 더했다.
- Sionna 팔: `refraction=False` → 셸이 불투명. 내부 금속이 씬에 있어도 광선이 도달하지 못한다.

우리 커널이 같은 상황을 직접 검증해 둔 문장이 `src/rcs_sbr.py:100` 에 있다 — *"SBR first-hit 은 셸을 불투명 처리해 내부 금속을 삭제한다(직접 검증: battery/pcb **0 히트**)"*. Sionna 팔은 이번 실행 내내 그 상태였다.

### 4.2 `--physics` 로 켜도 여전히 공정하지 않다

`src/materials.py` `make_material()` 은 커스텀 재질(plastic/prop_plastic/carbon/absorber)에 **두께를 안 넘긴다** → Sionna 가 `constants.py:80` 의 `DEFAULT_THICKNESS = 0.1 m` 를 쓴다. 실제 셸은 1~3 mm 다.

ITU 슬래브 식을 직접 계산했다(plastic εr=2.7 · σ=0.02 S/m · 3.5 GHz · 수직입사):

| 두께 | \|R_TE\| | \|T_TE\| | 편도 | 왕복 |
|---|---|---|---|---|
| **100 mm (Sionna 기본)** | 0.2142 | 0.7644 | −2.33 dB | **−4.67 dB** |
| 2 mm (실제 셸) | 0.1219 | 0.9852 | −0.13 dB | −0.26 dB |
| **우리 커널** τ=1−\|Γ\|², \|Γ\|=0.28 | (0.28) | — | — | **−0.71 dB** |

즉 `--physics` 실행에서 Sionna 는 **10 cm 두께 플라스틱 판**을 뚫는 계산을 한다. 우리보다 왕복 4 dB 더 죽이고, 슬래브 간섭 무늬도 다르다.

### 4.3 얼마나 흔들 수 있나 (가늠이지 측정이 아니다)

내부 금속은 우리 σ 에서 지배적 산란체 중 하나다(금속 |Γ|≈1.0 vs 플라스틱 0.28). 투과를 아예 막으면 그 기여가 0 이 되고, 넣더라도 왕복 감쇠가 4 dB 다르면 그 성분의 상대 가중이 그만큼 달라진다. **레벨 차이보다 자세별 간섭 무늬의 차이가 더 클 수 있다** — 코히어런트 합의 상대위상이 바뀌기 때문이다.

공정하게 만들려면 `make_material` 이 실제 셸 두께를 Sionna 에 넘겨야 한다. 그런데 `docs/RETRACTION_LOG.md` A3 이 적어 둔 대로 **셸 두께야말로 우리가 출처를 못 댄 값**이다.

## 5. ⭐⭐ 판정 3 — 직하방에서 회절이 도플러를 만들 수 있는가

### 5.1 대칭 정리 — 만들 수 없다

**주장.** 시선 û 와 **평행한 축**을 중심으로 강체가 회전할 때, 평면파 모노스태틱 후방산란장은 시간에 대해 **정확히 불변**이다. 담긴 물리가 무엇이든(PO·PTD·UTD·다중반사·투과·크리핑파) 상관없다.

**왜 그런가.** 모든 기전의 기여는 경로길이와 û 에 대한 국소 기하에만 의존한다. 회전 R 은 û 를 고정한다(Rû = û).

- 면적분 위상: (R p)·û = p·(Rᵀû) = p·û → 불변
- 모서리 회절 위상: q = 2û 이므로 (R R_c)·û = R_c·û → 불변
- UTD/PTD 계수: β₀ = ∠(û, t̂) 는 회전이 각을 보존하므로 불변. φ, φ′ 는 쐐기 국소틀에서 재는데 쐐기와 û 의 수직성분이 **함께** 돌므로 역시 불변
- 조명·가림 게이트: n̂·û 불변, first-hit 집합은 회전된 상 그대로

⇒ E(t) = const. **도플러 0.**

**회절점의 위상 중심은 회전하면 움직이는가?** 정지위상점(회절점)은 회전하면 **같은 z·같은 ρ 를 갖는 상(像)** 으로 옮겨간다. 시선 방향으로는 한 발짝도 움직이지 않는다. 그래서 회절은 나딧 도플러를 만들지 못한다.

이 정리는 우리 원장이 이미 수치로 확인했다 — `outputs/verify_nadir_flash.json` `C_D_geometry.nadir_plane_wave_ac_over_dc_db` = **−305.01 dB**(수치 0).

### 5.2 그럼 무엇이 대칭을 깨나 — 셋이고, 셋 다 회절이 아니다

**① 파면 곡률(근접장).** 로터 축은 시선과 평행하지만 **시선 위에 있지 않다**(팔 반경 a=0.2194 m). 파면이 휘어 있으면 거리에 ρ²/2R 이 더해지는데 ρ² = a²+r²+2ar·cos φ 라 로터 위상에 걸린다. **거리 변조 = 진짜 도플러**다.

`outputs/verify_nadir_flash.json C_D_geometry` (CPU 기하 대리모형):

| 조건 | AC/DC |
|---|---|
| 평면파 나딧 | **−305.01 dB** (0) |
| 구면파 10 m 나딧 | **−38.55 dB** |
| 같은 조건, 프롭만 | −41.51 dB |
| 같은 조건, 동체만 | −312.25 dB (안 돈다) |
| **SBR 커널 실측** (`ours/el-90`) | **−38.31 dB** |

대리모형과 실측이 **0.24 dB** 안에서 맞는다. 그리고 거리를 늘리면 죽는다: 10 m −38.55 → 100 m −79.35 → 1000 m −119.41 dB (≈1/r⁴).

**② 시선이 몇 도 어긋난 것.** 같은 원장 `offnadir_farfield` — **원거리장**(평면파)인데도:

| 나딧에서 벗어난 각 | AC/DC |
|---|---|
| 0.0° | −305.01 dB |
| 0.5° | −55.85 dB |
| 1.0° | −44.09 dB |
| **2.0°** | **−32.81 dB** |
| 5.0° | −11.88 dB |
| 10.0° | −1.21 dB |

⭐ **정확히 직하방은 실험에 존재하지 않는다.** 2° 만 어긋나도 근접장 효과(−38.5 dB)보다 **큰** 변조가 돌아온다. 호버 중 기체 자세각·짐벌·바람만으로도 몇 도는 쉽게 난다.

**③ 편파.** 시선축을 중심으로 이방성 산란체가 돌면 고정된 실험실 편파 기저에서 본 co-pol 응답은 2φ 로 변조된다(회전 다이폴). 2블레이드 로터에서 그 주파수는 정확히 f_flash 다. **평면파·원거리장에서도 남는다.** Sionna 는 완전 Jones 라 원리적으로 낼 수 있고, **우리 스칼라 면적분은 구조적으로 못 낸다.** ⚠크기는 미지수다 — 날개 면이 시선에 수직에 가까우면 r⊥≈r∥ 라 사라지고, 피치·트위스트로 비스듬한 만큼만 산다.

**④ 남은 교란(배제 안 됨).** 얼린 격자는 공간에 고정돼 있고 날개는 돈다. 표본점 집합의 churn 은 블레이드 통과 주기와 같으므로 **역시 f_flash 에 선을 만든다.** 실측 AC 전력의 **40.2 %가 2 kHz 이상 광대역**이라는 사실이 이 성분의 존재를 보여 준다. 근접장 대리모형과의 0.24 dB 일치는 강한 정황이지만, 격자 사다리로 직접 못 박은 적은 없다.

`outputs/elevation_sweep_md.npz` 의 복소 시계열에서 평균(캐리어)을 빼고 FFT (prf=19700 Hz, n=4096, bin 4.81 Hz):

|---|---|---|---|---|---|
| `ours/el-90` | **−38.31 dB** | **125.05 Hz** (= f_flash 126.67 의 인접 빈) | 47.3 % | 40.2 % | — |

⭐ **Sionna 팔은 나딧 질문에 답할 수 없다.** 그 팔의 자체 표본잡음(11.1 M spp 에서 AC/DC −0.11 dB, 2.5억 spp 로도 −11.35 dB)이 우리 팔이 재는 잔여(−38.3 dB)보다 **27~38 dB 크다**. 물리를 켜고 끄는 것과 무관하게, 이 예산에서는 신호가 잡음 아래 있다.

### 5.4 위상이지 진폭이 아니다

`outputs/adv_nadir_pm_over_am_refute.json` `rows['ours/el-90']`: `am_rms` 0.00478 · `pm_rms_deg` **0.64°** · `pm_over_am_db` **+7.37** · 1x 고조파에서 **+15.09 dB**.

나딧 잔여는 **진폭이 아니라 위상**이 지배한다. 이것이 근접장 거리변조 가설과 정확히 맞는다 — 시선축 회전은 조명면적·obliquity 를 안 바꾸고 **거리만** 바꾸기 때문이다. ⚠단 나딧 일반명제는 아니다: 같은 원장에서 `sionna/el-90` 은 `pm_over_am_db = −1.16`(진폭 우세)인데, 그 팔은 표본잡음이라 그렇다.

### 5.5 사용자 관찰에 대한 답

> "들어보니까 실제로 실증 실험했을때도 도플러가 남는거같더라고"

**맞는 관찰이고, 원인은 회절이 아니라 기하다.** 실제 실험에서 정확한 직하방은 존재하지 않고(2° 만 어긋나도 −32.8 dB), 근거리라면 파면 곡률이 더해지며(10 m 에서 −38.5 dB), 편파를 재는 수신기라면 회전 산란행렬이 f_flash 에 선을 남긴다. **셋 다 회절 없이 성립한다.**

## 7. 지금 GPU 3 에서 도는 대조가 답해 줄 것 / 못 할 것

### `sionna_phys` 가 답해 주는 것

- "Sionna 의 물리를 다 켜면 이 표적의 에코 레벨과 시계열이 얼마나 달라지나" — **한 덩어리로.**

### `sionna_phys` 가 못 답하는 것

- ⛔ **어느 스위치 때문인지 못 가른다.** `--physics` 는 네 가지(`max_depth` 1→3 · `refraction` · `diffraction` · `edge_diffraction`)를 한꺼번에 켠다. 단일축이 아니다.
- ⛔ **refraction 비교가 공정하지 않다.** 커스텀 재질에 두께를 안 넘겨서 Sionna 는 플라스틱을 0.1 m 판으로 본다(§4.2).
- ⛔ **표본 배분이 같이 바뀐다.** `diffraction=True` 면 `q(D)=0.2` 고정 확률이 걸려(`sb_candidate_generator.py:49`) 정반사·투과·확산에 갈 표본의 20 %가 회절로 간다. 같은 spp 에서 정반사 추정이 더 시끄러워진다 → **레벨 변화의 일부는 물리가 아니라 분산이다.**
- ⛔ **나딧(el −90)에는 답 못 한다.** 표본잡음이 재려는 효과보다 27~38 dB 크다(§5.3).

### `ours_ptd` 가 답해 주는 것

- 금속 모서리(모터·배터리)의 1차 프린지 항이 이 자세열의 레벨·위상열을 얼마나 바꾸나.

### `ours_ptd` 가 못 답하는 것

- ⛔ **블레이드 모서리 회절은 손도 못 댄다** — 날개가 `prop_plastic`(|Γ|=0.25)이고 `metal_only=True` 가 |Γ|≥0.999 만 통과시킨다(§3.3).
- ⛔ 금속 모서리는 안 도니까 프린지 항은 거의 상수를 더한다 → **새 변조를 만들지 않는다.**
- ⚠ 광선격자 λ/12 는 PTD 권고 λ/20 미만이라 커널이 경고를 낸다(`rcs_sbr._ptd_spacing_warn`, D-8). 이 판의 PTD 숫자는 격자 의존성을 함께 보고해야 한다.

## 8. 필요한 GPU 실행 (여기서는 안 돌렸다)

1. **단일축 분해** — sionna 팔을 (a) diffraction 만, (b) refraction 만, (c) `max_depth=3` 만 으로 **세 판 따로**. 지금 한 덩어리로는 귀속 불가.
2. **나딧 대칭 정리 직접 확인** — `ours --els -90` 을 `range_m=None`(평면파)으로 한 판. 예측: AC/DC 가 −38 dB 에서 수치 0 으로 떨어진다. 근접장 가설과 격자 churn 가설을 **가른다**.
3. **격자 사다리** — `ours --els -90` 을 λ/12 · λ/20 · λ/24 로. >2 kHz 성분(40.2 %)이 줄어드는지 본다.
4. **블레이드 PTD** — `edge_field(metal_only=False)` 를 넘길 수 있게 CLI 를 고친 뒤 재실행. ⚠결과를 "PEC 유도 계수의 유전체 근사" 라고 명시해야 한다.
5. **공정한 refraction** — `materials.make_material` 이 실제 셸 두께를 Sionna 에 넘기도록 고친 뒤 `sionna --physics` 재실행. ⚠셸 두께는 출처가 없는 값이다(RETRACTION_LOG A3).
6. **나딧에서 Sionna 표본잡음을 f_flash 선 아래로** — 2.5억 spp 로도 −11.35 dB 다. 필요한 예산 규모를 재는 짧은 사다리부터.

## 9. 아직 모르는 것 (모른다고 적는다)

- 블레이드(플라스틱, 코드 0.40 λ) 모서리 회절의 **실제 크기** — 두 엔진 어느 쪽으로도 잰 적이 없다.
