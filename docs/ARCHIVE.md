## A. 도구의 경계 — Sionna RT 는 무엇을 하고 무엇을 안 하나

| | 판정 | 근거 |
|---|---|---|
| **환경 전파** (벽·바닥·다중경로) | **정확하다. 쓴다.** | 바닥 반사를 19.3 ns / −14.7 dB 로 찾음. 거울상+프레넬 독립계산과 **0.02 dB** 일치 |
| **표적 RCS** | **못 준다.** | 아래 |

**"광선을 더 쏘면 되지 않나?" — 4억 발로 반증 (재현: `benchmark/verify_rt_rays.py`)**
- 광선 100M → 400M: 코히어런트 합이 **+8~12 dB 계속 커짐**. 수렴하지 않는다.
- 산란계수 **S 2배 → +15 dB**. 값이 드론과 무관한 **재질 노브의 함수**다.
- **ITU `metal` 은 S = 0** → 모터·배터리·PCB·카메라(σ의 대부분)가 **확산 채널에 기여 0**.
- 금속 평판 변 0.2→4 m (σ 52 dB 변화) → RT 진폭비 **−7.91 dB 불변**(산포 0.00 dB).

> **σ 는 적분에서 나온다.** GO(기하광학)는 표면을 '국소 무한 거울'로 보므로 면적 항이 없다.
> Sionna 가 틀린 게 아니라 **전파용 도구**다. 메인테이너도 "RCS is not supported out of the box".

**⛔ 절대 쓰면 안 되는 문장**: *"레이트레이싱은 RCS 를 못 낸다"* — **거짓**. SBR(GO+PO)은 계산한다.
**✅ 참인 명제**: *"산란적분 단계가 없는 전파용 path solver(Sionna RT 기본)에서는 σ 가 창발하지 않는다."*

## B. SBR — PO 를 광선추적 **안으로** 넣었다 (`src/rcs_sbr.py`)

상용 EM 솔버(FEKO/CST/HFSS SBR+)의 표준 방법. 광선이 조명면을 찾고(**가림 포함**), 그 위에서 PO 표면적분.

핵심: **PO 적분을 투영면 적분으로 바꾸면 비스듬함 계수가 상쇄**된다
→ 평행 광선 격자(간격 d)가 곧 PO 적분:  `E = Σ_hits |Γ_i|·e^{j2k p_i·û}·d²`,  `σ = 4π/λ²·|E|²`

- **검증**: 금속평판 **−0.01 dB**, 금속구 **+0.39 dB** (해석해 대조)
- **가림의 대가**: 기존 순수 PO 는 RCS 를 **+4~5 dB**, 마이크로도플러 |DC|/std(AC) 를 **22 dB** 과대평가
- **오목부 다중반사**: **−0.23 dB 뿐** — "PO 는 오목부를 못 한다"는 오래된 caveat 이 숫자가 됨

## D. 챔버 — semi-anechoic, 그리고 클러터는 죽은 파라미터

- **챔버는 anechoic 이 아니다.** 흡수체는 **벽 4면 + 천장**뿐, **바닥은 반사성 콘크리트**(ITU concrete).
  → 정의상 **semi-anechoic(ground-plane) 챔버**.
- **정적 클러터는 어떤 수치에도 도달하지 못한다** (삼중 차단):
  ① ECA 사영(도플러 없는 지연복제 = ECA 기저 부분공간 → 진폭 무관하게 정확히 0)
  ② 잔류는 0-도플러 행에 앉음  ③ 그 행이 CFAR 에서 삭제됨(`det[zd,:]=False`)
  → **직접파보다 14 dB 센 클러터를 넣어도 SCR 이 1.5e-9 dB 움직인다.**
- ⛔ **폐기된 서사**: *"무반사라 클러터가 약하다"*, *"RT≈Analytic 이므로 클러터 모델이 검증됐다"*(항등식이었다)

**진짜 위협 = 표적 경유 바닥 유령** (TX→표적→바닥→RX). 표적과 함께 **도플러가 실려 ECA 를 통과**한다.
- 진짜 표적 대비 **+3.53 m, −18.1 dB** (순전히 기하 — 파형과 거의 무관)
- 갈리는 건 **거리분해능**뿐: 5G(ΔRb 3.1 m) → 1.16×ΔRb → **100% 가짜 표적 검출**.
  WiFi(0.89×)·LTE(0.21×)는 병합돼 0%.
- ⇒ **광대역의 장점이 그대로 오경보로 되돌아온다.** (report4/5 옛 수치엔 미반영)

## E. 파형 — 자작 구현이 Sionna 와 비트 단위로 일치

`sionna.phy.ofdm.OFDMModulator` 로 같은 자원격자를 재변조해 대조:

| 파형 | 상관 | NMSE |
|---|---|---|
| WiFi 802.11ac | **1.0000** | −136.7 dB |
| LTE Rel-9 | **1.0000** | −135.3 dB |
| 5G NR Rel-16 | **1.0000** | −135.0 dB |

⚠ 정직하게: **Sionna PHY 에 WiFi/LTE 는 없다**(5G NR 만). SSB 생성기도 없다.
→ `waveforms.py` 를 버리지 않는다. Sionna 는 **OFDM 엔진이자 검증자**다.

**패시브 레이더의 기준신호는 상시 신호뿐** (사용자 지시): LTE = **CRS**, 5G = **SSB**. PRS 는 측위 세션 옵션.
- 거리분해능은 **채널 대역폭이 아니라 기준신호 점유대역** B_ref 가 정한다: ΔR = c/(2·B_ref)
- WiFi VHT-LTF 76.6 MHz → 2.0 m · LTE CRS 18 MHz → 8.3 m · **NR SSB 7.2 MHz → 20.8 m**
- 5G 의 이중고: SSB 는 **좁고**(20.8 m) **드물다**(20 ms 주기 → PRF 50 Hz → v_max 1.1 m/s)
- ⚠ 단, 이 제약은 **idle 셀 전제**에서만 성립. 부하 걸린 셀 + captured full-waveform reference 면
  대역은 채널 전대역, PRF 는 CPI 분할이 정한다(`prf = fs/Lf`). **두 체제를 섞지 말 것.**

## F. PO 커널 진단 — 평판은 시험이 못 된다

- 커널에 버그 5종을 심었더니 **평판은 전부 1.8e-15 dB(기계 0)로 통과**. 진단력 0(항등식).
- 금속구는 3개를 잡음: 2k→k **+6.06 dB**, obliquity 제거 **−29.81 dB**, 조명판정 제거 **+6.02 dB**.
- ⚠ **위상 부호 반전은 구도 못 잡는다** — E→E\* 이고 **σ ∝ \|E\|² 는 켤레 불변**.
  → **dφ/dR 위상 기울기 시험**을 따로 해야 잡힌다 (정상 +1.00 / 부호반전 −1.00).
  이 부호는 **마이크로도플러의 도플러 부호**를 결정한다 — RCS 숫자는 멀쩡한 채 도플러만 뒤집힐 수 있었다.

## H. 아직 모르는 것 (정직하게)

- **PO/SBR 의 절대 RCS 불확실도** — 옛 문서의 ±3 dB 는 유도가 깨졌다. **실측 앵커링 전까지 인용 금지.**
- **ECA 의 이상화** — 유한 동적범위·클러터 도플러퍼짐이 모델에 없다. 정적 클러터가 *실제로* 무해한지는 모른다.
- **흡수체 −25 dB** — 실측이 아니다. `materials.py` 는 평판 단일면이 |Γ|=0.549(−5.2 dB)이고
  −25 dB 는 **피라미드 다중반사로 달성되는 설계 목표**라고 명시한다.
- **호버 RPM** — DJI 가 공개하지 않는다. 5500 rpm 등은 **추정값**이고, 마이크로도플러의 두 헤드라인
  (183 Hz flash, ±1734 Hz tip)이 여기 선형으로 매달려 있다.
