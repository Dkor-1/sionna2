## 0. ⛔⛔지금 가장 급한 것 — 덱의 「sudden drops」가 두 가지를 한 말로 부른다

사용자가 2026-09-08 에 잡았다: 「실외 결과는 정면(0도)가 아니여도 서든 드랍이 발생하는거니?」

**측정으로 갈렸다 — 두 낙차는 다른 현상이다.**

| | 0° 낙차 | 실외 낙차 |
|---|---|---|
| 깊이 (중앙값) | **−3.52 dB** — 20·log10(2/3) 과 자릿수까지 같다 | **−45.4 dB** — 거의 사라진다 |
| 정체 | 평소 같은 도달이 **3 줄**로 적히는데 그 자세만 **2 줄** (`n_dup` 2→1) | 경로 **수는 정상**(차이 0.2 % 미만), 합이 무너진다 |
| 「|E| < 중앙값×0.1」 규칙에 걸리나 | **0 자세** — 안 걸린다 | 84/84 전부 걸린다 |
| 어디서 나나 | 정면 창 안(방위 ≤0.11° · 앙각 ≥−0.15°) | 앙각이 벌어진 자리(−15 ~ −75°) |
| 무엇이 만드나 | 솔버가 같은 줄을 여러 번 적는 것 | **지면 메쉬** — 쪼갠 칸 6/6 에서 지면이 만든다. 건물은 6 칸 중 1 칸에서 +1 뿐 |

⇒ **덱이 둘을 같은 말로 부르면 안 된다.** 고치는 중이다(§1).

### 근거 (전부 재현 가능 — 샤드에서 직접 셌다)

```
자유 / 건물만 / 지면만 / 둘다  의 낙차 자세 수 (|E| < 중앙값×0.1)
  R0D0E0F1 el−15    0 /   0 /  61 /  60      지면 +61 · 건물 +0
  R0D0E0F1 el−30   73 /  73 /  75 /  74      지면 +75 · 건물 +0   ⚠자유의 73 은 지면을 넣으면 사라지고 다른 75 개가 생긴다(겹침 0)
  R0D0E0F1 el−45    6 /   7 /  84 /  83      지면 +84 · 건물 +1
  R0D0E0F1 el−60    0 /   0 /  82 /  84      지면 +82 · 건물 +0
  R0D1E1F1 el−30    0 /   0 /  93 /  87      지면 +93 · 건물 +0
  R0D1E1F1 el−60    1 /   0 / 105 /  99      지면 +105 · 건물 +0
```
· 자유공간 낙차와 실외 낙차는 **겹치는 자세가 0 개**다(앙각 다섯 자리 전부).
· 낙차 자세의 경로 수는 정상이다 — 지면만 el−60 에서 낙차 2708 대 그 밖 2705.
· el 0° 낙차 자세 37 개는 `n_dup`=1(사본 둘), 나머지 8,155 자세는 `n_dup`=2(사본 셋)다.

⛔**아직 안 물은 것** — 실외 낙차가 「지면 반사와 직접 반사가 상쇄된 것」인지 확인하지 않았다.
  깊이(−45 dB)와 경로 수 정상은 상쇄와 맞지만, 경로 목록을 열어 확인한 것은 아니다.
  ⛔「지면이 신호를 지운다」로 결론짓지 않는다 — 지금 말할 수 있는 것은
    「지면 메쉬를 넣으면 이 낙차가 생긴다(6/6)」까지다.
