# Purpose, and what the result changes. Every outdoor cell this repo has bought since 0931 stands on a mirror ground: src/materials.py gives
#   concrete_dark and concrete_light scattering coefficient S = 0.0, so the ground plate reflects specularly and nothing else. Real soil,
#   grass and gravel do not. Whether we may ever leave that assumption is not a physics question first — it is a capacity question, because
#   diffuse paths are counted against the same per-source path cap as specular ones. This file buys the smallest set of GPU cells that can
#   answer it: does S = 0.1 fit in the cap, and what does it cost in seconds, sidecar bytes and card memory?
#   What it changes: if the returned set at S = 0.1 fits well inside the cap and the cost is bounded, ONE longer pair (n1024, S = 0 vs
#   S = 0.1) is designed at the cap that worked, and only then is a scattering axis considered for the ghost and receiver families. If the
#   cap decides the count, or the memory or the time runs out, the scattering axis is folded here and no ground-roughness cell is bought at
#   all — the standing rule is that a saturating cap makes that axis unmeasurable, and the honest outcome is a written cost, not a channel.
#   ⚠What --env-scat is, in one sentence: it overwrites the RadioMaterial scattering_coefficient of the environment objects of the scene
#   (benchmark/elevation_sweep_md.py, the branch after build_scene: every object whose name starts with env_ gets
#   radio_material.scattering_coefficient = S). It is NOT an RMS roughness, NOT a surface-height statistic, and NOT a grass / asphalt /
#   soil material type. It splits the energy of an environment reflection between the specular direction and the diffuse lobe, nothing more.
#   ⚠And this is a STATIC scattering comparison. The ground does not move in any cell here. Scattering at S = 0.1 produces more paths from a
#   motionless plate; it does not produce the Doppler of moving grass, leaves or branches. No clutter-Doppler claim comes out of this file.
