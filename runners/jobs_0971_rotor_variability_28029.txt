# Why --dump-paths is on every line, and what would be lost without it.
#   Three of the six geometries are ground cells, where the environment return is large and STATIC while the
#   rotor return is small and modulated. The repo's standing rule is that the static component leaks into the
#   STFT band and has to be subtracted before any rotor quantity is read. With path lists the record splits into
#   [d] (drone only), [g,d] and [d,g] (one ground leg) and [g] (ground only), so the modulated share can be
#   measured separately from the static one, per class and per part. Without them each shard stores only the
#   summed field E, the ground and the rotor are inseparable in it, and the whole comparison would be a comb
#   contrast computed on top of an unknown static pedestal — exactly the reading the repo has already recorded
#   as a fake peak generator. It would also make the sky and ground halves of this file unreadable against each
#   other, since the sky cells have no pedestal.
#   ⚠Sub-sampling the dump is not an option here. --dump-paths N spreads N positions evenly over the shard
#   (elevation_sweep_md.py:894-898), so N < 4096 would decimate the class time series; at a decimation of 8 the
#   effective rate is 3,503.6 Hz and its Nyquist 1,751.8 Hz, below the blade-flash harmonics this file exists to
#   measure (126.4 Hz fundamental). outputs/readout_0918.json gates.0961.T1_T2 puts

#   verdict «at least 1 % of the rotor-part power lies above the 19.7 kHz Nyquist limit at 15 deg up». So the class time series is kept at full rate and the cost above is paid.
#   Cost of the decision: 3.14 GB, i.e. 0.30 % of free space. Cost of not paying it: the ground half
