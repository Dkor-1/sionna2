# Purpose. Plan §9 central question: a site-specific twin can only beat a written geometric heuristic if where the mast stands relative
#   to structures changes what the receiver sees. This is the cheapest test of that premise in a scene with structures, at a field range
#   (plan: 20-300 m) and a realistic radar height.
#
# Why these positions and not 15 m (the 18:45 draft).
#   To this solver every environment material is a mirror (S = 0), refraction and diffraction are off, max_depth is 2, and the meshes are
#   axis-aligned boxes. A structure can therefore enter a path only through exact specular geometry.
#   · Image-method search over all box faces (scratch queue_design_0917/adv/specular_enum.out, az_scan_30.out, enum30.out; occlusion
#     ignored, so it can only over-report): no path touches a building or a pole at 15 m for az 0 or az 225. Those cells would repeat
#     ground only.
#   · The solver agrees where it was tested. 0955's full scene (iso, d2, el −30, az 0, default height), shard 0, against the stored
#     ground-only cell: E identical to 1e-5 at 4,077 of 4,096 positions, path counts equal at 3,990 (±1 elsewhere) — inside the same-seed
#     rerun spread, at 3.8× the shard time (149.8 vs 39.3 min).
#   · At 30 m, with the radar 1.50 m above ground and the drone at 9.26 m, the search picks two positions. Both have a clear line of sight,
#     with the radar 31 m inside the ground plate edge:
#     az 0   radar in the street between bldg_b and bldg_d (x 29.0, y 0).
#            Environment-only wall returns at 28 m and 22 m of path, and a wall-to-wall double bounce at 50 m: 0.67 / 3.3 / 6.7 range
#            cells from the drone's 60 m at 20 / 100 / 200 MHz. No path from a structure to the drone.
#     az 90  radar in the gap between bldg_a and bldg_b (x 0, y 29.0).
#            Paths radar → wall → drone → radar via bldg_b (+16.9 m) and bldg_a (+18.4 m): 1.1-1.2 / 5.6-6.1 / 11-12 cells from the drone.
#            No environment-only structure return.
#   The two positions carry different mechanisms: clutter near the drone's range vs multipath on the drone's own echo. The nadir is the
#   same at both.
#
# What exists / partners (same drone, rays, depth, R0D0E0F1, cap, record length and dump as 0957):

# Read-out — fixed before any shard is read. E_B, drone paths, environment-only paths, contrast_gated, env_in_bin_db, event_in_bin and
#   event_share are defined in the runners/jobs_0957 header. B = 20, 100, 200 MHz; Hann window, rectangular as the knob.
#   Per cell:
#   · contrast_raw (all delays) and contrast_gated;
#   · env_in_bin_db split into paths touching env_ground only and paths touching any env_bldg_* or env_pole_*;
#   · for each environment-only path class, its offset x and |h_B(x)|;
#   · the listed structure paths checked against the image-method list above (a path the search did not predict is listed by part and delay).
#   structure_drone_in_bin_db (new name, defined here) = 10·log10( in-bin power of paths with at least one drone interaction and at least
#   one building/pole interaction / in-bin power of all drone paths ). A path touching two structures is counted under each and flagged,
#   never shared out (0936 retraction).
#   scene − sky at the same azimuth is «field difference due to the environment»; a building contribution is named only where path
#   classes show it.
#   Δ_struct(q) (new name, defined here) = q(full scene) − q(ground only) at the same azimuth, range and antenna, for q = env_in_bin_db and
#   q = contrast_gated. It removes the drone's aspect and the ground, which change with azimuth in both cells alike.
#   Pre-set working thresholds, not repeat-based. Below them write «threshold not crossed», never «no effect».
#   G  structures change the bin, per position: |Δ_struct(q)| ≥ 3 dB for either q, or structure_drone_in_bin_db ≥ −10 dB, at 20 or 100 MHz
#      → «buildings change the drone's range bin at this position».
#   F  position lever: |Δ_struct(q)(az 90) − Δ_struct(q)(az 0)| ≥ 3 dB for either q, at 20 or 100 MHz → «position lever present at this
#      geometry». Written beside it, and not read as a lever: the raw between-position differences of the full-scene cells, and those of
#      the two open-sky partners (drone aspect alone).
#   Hann and rect disagree on F or G → not written. All levels carry the 0957 ray-density note; only Δ_struct and F are read as results.
#   Scope in every sentence: two named positions, one hover point, 30 m, flat mesh scene with mirror materials and box buildings,
#   tr38901 stand-in, no leakage or receiver noise, one run per cell.
