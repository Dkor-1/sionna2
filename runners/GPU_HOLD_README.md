## ⛔이 규약이 **못** 하는 것

컨테이너 **이름을 확인하지 않는다.** 우리 컨테이너 안에서 `nvidia-smi` 의 compute-apps 는
**우리 프로세스만** 보여 준다. 잴 수 있는 것은 「카드 전체 사용량 − 우리 것」 = 남의 점유(MB)
뿐이다. 지금 판은 `gpus: [4]` 로 **조건 없이** 빼고 있다 —
「4번을 쓰고 있을 때만」 으로 바꾸려면 `gpus` 를 `[]` 로 비우면 `gpus_if_external` 이 남는다.
